
## §28 形状口径で採点し直す + 3–9 Hz が伸びない構造的理由

**きっかけ**: 「我们要的是形状上的一致，不是能量上的完全一致」。
これまでの主指標 `残差/実測` は二乗誤差比 = **エネルギー口径**で、
「形は合うが振幅が小さい」予測を強く罰する。分離して測り直した。

分解: `残差/実測` = 形状のずれ `(1−ρ²)` + 振幅のずれ（最適ゲイン α≠1 の分）。
`ρ²` = 最適スカラーゲインを許したとき説明できる分散比 = **純粋な形状点**。

pp2 開発基準集 17 集、各系列は自分の最適シフト:

| モデル | 0.5–3 Hz ρ² / α | 3–9 Hz ρ² / α | 0.5–9 Hz 残差 / (1−ρ²) / α |
|---|---|---|---|
| G-π-phys-v1（旧） | 0.448 / 0.78 | 0.016 / **0.16** | 0.980 / 0.819 / **0.51** |
| **G-q-v1** | **0.710** / 1.05 | **0.107** / 1.13 | 0.564 / **0.563** / **1.06** |
| kin(G-q-v1 の関節) | 0.721 / 1.09 | 0.179 / 2.00 | 0.547 / 0.540 / 1.14 |
| kin(実測エンコーダ) | 0.906 / 1.05 | 0.487 / 1.77 | 0.322 / 0.311 / 1.15 |

**判読**: G-q-v1 の最適ゲインは 1.06、残差 0.564 ≒ 1−ρ² 0.563。
⇒ **口径を形状に替えても G-q-v1 の評価は変わらない**。0.564 はほぼ全部が形状誤差。
（旧 phys-v1 は α=0.51 で振幅が半分 ⇒ そちらでは区別が効いた。既に解消済み。）

帯域で割ると割れ方は明快: **0.5–3 Hz は ρ=0.84 で形が合う / 3–9 Hz は ρ=0.33 で合わない**。
図 `outputs/step2_g/advisor/fig6_pp2_shape_bands.png`（中央値 B09A・最難 B07A）。
上段は三本の線がほぼ重なる。3–9 Hz は帯域通過エネルギーの約 45%。

### なぜ 3–9 Hz が動かないか（六輪連敗の構造的理由）

接触パッチ・限幅器再検査・`ΔH·u_hf` 層・学習式 HF 残差・速度目標・planner 比較
—— **六つとも 3–9 Hz を狙い、全部失敗か限界的**。証拠は損失の在処が別だと言っている。

1. **関節→IMU 写像の責任**: **実測エンコーダ**を今の剛体センサ写像に入れても
   3–9 Hz 残差は **0.604** 止まり。関節予測が完璧でも 6 割残る。
   一方 3–9 Hz の**関節**残差は仿真 q = 0.3796 で、線形予測界 1−γ²=0.70 を既に下回る。
   ⇒ 動力学パラメータ・planner・接触は、どれもこの層に触っていない。

2. **口径の非対称（新規・要注意）**: シミュ側の陀螺は `g_q_v1.py:231` で
   1 kHz から **9 Hz 抗混叠フィルタ**を通して 20 Hz に落とす。
   実機側は TSND151 100 Hz を `get_latest()` で **5 倍間引き・抗混叠なし**
   （`step2_ceiling.py` が既に指摘済み）。
   ⇒ **抗混叠済みの信号を、混叠した信号に当てて採点している。**
   実機の混叠成分にはシミュ側に対応物が原理的に存在しない。

   `probe_b2` の 6 回裸複放（指令バイト一致）で 100 Hz 生から両方式で 20 Hz に落として
   **真機自身の再現性**を測った:

   | 帯域 | (a) 現行=抗混叠なし | (b) 抗混叠あり | 差 |
   |---|---|---|---|
   | 0.5–3 Hz | 90.5% | 98.6% | +8.1pp |
   | **3–9 Hz** | **68.5%** | **88.4%** | **+19.9pp** |
   | 0.5–9 Hz | 80.1% | 94.6% | +14.5pp |

   ⇒ 現行ログの 3–9 Hz は **31.5% が真機自身にも再現できない**。
   決定論的モデルの床は残差 ≈ 0.157（= (1−0.685)/2）。

   **ただし過大主張しないこと**: 我々は 0.894 にいて床は 0.157。
   混叠を直しても我々の数字は 2 ポイント程度しか改善しない。
   混叠は**天井を下げている要因**であって、**現在の失敗の主因ではない**。
   （この測定は `probe_b2` であり pp2 ではない。ログ経路は同一なので機構は移るが、
   大きさは pp2 で測り直していない。）

**結論**: 3–9 Hz の到達可能な改善は 0.894 → 0.604（約 32%）で実在するが、
その 0.604 の壁は**センサ／可観測性の層**（20 Hz で見えないフレーム間運動、
エンコーダ≠連杆角、IMU 外参・内部フィルタ・支架モード、剛体写像）にあり、
23 パラメータ・planner・接触のどれを回しても届かない。六輪はそこを外していた。
