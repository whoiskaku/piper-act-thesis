# G-vNext 结果：7 条判据过 6 条，唯一未过是 3–9 Hz 的 ρ²

预注册 `PREREG_G_VNEXT.md`。采集 + 分析 2026-09-02。

## 0. 一句话

`q̂ = G-q-v1(u) + r_q`、`ω̂ = kin(q̂) + r_s`，两层都是**因果 FIR**。
在**未见轨迹 + 跨会话**留出上，3–9 Hz 的 ρ² 从 **0.193 → 0.520**，
0.5–3 Hz 从 0.817 → 0.836；**7 条判据过 6 条**，
唯一未过的是判据 2（3–9 Hz 0.520 < 门槛 0.707）。
**没有输给相位模板**（0.137）—— 旧 `hf_learned_residual` 致命的那一条这次没重演。

## 2. ⚠ 两处必须记住的错误（不修则结论全错）

### 2.1 损失权重形同虚设（我自己挖的坑）

写的是 `L = 0.5·MSE(残差) + 0.5·MSE(bp_{3-9}(残差))`。但**带通后的目标方差比宽带小
约三个数量级**，所以「0.5 权重」让带内项几乎不起作用 —— 又是
「目标从没要求过 3–9 Hz」（`RESULT_BAND_WEIGHTED_IDENT.md`）那个坑。
`optuna_ident_band` 里本来是**各自按自身尺度归一**的，没照搬过来。

修正 `L = (1−w)·MSE/var(Y) + w·MSE(bp)/var(bp Y)` ⇒ 折外 **−3.4% → +3.6%**。

### 2.2 一条执行异常的集占了训练集 99.9% 的残差能量

`s1/pp2_ep001` 带 **`return_blocked=True`**：集内 t=16.4 s 时 j2 指令 −1.44°
而实测 **97.49°**，j1 只走了指令行程的 38%（22.3° vs 58.6°）——
机械臂中途就没在跟指令了。它的关节残差 RMS **620 mrad（35°）**，
其余 25 条是 3.19–7.43 mrad。

根因是流程缺口：**`collect.py` 按帧数判「录满了」，那个判据管的是「有没有录到」，
不管「有没有执行对」**。有效性标志本来就在文件里。
已加 `data.valid_files`，剔除 `stopped`/`return_blocked` 并**大声报出**。

剔除后折外 **+3.6% → +45.9%**。

## 3. 训练（只用训练族折外选参，留出族未参与）

| 层 | 选中 | 折外 3–9 Hz 削减 | 折外 宽带 |
|---|---|---|---|
| `r_q` | FIR nlag=4, λ=1e-4 | **45.9%** | 40.2% |
| `r_s` | FIR nlag=16, λ=1e-4 | **42.3%** | 0.5–3 Hz 21.1% |

`r_q` 折外逐关节：j1 52.8 / j2 42.0 / j3 58.0 / j5 46.3 / j6 27.8 %。
`r_s` 的输入里 `q̂` **只用 `r_q` 的折外预测**（防训练泄漏）；
目标 `IMU100_real − kin(q200_real)` 用**真关节**，与关节预测好坏解耦。
传感器层基线残差（真关节 + 刚体渲染）3–9 Hz = **0.493**。

**网络那一次已按预注册用掉**：修数据前触发（折外 < 5%），
结果样本内 +64.9% / 折外 **−56.6%**，纯记忆。修数据后 FIR 折外 45.9% ≥ 5%
⇒ **不需要网络**，最终模型两层都是线性因果 FIR。

## 5. 判据 2 差在哪 —— 结构性，不是调参能补的

3–9 Hz 的链条：

```
G-q-v1  0.193
  ├─ +r_q  → 0.410     关节层，已拿到 38.5% 的关节误差削减
  ├─ +r_s  → 0.520     传感器层，折外 42.3%
  ├─ 天花板 0.649      真关节 + **刚体**渲染的上限
  └─ 可重复性 0.840    真机自身（跨会话）
```

- **门槛 0.707 高于刚体渲染的天花板 0.649** ⇒ 无论关节层做到多好，
  只要传感器侧还是刚体渲染 + 加性残差，就过不了。
- `r_s` 已经把 0.410 推到 0.520，即吃掉了 (0.520−0.410)/(0.840−0.410) = **26%**
  的可得空间；要到 0.707 得吃掉 69%。
- 剩下的差距在 **0.649 → 0.840** 这一段，即刚体假设本身
  （支架模态、IMU 内部滤波、外参、连杆柔性）。加性 FIR 残差补不了乘性/结构性的项。

## 7. 口径（每处引用必须带）

- 留出 = 会话2 的 pp2f(5) + pp2f60(3)，**轨迹未参与训练、会话也未参与训练**。
- 两层的 nlag/λ 均由**训练族折外**选定；留出集未参与任何选择。
- 真机 100 Hz → 9 Hz 低通 → 20 Hz；时基 = TSND 设备 ms + CAN 内核时刻；
  **不用落盘的 20 Hz 字段**。
- 真机逐集正交 Procrustes 旋入机体系（绑带逐会话重装、无标定）；逐系列最优位移。
- 可重复性上界 0.983 / 0.840 是 pp2 **跨会话**实测（比同会话保守）。
  预注册的 0.986 / 0.884 是 `1−‖A−B‖²/‖B‖²` 口径被当 ρ² 用（**混了指标**），
  所幸偏严：冻结门槛相当于实测上界的 80.3% / 84.2%。**门槛按预注册保持冻结。**
- 30 条候选中 4 条因越 MuJoCo 模型限位（j2，0.07–0.40°）**在采集前剔除**，未放宽限位；
  另 1 条因 `return_blocked` 在分析时剔除。
- 本轮数字**不可与** 17 集 pp2 开发基准集或 §28 的旧口径数字并列。
