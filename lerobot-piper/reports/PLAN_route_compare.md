# 两条路线的比较方案（v0.6，2026-10-19；路线 1 按此实现）

共同起点（已定）：开 TE、提前 60 ms 的 Shift，目标是**未加补正的原始策略指令**；评价按 `reports/PLAN_eval_standard.md`
（关节偏差、末端角速度偏差，相对原始指令一族，判据 b，运动护栏）。两条路线都要证明真机效果能进一步超过 Shift。

分两步（用户 2026-10-19 定）：
- **第一步（本轮）**：固定指令上的小规模比较——在相同真机预算下，哪条路线找到的补正序列能超过 Shift。不训练通用 π。
- **第二步**：训练 π，在没有参与训练和选参数的指令上检验泛化，最后进入 ACT + TE 闭环。

得到有效的补正序列只证明「这条轨迹有可改善的空间」，不等于完成了学习型补正器。

**顺序**（用户 2026-10-19 定）：先做路线 1（不加 G），之后再加路线 2。两条路线不在同一会话，各自只和同会话的 Shift 比；
跨会话的漂移（含 IMU 标定）不能靠穿插消除，比较时要写明。路线 1 的回放是否、以何种成本开放给之后的路线 2【待定】。

## 0. 老师标准第 1–6 条（第一步）

1. **只确定一件事**：在相同真机预算下，两条路线在固定指令上能否超过 Shift，哪条用更少的真机试验做到。不涉及泛化。
   「IMU 有没有贡献」是另一件事，由路线 1 内的分叉对照单独回答（§2），不和路线比较混在一起。
2. **G**：只在路线 2 里用。G 的输入输出、训练数据、每一版的名字（第几轮）在 §3 写清；每轮都在「补正后的指令」上和真机对照。G 内的改善只作训练诊断，不进判据。
3. **π：本轮不涉及**。第一步优化的是固定指令上的补正序列，不是网络；π 放到第二步。
4. **实现正确的证据**：补正 = 0 时复现 Shift 的数值；人工给定补正，误差变化与手算一致；路线 1 的更新方向在合成数据上能收敛；路线 2 的 G 每轮在留出的真机回放上测。
5. **推理链**：结果只针对 A、B 两条已反复看过的开发轨迹；路线输了只说明「这个最小版本、这个预算下」输了；两条都没过 Shift 不推出「补正做不了」；路线 1 胜不能写成「G 没用」。
6. **真机**：判定只看真机回放；每个评价点同一会话穿插 Shift。

## 1. 两条路线共用的约定

- **补正形式**：发出的指令 = a_π(t + 60 ms) + Δ(t)，只优化 Δ（每条固定指令一条补正序列）。
- **目标锁定**（用户 2026-10-19 定）：两条路线优化的都是**总跟踪误差**，两项都相对原始策略指令：
  关节 = 编码器 − 原始指令（零阶保持）；IMU = 实测陀螺 − 原始指令的运动学渲染（线性插值）。IMU 参与两条路线的更新。
  两项相关（关节运动对应的偏差 + r），不为避免重叠而改目标。
  **合并规则**（用户 2026-10-19 定，第一轮开发规则）：两项各除以基准值后等权相加作优化目标；两项各自不得比基准差超过 +5%（护栏）。
  基准：路线 1 的两支 = 分叉点；路线 1 共同关节阶段与路线 2 = 同会话 Shift。只用关节项的部分不用 IMU 护栏（IMU 只评价；用户 2026-10-19 确认）。
  评价用的偏差取 RMS，符号无关；**更新用的误差一律写成「目标 − 实测」**（§2）。
  r =「编码器刚体运动学未解释的残差」（实测陀螺 − 编码器刚体运动学），只用于分析编码器之外的信息与补正机制；其中仍可能含测量、标定和运动学误差。
- **IMU 前提**：每次会话先做标定回放；分析逐遍报朝向偏差，超过约 2° 停下检查（10-19 Shift 会话 IMU 转了约 8.9°，见 PLAN_shift_replay §6 订正）。
- **条件相同**：同样的固定指令、可用信息、补正范围。
- **补正范围**：Δ 上限每关节 ±15 mrad 为候选（残差大小只支持量级选择，不证明安全；安全检查针对最终的 Shift + Δ 指令）；
  频带先按 5 Hz 设计，作谨慎起点——不据此认定更新方向可靠（ILC 是否收敛取决于更新规则与实际动态是否匹配，低通只是约束之一）。
  20 Hz 指令不能独立表示任意高于 10 Hz 的补正，但不能因此断言它影响不了更高频的振动（改变激励方式也可能降低振动），需真机验证。
- **疑似接触段内 Δ = 0**（两条路线相同，接触标记前后留余量）：评价不算这些段；碰桌时补正可能加大接触力；迭代会追碰撞造成的误差。
- **固定指令**（用户 2026-10-19 定）：沿用可重复性检验的 A、B（开 TE 抓放），不增加新工况；它们是反复看过的开发轨迹，本轮结论只针对这两条。
- **已有数据**（可重复性检验、Shift 回放、正式基线等）对两条路线同等开放，不计入预算。

## 2. 路线 1：直接用真机误差改指令（不训练前向动态 G）

- 定义：**不训练前向动态 G**；允许使用已知运动学（雅可比、IMU 标定）。最小做法 = 迭代学习（ILC）：回放一遍 → 用这一遍的真实误差更新下一遍的补正。
- 要回答：不训练前向 G，能否找到超过 Shift 的补正？风险：对这条指令有效，换一条可能无效（第二步检验）。
- 结构：共同关节阶段 → 从同一份补正（分叉点 Δ_bp）分两支：只关节支、加 IMU 支（用户 2026-10-19 定），区分「IMU 的贡献」和「继续迭代的贡献」。

### 2.1 记号

- 帧 k = 0…N−1（20 Hz，N = 515）；每遍回放的第 k 帧在本遍自己的 t_send[k] 写总线。
- a_k：原始策略指令（5 个活动关节，rad）；s_k：提前 60 ms 的指令（Shift）；发出的指令 u_k = s_k + Δ_k。
  **Δ 按帧、即按本遍发令时刻索引**；j4 与夹爪的 Δ 恒为 0。
- q(t)：编码器（200 Hz）；g(t)：陀螺（100 Hz，IMU 坐标）；标定 R、b_g、d：g(t) ≈ R·ω_site(t − d) + b_g。
- 掩码 W_k ∈ [0, 1]：开头保持段（k < 20）与疑似接触帧为 0，向外 0.25 s（5 帧）余弦过渡；最后 0.25 s 过渡到 0。
- Q：20 Hz 帧序列上的零相位 4 阶巴特沃斯低通，截止 5 Hz（谨慎起点，不代表更新方向可靠）。

### 2.2 关节项（e_q = 原始指令 − 实测位置）

1. e_q(t) = a_zoh(t) − q(t)：a_zoh 按本遍 t_send 零阶保持；疑似接触帧内置 0。
2. ẽ_q = 零相位 5 Hz 低通(e_q)（200 Hz 网格上）。
3. ē_q,k = ẽ_q(t_send[k] + τ)；超出记录范围置 0。
   **τ = 60 ms 是初始假设**：来自 Shift 的最佳总滞后，不是新增 Δ 的响应延迟实测值。
- 符号：实测落后于指令时 e_q > 0，Δ 增大，指令加大，实际跟上（负反馈）。若误差写成「实测 − 指令」，更新要用减号。

### 2.3 IMU 项（e_ω = 目标 − 实测；刚体运动学近似逆，角速度 → 关节位置）

1. e_ω(t_i) = g*(t_i) − g(t_i)：g* = R·ω_site[原始指令线性插值](t_i − d) + b_g，与评价相同的渲染；疑似接触帧内置 0。
2. 转到安装点坐标并限带：ε(t_i) = 零相位带通 0.5–5 Hz（Rᵀ·e_ω）。下限 0.5 Hz 防积分漂移，更低频交给关节项。
3. 关节速度修改（rad/s）：δq̇(t_i) = J⁺·ε(t_i)；J = 原始指令位形（t_i − d 时刻）下安装点角速度对 5 个活动关节的雅可比（3×5，安装点坐标）；
   J⁺ = Jᵀ(JJᵀ + λ²I)⁻¹，λ = 0.05（阻尼最小范数解）。
4. 积分成位置修改（rad）：δq(t_i) = ∫ δq̇ dt（从第一个样本起梯形积分），再零相位高通 0.5 Hz 去掉积分漂移。
5. ē_ω,k = δq(t_send[k] + τ + d)（IMU 时钟上的运动晚 d）；超出记录范围置 0。

### 2.4 合成与更新

- 共同关节阶段：ē = ē_q；分叉后两支的关节系数相同（用户 2026-10-19 订正）：只关节支 ē = ½·ē_q，加 IMU 支 ē = ½·ē_q + ½·ē_ω。
  这样两支只差 IMU 项；IMU 项为零时两支生成的候选相同（测试）。
- **Δ_next = clip_{±15 mrad}( Δ_acc + W ⊙ Q[γ·ē] )**（用户 2026-10-19 订正：窗只乘新增量，不反复削弱已接受的补正；
  保持段、接触段因 W = 0 且初值为 0 而严格为零；零更新保持 Δ_acc 不变——测试）。γ 初值 0.5，每次退回后减半，之后不回升。
- ē^(n) 取自当前已接受补正的回放（经确认的取两遍平均）。第一次更新：Δ^(0) = 0，误差用开场两遍 Shift 的平均。
  两支都从分叉点 Δ_bp 和它的回放误差出发。

**关节限位保护**（用户 2026-10-19 定，两支统一执行，之后的路线 2 同样适用）：
- **掩码按实际发令帧建立**：原始帧越界、实际发令的 Shift 帧越界、前瞻误差对应的原始帧（t_send[k] + τ 时生效的那帧）越界，三者取并集，
  再做逐关节 0.25 s 余弦过渡；掩码仍只乘新增量。越界 = 超出模型关节限位（j2 < 0°、j3 > 0°）。冻结帧：A j2 34、j3 61；B j2 34、j3 65。
- **最终 Δ 同时满足两个限制**：±15 mrad，且 Shift + Δ 离回放管线硬界（模型限位 ± 2°，同 replay_probe.safety_checks）至少 0.2°。
  A、B 当前的 Shift 都有余量（A j2 最紧：Δ 下限 −0.55°），Δ = 0 可行；不满足就拒绝开始。
- **单帧跳变自检**：Δ 写在序列里，管线的这项检查是拿序列和它自己比，起不到作用；改由本脚本按管线同一公式检查
  （以 Shift 为裸序列：最大单帧跳变 < 1.5 倍 + 6 mrad），不通过就停。
- **措辞**：这些帧在提前 60 ms 的回放里有饱和迹象（j2 停在 0.00°、j3 约 0.01°），本轮保守停止这些位置的更新；
  不能说这些误差都改不了——回放管线（replay_probe.py 第 115 行）把模型范围称为保守软限。评价继续包含这些帧；
  把整帧误差置零得到的降幅（A 3.33 → 2.93、B 3.29 → 2.97 mrad）不是不可改善误差的准确占比，只作情景参考。

### 2.5 接受、确认、「没有改善」

- 目标值 J = J_q / J_q^基准 + J_ω / J_ω^基准。J_q：关节偏差 RMS；J_ω：末端角速度偏差 RMS（<15 Hz）；
  都在非接触段算（同 Shift 回放分析，基线与提前 60 ms 两份指令的疑似接触帧取并集）。
- 基准：共同关节阶段 = 开场两遍 Shift 的平均；两支 = 分叉点的回放（经确认的取两遍平均）。
- 护栏：共同关节阶段与只关节支只看 J_q ≤ 1.05 × 基准；加 IMU 支两项各自 ≤ 1.05 × 基准。
- 触发护栏 → 同一候选再回放一遍确认，按两遍平均判断；仍超就退回（Δ 回到已接受的那份，γ 减半）。
  确认能减少偶然误退，实际误退率未知。预算不够做确认时，直接退回。
- 护栏通过就接受（不要求 J 下降：单遍噪声下只接受下降会随机拒掉无差别的候选）。
- 加 IMU 支里的「没有改善」= 被退回，或已接受但 J 不低于上一份已接受补正的 J（单遍或两遍平均）。

### 2.6 切换到真机试探（只在加 IMU 支）

- 连续两次「没有改善」后，该支剩余预算里的 IMU 项改为试探。
- 每步两个候选：Δ_± = clip( Δ_acc + W ⊙ Q[γ·(½·ē_q ± c·½·ē_ω)] )，ē_q、ē_ω 取自已接受补正的回放；c 初值 1。
  **试探阶段只剩 1 遍时：复测已接受的补正，不再更新**（用户 2026-10-19 订正）。
  两个候选都回放，护栏与确认照常；通过护栏、J 较低且低于 J_acc 的那个被接受；两个都没有改善就保持 Δ_acc，c 减半。
- 试探的变量只有 IMU 项沿刚体运动学方向的符号和幅度（一维）；只估计当前这一步，不建立或求逆通用的响应模型。

### 2.7 诊断（只报告，不进判据）

- 新增 Δ 的经验滞后：相邻两份补正之差与对应编码器之差的互相关滞后（第一轮不据此改 τ）。
- 最终 Δ 的纯时间平移分量 δt = ⟨Δ, ȧ⟩ / ⟨ȧ, ȧ⟩（ȧ = 原始指令速度）。**已知风险**：两种参考的最佳时刻差约 35–45 ms
  （关节零阶保持 vs 末端线性插值，其中约半帧来自参考定义），加 IMU 支可能被拉向更早，受关节护栏约束；用 δt 区分「时间平移」与「形状修正」。
- 逐遍 IMU 朝向偏差（超过 2° 停下）；逐遍 J_q、J_ω 的迭代曲线；每次更新的 γ、c 与接受 / 退回记录。

## 3. 路线 2：借助持续更新的 G 改指令

- 最小做法：用真机数据建立 G → 在 G 中优化补正序列 → 上机检验 → 用补正后的真实运行更新 G → 再优化。
- G 的形式（结构模型还是神经网络）、输入输出、初始数据怎么采：待讨论。每一版记名（G₀、G₁…）。
- 要回答：G 的预测能否帮助我们用更少的真机试验找到更好的补正？
- 风险：优化会利用 G 的预测错误；持续更新也不保证有效。每轮记录 G 在补正后指令上对真机的预测误差。

## 4. 预算与评价点（路线 1 的封顶预算）

计数单位：一条序列的一遍回放。候选（接受或退回）、确认、试探、评价、标定、Shift 全部计入。开始运动后中止的那遍也计入、不补跑；
连接失败、臂没动的不计（同 `attempted` 规则）。A、B 各有自己的 Δ 和预算，流程相同。

| 环节 | 每条序列 | 合计 | 说明 |
|---|---|---|---|
| 开场标定回放 | — | 1 | 两条序列共享 |
| Shift 基准 | 2 | 4 | 单列为 Shift 对照；第一次更新用它们的误差 |
| 共同关节阶段 | 4 | 8 | 按回放数封顶，不按接受次数；用完即停，结果 = 最后接受的补正 |
| 只关节支 | 6 | 12 | 与加 IMU 支**相同的实际追加回放数** |
| 加 IMU 支 | 6 | 12 | 候选、确认、试探都从这 6 遍里扣 |
| 最终评价 | 16 | 32 | Shift、Δ_bp、只关节支、加 IMU 支，各 4 遍；其中 Shift 8 遍单列 |
| **上限** | | **69** | 约 80 分钟（按上次约 70 秒一遍）；不再追加 |

- 两支、两条序列交错进行，顺序事先排定（两支各占一半先手）。
- 跨会话比较（之后的路线 2）只用各自同会话 Shift 的相对值，并写明漂移不能靠穿插消除。

## 5. 判定（第一步）

- 最终评价：每轮 = 每条序列四个条件各 1 遍（拉丁方顺序），共 4 轮。
- **配对**：同序列、同轮，相对变化 (x_条件 − x_参照) / x_参照，指标为 J_q、J_ω，护栏为路径长度、关节速度 RMS。
- **按序列汇总**：每条序列取 4 对的中位数；总体效应 = 两条序列中位数的平均（每条序列等权，不把 8 对当成 8 条独立轨迹）。
- **95% 置信区间**：对完整轮次有放回重抽，**A、B 用同一组轮次**（保留同轮关联），算「两条序列中位数的平均」，重复 10000 次
  取 2.5 / 97.5 百分位；序列本身不重抽（结论只针对 A、B）。同时逐序列报告中位数与范围。
- **完整度**（用户 2026-10-19 订正）：规定的 4 轮都完整（两条序列都有这两个条件）才判定；缺失则只用完整轮次报告，记「未完成」。
- 判据 b：两个主指标的上界 ≤ +5%（不变差），且至少一个上界 < 0（改善，不设最小降幅，同时报降幅大小）；护栏 ±5%（中位）。
- 四组比较：Δ_bp vs Shift；只关节支 vs Shift；加 IMU 支 vs Shift；**加 IMU 支 vs 只关节支**（IMU 的贡献，以只关节支为参照）。
- 每条 4 对是小规模开发评价，不保证检出力；分层自助法下，上界 < 0 基本要求多数配对同号。
- 估算一律叫「情景估算」，不叫「收益上限」：补正后关节运动、振动激励和遍间变动都可能改变；两部分误差相关，不能按功率相减。
- 两条路线之间（路线 2 做完后）：各自相对同会话 Shift，报告「累计用了多少次真机、实际改善了多少」。

## 6. 后续采集要求（第二步与闭环之前）

- **逐帧保存 chunk**：预测值、对应的目标帧、实际可用时刻、TE 集成规则，用来重建「当时真正能发出的提前 60 ms 指令」。
- 回放能读整条未来指令，在线只能用当时已有的 ACT 预测；离线比较能量出两种指令的差别，闭环效果仍要另测。

## 7. 逐项讨论
