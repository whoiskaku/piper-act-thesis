## 4、② `F_inc`：结构、输入与训练

**只用 `P1`（8 集）训练。目标是<u>实测总 `gap`</u> 的预测误差，<u>不用 `H` 生成标签</u>。**

```
预测量：  ĝap(u, δa) = ê_base(u)  +  F_inc(u, δa)
                        └ 冻结 ──┘     └ 本轮唯一被训练的东西
损失：    P(·) 之后的  ‖ gap_measured − ĝap ‖²  / (3 T_e)      （与 F_abs 同口径）
```

### 4.1 结构保证 `F_inc(u, 0) ≡ 0`（差分式）

```
F_inc(u, δa) = N([ x(u), 𝒩(δa) ]) − N([ x(u), 𝒩(0) ])
```

同一网络 `N` 两次前向。**零扰动分支：先把<u>原始</u> `δa` 置 0，再过同一归一化 `𝒩`。**
⇒ `δa = 0` 时两次前向的输入完全相同 ⇒ **输出逐位为 0，与参数无关**（自测须验证）。

⚠ **这只保证「零扰动时输出为零」，<u>不</u>保证「非零扰动时响应正确」。**
（这正是本实验要测的东西，不能拿结构性质当结论。）

### 4.2 网络与输入（⑤）

与 `F_abs` **同一主干**：因果空洞卷积，左填充，4 层 `k=5`、`d=1/2/4/8`、64 ch，
输出头零初始化。输入 **21 + 6 = 27** 通道 = `[u, Δ⁻u, Δ⁻²u]`（21）+ **原始 `δa` 6 维**
（**不补差分**）。归一化统计**仅用 `P1`**。

⚠ 受野 `1 + 4×(1+2+4+8) = 61` 帧，**说明覆盖了较长历史**（远超 `H` 的 16 滞后），
但**不能据此断言表达力或优化一定不是瓶颈**。

### 4.3 优化与步数（③，**事前固定，不搜索**）

Adam · `lr = 1e-3` · **梯度裁剪 1.0** · **固定 3000 步** · **无 weight decay** ·
**不新增输出惩罚** · **不选最佳检查点**。

⚠ **这是一个事前固定的首轮配置，不代表它适合所有数据规模。**
**保留训练损失记录。若失败，不事后追加正则，也不续训。**

**训练种子 `0`、`1`、`2`，全部报告，不挑最好种子。**

## 5、③ 同基线比较

### 5.1 四项预测（`P2` 主比较，`P3` 压力评价）

| # | 预测 | 含义 |
|---|---|---|
| **(a)** | `ê_base` | 只有名义分支（不建模任何响应） |
| **(b)** | `ê_base + H ⊛ δa` | 冻结 `H`（sha `89d118d4b69837f0…`），**原 `H` 不修改** |
| **(b′)** | `ê_base + β·(H ⊛ δa)` | **标量校准 `H`** —— 见 §5.3 |
| **(c)** | `ê_base + F_inc(u, δa)` | 神经增量分支 |

### 5.2 误差泛函与**聚合顺序**（②）

```
P(·)      = 逐集去均值 → bandpass41(0.5–9 Hz) → 丢首尾 EDGE = 20 帧
E(e, x)   = ‖ P(gap_e − pred_x,e) ‖² / (3 T_e)          T_e = 有效帧数
```

**必须按这个顺序聚合**：

```
① E_x(s, k) = (1/2) Σ_{e ∈ 探针种子 s}  E(e, x)        ← 先对同一探针种子的两集**误差**取平均
② E_x(s)    = (1/3) Σ_{k ∈ {0,1,2}}    E_x(s, k)      ← 再对三个**训练种子**的误差评分取平均
③ d_s^{(y)} = [ E_y(s) − E_c(s) ] / E_y(s)             y ∈ {b, b′}
④ d̄^{(y)}  = (1/3) Σ_s d_s^{(y)}                      ← 探针种子**等权**
```

> ⚠ **不是先平均网络预测再评分** —— 那会变成集成模型实验。自测须显式区分这两者。

⚠ **「训练种子」（`F_inc` 的 0/1/2）与「探针种子」（`2000/2001/2002`）是两个不同的东西。**
(a)/(b)/(b′) 不依赖训练种子（`β` 只由 `P1` 与冻结的 `ê_base` 决定）。

### 5.3 ④ `β` 的定义（**拟合扣除名义预测后的残差，不是总 `gap`**）

```
r_e = P( gap_e − ê_base,e )          h_e = P( H ⊛ δa_e )            e ∈ P1

      Σ_{e∈P1} w_e ⟨r_e, h_e⟩
β =  ─────────────────────────        w_e = 1 / (3 T_e)
      Σ_{e∈P1} w_e ‖h_e‖²
```

`P` 使用**与 §5.2 完全相同**的逐集去均值、带通与有效帧处理。
**只拟合一个全局标量，仅用 `P1`；不扫描、不按轴分开。**

⚠ **允许 `β` 为负，但必须报告。负值意味着包含<u>方向反转</u>，
不能只称「幅度校准」。** 原 `H` 不修改。

### 6.1 事前停止条件

| 检查 | 定义 | 不通过怎么称呼 |

### 6.2 推进门槛

**`P2` 上，(c) 相对 (b) <u>和</u> (b′) <u>都</u>必须满足：**

1. **三个探针种子的 `d_s` 全为正**；
2. **等权平均 `d̄ ≥ 5%`**。

**并且**（防止只是打败了一个有负贡献的响应模型）：

3. **`P2` 按探针种子等权的平均误差，(c) 必须低于 (a)**：
   `(1/3) Σ_s E_c(s) < (1/3) Σ_s E_a(s)`。

**三条全部满足才算推进。**

⚠ **`5%` 沿用为推进阈值，但本轮增加了名义分支，<u>比较基准与分母已经改变</u>，
<u>不能</u>与分箱核的 −1.40%、`K_φ` 的 +0.144% 直接排名。**

⚠ **不得**用真机 `C−A = −8.0%` 之类的数字论证这个离线门槛
（预测误差下降 与 受控后的真机误差下降 **不是同一个指标**）。

### 6.3 `P3`

**次要压力报告。不挽救 `P2`。**
⚠ `P3` 均值大于零**只能记作平均改善**，**不能据此宣称已覆盖 3 mrad RMS**
（何况 `P3` 含 0.04%–0.12% 的 ±10 mrad 截断，不是纯 2× 缩放）。
