## 2. 采集设计（两阶段）

    第一阶段（7 次）： A0 → A1×6             ⇒ **只估噪声，据此锁定 N**
    第二阶段（2N+6）： (+ − − +)×(N/2) → A2×6

- `A1` / `A2` **各固定 M = 6**；`Bp` / `Bm` **各 N**，`N ∈ {6, 8, 10}`
- 总次数 **13 + 2N = 25 / 29 / 33**
- **`A2` 必须留在 `B` 之后**，保留前后基线
- 符号**不与采集时间绑定**；⚠ **实际时间戳仍须记录 ——
  采集位置平衡不代表所有漂移都被消除**
- 裸臂次数与符号次数**分开存储**，代码**断言实际序列计数一致**

### 2.1 `N` 的确定规则（**事前冻结**）

    S_H = 最终冻结波形经 H 后，预测奇分量的 RMS       = **0.0292589 rad/s**（已冻结）
    σ̂  = 当日 M=6 条 A1 估出的单次复放噪声
          （**同坐标、同滤波、同有效时间窗**；由**重复轨迹之间的差异**估计）

    取满足  S_H · sqrt(2N) / σ̂ ≥ 3  的**最小偶数 N**，且 N ≥ 6，上限 10

- 所需 `N ≤ 10` ⇒ **锁定后采 B，不根据中途模型得分追加**
- 所需 `N > 10` ⇒ **不启动 B**，记「**当前预算下预计检出能力不足**」，
  另行决定预算，**不能判模型失败**

⚠ **这是次数规划，不是通过保证、也不是统计功效证明。**
噪声**不是**整段运动的 IMU RMS，**也不能**把数千帧当独立重复。
六次估计本身仍有不确定性；公式还依赖**重复噪声近似独立、同方差**。

## 4. 分析口径（`sim/analyze_probe_3c.py`，自测 5/5 通过）

    base  = ½(mean A1 + mean A2)
    Δ⁺    = mean(Bp) − base          Δ⁻ = mean(Bm) − base
    Δ_odd = ½(Δ⁺ − Δ⁻)               E  = Δ⁺ + Δ⁻   （**不除以二**）

**单侧、奇分量、偶分量必须分别报告。**

### 4.1 不确定性按**整次复放**估计

| | |
|---|---|
| `Var(Δ±)` | `σ²/N + σ²/(2M)` |
| **`Cov(Δ⁺,Δ⁻)`** | `σ²/(2M)` ⇒ **相关系数 ≈ +0.455（N=10, M=6）** |
| `Var(Δ_odd)` | `σ²/(2N)`（裸基线**精确抵消**） |
| `Var(E)` | `2σ²/N + 2σ²/M`（裸基线噪声**进来两次**） |

⚠ **两侧共享同一条裸基线 ⇒ Δ⁺ 与 Δ⁻ 相关，不得当独立处理。**
除解析式外，另做**留一条整次复放的 jackknife**；**不把帧当独立样本**。

### 4.2 ⚠ 三条禁令

1. **不得假设两侧发送量严格反对称** —— `±δa` 独立取整 ⇒ 指令层就有
   `e_cmd = c₊ + c₋ − 2c₀ ≠ 0`（实测最大 1 count = 0.01744 mrad，
   RMS 0.01051 mrad = δa RMS 的 **1.79%**）。
   ⚠ **1.79% 是输入 RMS 比，不是 IMU 偶响应的比例。**
2. **不得**用尚待验证的 `H` 扣掉这部分响应，再把剩余量称为**独立的线性验证**。
3. **`g = cos × 范数比` 会骗人** ⇒ **波形 / cos / 范数比 / g 四者分开报**。

## 5. 判读边界（**只允许这三种**）

| # | 条件 | 只能这样报告 |
|---|---|---|
| ① | 奇分量信噪 ≥ **3** | **可比较冻结模型与真实响应**；方向门槛 `cos > 0.6` |
| ② | 信噪 < 3 **或** 重复性无法可靠估计 | **本次无法判定**。⚠ **不得**归为「模型失败」，**也不得**归为「真实响应不稳定」 |
| ③ | 偶分量明显存在（`‖E‖/‖Δ⁺‖ > 0.3` **且**噪声底 < 0.3） | **只能报告「系统整体的正负非对称」**。⚠ 来源**可能包括输入量化、固件整形和机械响应**，**不能自动归因于机械非线性** |

### 5.1 ⚠ 偶分量的检出能力：**事前声明**

`σ_E = σ·sqrt(2/N + 2/M) ≥ σ·sqrt(2/M)` —— **下界与 `N` 无关**。
按借用的 σ 预演：`M=6` 时比值下界 **0.856**，**加大 `N` 降不下来**；
要让「比值 < 0.3」有判别力且 `N=M`，需 **`M = N ≈ 98`（总 ≈ 392 次）**。

> **准确表述**：**当前预算无法支持「偶分量 < 0.3」这个精度目标**，
> **不是**「任何偶分量都测不出来」—— **很大的偶响应仍可能检出**。
> `M=N≈98` 也只是按当前噪声假设把预计噪声压到 0.3 附近，
> **不等于已经具备指定检出力**。
>
> ⚠ **不得因为噪声大就抬高容忍线，最后宣称「线性通过」。**
> 噪声底高于容忍线时，只能写「**检出能力不足，无法判断是否足够小**」。

|---|---|
| **H 在这些工作条件下预测可靠** | 暂时保留简单响应模型，重点放回 **π 的训练与约束** |
