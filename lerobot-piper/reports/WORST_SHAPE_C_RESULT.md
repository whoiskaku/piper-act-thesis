# 最不利 shape error 搜索（2026-07-28）

工具：`sim/worst_shape_C.py`　输出：`outputs/probe_c/worst_shape_C.json`

---

## 0. 判据方向（先钉住，避免与上一次分解审计对读错）

本文的

```
ΔSSE = (错误分支邻域内最小 SSE) − (全局最小 SSE)
```

是**分支间隔裕度**，**越小越危险**。「最不利」= 把它压到最小。

上一次「shape/noise 分解审计」里的 ΔSSE 是**失配代价**（越大越糟）。
**两者方向相反，数值不可直接比较。**

---

## 1. 致命退化的防护（用户 2026-07-28 明确要求）

> 不能允许 shape error 包含任意的跨位姿共享线性相位斜率，否则它可以直接伪装成
> 另一个 τ 分支，搜索必然把问题做成不可辨识。

落实为**零全局线性相位斜率规范**：逐位姿相位斜率 `a_p` 强制 `Σ_p a_p = 0`。
⇒ 共享线性相位**全部归入 τ**，shape error 只保留位姿相关的斜率差。

### 参数化（14+ 维）

```
S_p(f) = exp(g_p(f)) · exp(−j·ψ_p(f)) · Rot(θ_p)

g_p(f) = c0 + c1·ν + c2·ν²  + d·u_p          平滑 log-gain（含位姿依赖）
ψ_p(f) = a_p·2πν + b1·2πν² + b2·2πν³         **非线性**相位曲率 + 位姿相关斜率
θ_p    = e0 + e1·u_p                          三轴方向偏差（含位姿依赖）
```

- `ν = f − f̄`，`u_p` = 该位姿的 φ 投影（标准化）
- **低阶多项式** ⇒ 频率二阶差分天然有界，满足「不能逐频点任意跳变」
- `b1, b2` 是**非线性**相位，全局允许——它无法伪装成纯时延

### 允许集合

`‖x/σ‖₂ ≤ r`，σ 取 B′ 实测量级：log-gain `ln3`、相位斜率 `20 ms`、方向 `15°`。

### seed 口径

- shape error 是**固定的真实系统失配**，**不对每个噪声 realization 单独优化**
- 搜索用一批 **common-random-number** seed；**另一批独立** seed 验证（防对噪声过拟合）

### 2.4 最坏条件下的排名

```
排名(随机 shape): D1 > 混合(0,1,2,5) > 混合(0,2,4,5) > 混合(1,2,5,6) > D2
```

**排名未变。** 但注意：**混合#1 在最坏条件下是三个锚点集合里最弱的一个**
（Wilson 下界 98.1% vs 另两组 98.7%），而它在**平均**口径下排第一。
⇒ 锚点集合 #1 **不应据此冻结**；见 §3。

### 2.5 边界饱和

五个设计的最坏 x* **全部顶到允许集合边界**（‖x‖ = r）。
⇒ 结论是**边界受限**的：它由 B′ 实测误差尺度决定。若真实失配大于 B′ 尺度，
必须按放大后的 r 重估，本结果不能外推。

### 2.7 定向退化探针（只放开共享线性斜率 s，其余分量 = 0）

| 设计 | s (ms) | 椭球 r | 选对率 | Q5% ΔSSE |
|---|---|---|---|---|
| D1 | 0 | 0.0 | 100.0% | 1.299e6 |
| D1 | 20 | 4.0 | 100.0% | 1.047e6 |
| D1 | 40 | 8.0 | 0.0% | 7.629e5 |
| D1 | 77 | 15.4 | 0.0% | 2.641e5 |
| D1 | 110 | 22.0 | 0.0% | 1.670e4 |
| D1 | 154 | 30.8 | 0.0% | **0.000e0** |
| 混合#1 | 20 | 4.0 | 100.0% | 3.509e5 |
| 混合#1 | 40 | 8.0 | 0.0% | 2.477e5 |
| 混合#1 | 110 | 22.0 | 0.0% | 4.911e3 |
| 混合#1 | 154 | 30.8 | 0.0% | **0.000e0** |

**这张表里的「选对率」在 s ≥ 40 ms 处归零，但那不是分支混淆。**必须分开两件事：

- **绝对 τ 精度**：判据是 `|τ̂ − τ_true| < 30 ms`。共享斜率 s 与 τ **在数学上完全等价**，
  所以 τ̂ 精确地平移 s；s = 40 ms 就必然越过 30 ms 容差。这是**正确行为，不是失效**——
  它恰好证明共享斜率就是那个**不可辨识方向**，也正是必须把它归入 τ、
  用规范从 shape error 里剔除的理由。
- **分支判别**：由 ΔSSE 衡量。s = 40 ms 时 ΔSSE 仍有 7.6e5（错误分支被强烈拒绝），
  要到 **s ≈ 110–154 ms** 才塌到零。

⇒ 正确措辞：**在当前规范和定向扰动族下，两个离散分支的 SSE 裕度约在
110–154 ms 共享相位斜率处消失。**

> 它**不是物理时延的置信区间**。允许共享线性相位后，shape 与 τ 本来就不可分
> ——这正是必须施加规范的原因。

### 2.8 规范在 r = 1 处**并不吃紧**（必须如实记录）

| 设计 | r | 规范开 Q5% | 规范关 Q5% |
|---|---|---|---|
| D1 | 1.0 | 1.620e5 | 1.615e5 |
| 混合#1 | 1.0 | 5.927e4 | 5.791e4 |

两者差 <1%。⇒ **在 B′ 误差尺度上，保护选对率的不是规范，而是 31× 的退化距离。**

规范仍然必须保留——它是防止搜索**平凡取胜**的方法论保障（否则最不利搜索会
把问题做成不可辨识，得出无意义的 0%）——但**不能声称"规范撑住了选对率"**。

> 附带修正：先前把「关闭规范、r = 4 时选对率归零」当作规范必要性的证据是**错的**。
> r = 4 时 log-gain 分量可放大到 e⁸ 量级，那是**增益炸毁**，与共享斜率退化无关
> （同 r 下的定向探针 s = 20 ms 仍是 100%、ΔSSE 1.0e6）。该对照已作废，
> 改用 §2.7 的定向探针。

## 3. 结论

1. **五个设计在最坏 shape error 下均通过放行门槛**（两分支各自 Wilson 下界 98.1–98.7% ≥ 95%）。
   搜索批与验证批一致（差 1.4%）⇒ 未对噪声过拟合。
2. **裕度损失由 shape error 主导**（shape-only 已达联合值的 106–122%，noise-only 高 7–8 倍），
   与上一次分解审计一致。
3. **最坏条件下锚点排名未变。** 混合#1 的 Wilson 下界 98.1% 低于另两组的 98.7%，
   但差别只是 **300 个 seed 里多错 1 个**，不具统计意义——
   **不能据此改选，也不足以冻结 #1。**
4. **最坏误差全部顶到允许集合边界** ⇒ 结果是**边界受限**的，由 B′ 实测误差尺度决定。
   若真实失配超出 B′ 尺度，必须放大 r 重估，本结果不可外推。
5. 在当前规范和定向扰动族下，两个离散分支的 SSE 裕度约在 **110–154 ms 共享相位斜率**
   处消失（不是 40 ms，见 §2.7）。**这不是物理时延的置信区间。**

### 本结果关闭了什么、没关闭什么

- **关闭**：「混合四锚点能否辨别时序分支」这一**替代模型**门禁。
- **未关闭**：C 的整体放行。真实层级 L0–L3、group-LOPO、holdout 验收都还没做。

### 对下一步的影响

- 混合四锚点**在最坏情况下过了门槛** ⇒ 按用户既定分支，**不需要**先去测五或六个宽带锚点。
- 但 §2.6 显示最坏误差主要走 **log-gain** 通道，而 log-gain 的允许尺度 `ln3`
  是从 B′ 实测误差直接搬过来的。这个尺度是否适用于 C 的静止/慢动工况**尚未验证**
  ⇒ 建议在 §3.2 接入真实 L0–L3 时一并做 r 的敏感性（r = 1, 2）。
- 锚点集合 #1 保持**候选、未冻结**。

**下一步**：接入真实 L0/L1/L2/L3 与 group-LOPO（用户既定顺序 3.2）。
