# 完整采集方案对比：v1（原 8 s）vs **v2（分阶段进场 + 锚点多窗）**

工具 `sim/design_compare_C.py`。v2 依用户 2026-07-29 提议起草，**作为默认候选**。

16 train 条件，宽带锚点 = 物理位姿组 (1,2,5,6) → 序号 **[2, 4, 14, 15]**。
慢动频率 {0.25, 0.40, 0.80} Hz ⇒ 最慢周期 4.0 s。

---

## 1. v2 时间线

```
① 单向预进场（**dither 尚未启动**）      2.0 s
② 到目标后稳定                          1.0 s
③ dither 从**固定相位**渐入              1 个周期
④ warm-up                               2 个周期
⑤ A: ≥3 个完整慢动周期的评估段
   B: n_win × 探针窗(2.0 s)，窗间 ringdown 1.5 s
```

**判据分工**（v2 的要点）：
**C3 只评价 ① 的编码器净行程与方向**；**C2 评价 ④ 之后的周期相位**。
这样 dither 幅值大于进场偏置也不会让 C3 标签失效。

## 2. C3：**不需要加大进场偏置**

| dither | v1 净行程 | v2 净行程 | v1 | v2 |
|---|---|---|---|---|
| 1.0° | 0.50° | **1.50°** | ✓ | ✓ |
| 2.0° | **0.00°** | **1.50°** | **✗** | ✓ |

v1 里 dither 与偏置同时渐入，2.0° 的位姿净行程被淹没到 0（pilot 实测 P3 为 0.093°）。
v2 因 ① 阶段 dither 未启动，**净行程恒等于偏置 1.5°**，远超 0.5° 要求。

> **关键结论**：把偏置统一加到 >2° 是不必要的，而且会侵蚀 P2/P3 的边界余量。
> 拆时间线就解决了。

## 3. ⓪ 安全余量：注入段不变，进场段**更安全**

注入窗的位姿/频点/幅值/偏置都不变 ⇒ **residual margin 逐位姿不变**。
进场段 v1 是 dither 与偏置叠加，v2 分开：

| 锚点 | 进场段最大偏移 v1 | v2 |
|---|---|---|
| 位姿序号 2 | 2.50° | **1.50°** |
| 位姿序号 4 | 2.50° | **1.50°** |

## 4. 序列时长与机时

| hz | v1 全臂 | v2 A | v2 B(1 窗) | v2 B(3 窗) |
|---|---|---|---|---|
| 0.25 | 8.0 s | **27.0 s** | 17.0 s | 24.0 s |
| 0.40 | 8.0 | 18.0 | 12.5 | 19.5 |
| 0.80 | 8.0 | 10.5 | 8.8 | 15.8 |

A 必须覆盖 ≥3 个完整慢动周期 ⇒ 0.25 Hz 时评估段 12 s（与用户估计一致）。

| 方案 | 条数 | 总机时 |
|---|---|---|
| v1 原方案（单窗） | 128 | **59 m** |
| **v2 锚点 3 窗（单 session 内）** | 128 | **80 m** |
| v2 锚点跨 3 session（每 session 1 窗） | 192 | **118 m** |

未含 5 个 holdout：同协议再 +40 条。

## 5. γ² 可行性（v2 的主要收益）

| | v1 | v2 |
|---|---|---|
| 锚点窗数 | 1 | **≥3** |
| γ² | **无法计算** | 可算 |
| 相位 / 全局 τ | 不可判 | 可判 |
| 窄带条件 | 单窗 | 单窗（只供位姿依赖与层级拟合，**不报单点 γ²**） |

多窗在拟合中按 **pose/session 聚类**，不作独立行 ⇒ 锚点不获过大权重。

## 6. 采纳 v2 时必须同步修改

- `session_index` 改为**必填**（pilot 回填 0，完整采集禁止 `None`）
- **C2 阈值固定为 2°**（pilot 最大 spread 1.04° 的保守上限）
- holdout 用与同类 train 条件**完全相同**的协议采集，但仍只落盘封存
- **B+ 与 B− 使用完全相同的窗口相位表**，符号严格相反
- 重算 ⓪ / φ·Jacobian / 时长 / 能量 / 机时；更新 hash·tag·manifest；**重跑 dry-run**
- 同位姿 A 的安全门评估段 ≥3 个完整慢动周期（当前 pilot 只有 2–5 个，UCB 偏窄）

## 7. 推荐

**采用 v2，锚点窗数按 session 数决定**：

- 若能跨 ≥3 个 session 采集 ⇒ 每 session 1 窗（118 m），
  同时满足"四锚点每 session 重复"这条防混杂要求 —— **首选**。
- 若只能单 session ⇒ 锚点单次内 3 窗（80 m），但 session 漂移与位姿效应无法分离，
  跨 session 泛化仍不可验证。

代价：机时 59 m → 80–118 m。换来的是 **γ²、相位与全局 τ 变得可判**，
以及 C3 对全部位姿有效。
