## 门禁 A · 冻结与身份（上机前，逐条留痕）

| 项 | 要求 | 落盘字段 |
|---|---|---|
| A1 | commit hash + tag `c-pilot-v1`，工作区干净 | `git_hash`, `git_tag`, `git_dirty=false` |
| A2 | 探针序列 hash 与冻结值一致 | `seq_hash` |
| A3 | 位姿表（16 train）逐条 q2/q3/grip/dither/hz 与冻结值一致 | `pose_table_hash` |
| A4 | 随机种子（位姿顺序、B± 顺序）来自**预存 seed**，不现场生成 | `seed_order`, `seed_sign` |
| A5 | session 顺序与计划一致 | `session_id`, `session_index` |
| A6 | **2 mrad 实际发送峰值**复核：`max|u|` 逐关节 ≤ 2 mrad | `u_peak_per_joint` |
| A7 | **实际发送能量** `Σu²Δt` 与冻结值相对差 <1% | `seq_energy`, `energy_rel_err` |
| A8 | **单关节约束**：每条只注入一个关节，其余关节注入分量恒为 0 | `injected_joint`, `other_joint_max` |

任一项不符 ⇒ **不上机**。

## 门禁 ⓪ · 安全余量（每位姿、每窗口，A 臂实测后重算）

计算对象必须是**预移动 + 慢速往复 + 探针叠加后的完整指令**，不是探针单独。

```
residual_margin = 命令余量 − A 实测跟踪误差 p99 − 安全预留
                > 0          （逐关节、逐窗口）
```

| 项 | 要求 |
|---|---|
| ⓪1 | 位置：到**可达范围**（非安全限位）的余量，扣 A 跟踪 p99 与安全预留后 > 0 |
| ⓪2 | 速度：不越既有经验包络 |
| ⓪3 | **增量加速度**：不越既有经验包络 |
| ⓪4 | **削顶**：编码器停滞（<0.5°/s）+ 处于/越过可达边界 + 命令仍在动（>1°/s）⇒ 判削顶 |
| ⓪5 | **停滞**：窗内编码器速度持续为零而命令在动 |

⓪ 必须**用本次 A1 的实测数据重算**，不沿用历史预估。任一窗口不过 ⇒ 禁用该窗口。

## 门禁 B · 记录链路

| 项 | 门槛 |
|---|---|
| B1 | 100 Hz 缺样率 **< 2%** |
| B2 | 无时间回退、无重复时间戳 |
| B3 | 最大采样间隔 ≤ 冻结门槛（沿用 B′ 值） |
| B4 | 记录**晶振 ppm**（时钟映射斜率偏离 1 的量） |
| B5 | 记录**传输延迟 p95** 与 `t_send_span` |
| B6 | 每条运行保存**原始 device / host / send 三套时间戳**，以及时钟映射残差 |

## 门禁 C · 起始状态一致性

| 项 | 要求 |
|---|---|
| C1 | 预移动后**六关节 + 夹爪**位置一致（阈值冻结） |
| C2 | **慢动往复相位**一致 |
| C3 | **进场方向**一致（所有位姿从同一侧接近，保证背隙状态可重复） |
| C4 | B± 与其对应 A 的起点差异在冻结阈值内 |

## 门禁 D · 信号验收（奇分量）

| 项 | 门槛 |
|---|---|
| D1 | 奇分量**功率 SNR ≥ 3** ⇒ 链路门（低于此：停止继续采集并诊断，非急停） |
| D2 | 奇分量**功率 SNR ≥ 5** ⇒ 校准资格门（Ĝ 更新的必要非充分条件） |
| D3 | 报**每频点、每轴**的相干度 γ² 与**复 FRF** |

> **单幅值只能写「奇对称」，不能写「幅值线性」。** 幅值线性必须等 2/4 mrad 对比。

## 门禁 E · 偶分量与漂移（三口径并列，分开报告）

| 口径 | 内容 |
|---|---|
| E1 | **基频**偶分量 |
| E2 | **差频**偶分量 |
| E3 | **宽带**偶分量（插值无关） |

分开报告三类漂移，不合并：

- **A 前后漂移**（同 session 内首尾 A 的差）
- **B± 偶分量**（非线性/不对称）
- **session 漂移**（跨 session 的共同项）

## 门禁 F · 物理停止门（任一触发即停）

**相对量**（B 相对同位姿 A）：关节速度、关节加速度、**gyro 增量**超冻结倍数。

**绝对护栏**：位置/速度/加速度绝对上限、关节限位、异常声音、意外接触、
IMU 数据陈旧（stale）、时钟异常。

## Pilot 执行（三个 train 位姿，逐位姿分析）

| 顺序 | 位姿 | 选取理由 |
|---|---|---|
| P1 | **中心宽带锚点** | 最典型、SNR 最有把握 |
| P2 | **residual margin 最小的宽带锚点** | 安全余量最不利者 |
| P3 | **一个窄带非锚点** | 覆盖窄带路径 |

每个位姿的臂序：`A → B+ → B− → A`（B± 顺序按预存 seed 交替）。

> **每个位姿完成 A/B±/A 后立刻分析，不连续跑完再检查。**
> 出现报警、异常振动、越包络或记录失败 ⇒ 立即停止。

pilot 只允许得出三类结论：

1. 100 Hz 记录与统一时钟链路是否可靠
2. 2 mrad 响应是否可见、是否奇对称
3. 是否存在削顶、明显非线性或安全余量问题

**不得**据 pilot 宣称相位/时延/幅值线性已验证。

## 完整采集 runbook（pilot 通过后）

1. **四个宽带锚点在每个 session 都重复** —— 否则位姿效应与 session 漂移混杂，
   这类混杂事后加 Monte Carlo trial 补不回来。
2. 其余位姿按**预存 seed** 随机化顺序（不现场生成）。
3. **B+/B− 顺序交替**。
4. **A 对照穿插**在位姿序列中，不只放首尾（B′ 第 1 轮门禁 ⑤ 的失败就暴露了
   「A 在首尾、B 在中间」的结构性弱点）。
5. **holdout 文件仅采集并封存**，不进入拟合、不进入模型选择。
   代码层由 `assert_train_only` 拦截。

## 采集后

- 用 **train 数据**做临时 Ĝ 拟合，结果标为**探索性版本**。
- 临时 Ĝ 拟合前，先看一次修复噪声后的 100 trial 结果（后台运行中，不阻塞 pilot）。
- 若上 DAgger：只做**低幅值、小批量** pilot，不直接扩大到正式闭环实验。
