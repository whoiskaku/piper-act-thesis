# 结果：`pi-g2env-v1` 真机 A/D（2026-09-16 采集）

**结论：在冻结 G-2 环境里训出来的 π，迁移到真机后显著变差。**

> **`D − A` = +25.0%，t = +5.58，p = 5.1×10⁻⁶，改善集数仅 6/30**

事前判读规则的第三种情形：**`> 0`（补反了）⇒ 方向也错，**G-2 的增量通道完全不可用**。**

## 1. 这个结果为什么可信

### 1.1 所有检验一致，且区间不含 0

| 检验 | 结果 |
|---|---|
| **配对 t（事前主判据）** | **+25.0%**，p = 5.1×10⁻⁶ |
| Welch 非配对 t | p = 5.7×10⁻⁷ |
| Mann–Whitney U | p = 9.5×10⁻⁶ |
| Wilcoxon 符号秩 | p = 6.9×10⁻⁶ |
| 符号检验（6/30 改善） | p = 0.0014 |
| **bootstrap 95% CI** | **[+15.5%, +35.3%]（整体在 0 以上）** |
| 采集位协变量回归 | +25.0%，p = 2.9×10⁻⁹ |

对比 C 臂那次（−8.0%，仅主判据过线、bootstrap 含 0），**本次是无歧义的**。

### 1.2 漂移不解释它

`A×15 → D×15 → D×15 → A×15` 使两臂平均采集位**完全相同**（各 30.5）。

| | 第一块 | 第二块 | |
|---|---|---|---|
| A | 0.09152 | 0.06730 | **−26.5%** |
| D | 0.09705 | 0.10141 | +4.5% |

⚠ 本次会话漂移方向与 ab5 **相反**（ab5 是 +27%，这里 A 下降 26.5%）
⇒ **漂移方向不可预设**，平衡设计是必需的，不是保险。
把采集位作为协变量控制住后，臂效应仍是 **+25.0%（p = 2.9×10⁻⁹）**。

### 1.3 「训练没跑起来」已被事前排除

π 在 G-2 环境里、**用真前向**（非线性化）在**留出集**上降 **+15.8%**
（环境内解析参照 +15.2%）。所以本次失败**只可能是迁移失败，不是学习失败**。
这正是这个实验被设计出来要区分的两件事。

## 4. ⚠ 事前预测偏了，而偏差本身是个发现

事前用真机已验证的 `H`（β=0.955）预测 **`D−A` = −0.1%**，实测 **+25.0%**。
方向（π 没用）对了，**量级完全不对**。

统一口径（`ALIGN_L=3` 对齐）下反解：

| | 值 | 相对 A |
|---|---|---|
| A（裸） | 0.05777 | — |
| D 实测 | 0.07421 | +28.5% |
| D **扣掉 `H` 预测的 δa 响应** | 0.08589 | **+48.7%** |

扣掉 `H` 说的那份「贡献」反而**更差** ⇒ **`H` 认为 π 的 δa 在帮忙，真机说它在帮倒忙。**

### 假说（**未证**）：`H` 的位形平均，对**结构化** δa 失效

`H` 正确预测了 C 臂（离线 −7.6% vs 实测 −8.0%），却预测不了 D 臂。两者的 δa 不同：

| | C 臂 | **D 臂（π）** |
|---|---|---|
| RMS | 0.54 mrad | **2.15 mrad** |
| 峰值 | ~5 mrad | **10 mrad（触界）** |
| 结构 | 由 `H` 解出 | **指令的函数 ⇒ 与臂位形相关，集中在 chunk 接缝** |

`H` 是用**带限白噪声**辨识的**单一核、对臂位形取了平均**（这是此前已标注
「**位形依赖从未检验**」的短板）。白噪声会把位形依赖平均掉；而 π 的 δa
系统性地只打在特定位形上，于是 `H` 的平均核对它失准。

⚠ 这是**假说**，不是已证机制。其他候选：触界处的饱和非线性、单纯的幅度外推。
要分离需要**按位形分组的探针实验**。

## 5. 判读

1. **G-2 的增量通道（对 δa 的反事实响应）不可用于训练可迁移的补正策略。**
   这是事前写死的第三种情形，且证据无歧义。
2. **「绝对保真度够、增量保真度不够」这个论断得到真机确认**，并有了倍数：
   G-2 只需 0.13 mrad 就能抵消同一面墙，真机需要 0.85 mrad（**约 7×**），
   而 `Δ_G` 与 `Δ_H` 的 `cos` 仅 **0.12**。π 学的是前者，发到真机上就是 +25%。
3. **`H` 的适用范围比原先记录的更窄**：它在**结构化、与位形相关**的 δa 上失准。
   这一条独立于 π 的成败，**对 C 臂那条线也是新的限制**。
4. 部署管线（零空档、逐帧一致性、安全约束）**全部正确** —— 失败是方法层面的，不是工程层面的。
