## 2. 设计

### 2.1 箱体与顶点（沿用 v2 §2 的参数化，便于可比）

```
x₁ = A_prox /2mrad ∈ [−1,1]      x₂ = A_wrist/2mrad ∈ [−1,1]      x₃ = (τ−6)/4 ∈ [−1,1]
δa_G(k) = A_G · v_G · exp(−k/τ)          v_G = d_G / max(‖d_G‖∞, 2mrad)
```

8 个顶点：`A_prox, A_wrist ∈ {−2, +2} mrad`，`τ ∈ {2, 10}` 帧。

| 顶点 | A_prox | A_wrist | τ | 近端接缝 |
|---|---|---|---|---|
| (−−−) | −2 | −2 | 2 | 强化 |
| (−−+) | −2 | −2 | 10 | 强化 |
| (−+−) | −2 | +2 | 2 | 强化 |
| (−++) | −2 | +2 | 10 | 强化 |
| (+−−) | +2 | −2 | 2 | 平滑 |
| (+−+) | +2 | −2 | 10 | 平滑 |
| (++−) | +2 | +2 | 2 | 平滑 |
| (+++) | +2 | +2 | 10 | 平滑 |

`‖v_G‖∞ ≤ 1` ⇒ `|δa| ≤ 2 mrad` 在顶点上仍恒成立 ⇒ **安全门 §6 不需任何改动**，
`sat_pct` 仍应恒为 0。

### 2.2 模型：必须是完整 2³，不得用可加模型

```
log L ~ x₁ + x₂ + x₃
      + x₁:x₂ + x₁:x₃ + x₂:x₃
      + x₁:x₂:x₃
      + session + block/time
```

**为什么 τ 必然与两个幅值交互**（不是经验判断，是参数化的直接后果）：

1. 脉冲的累积冲量 `Σₖ A·exp(−k/τ) ≈ A·τ` —— 是**乘积**，纯交互项。
2. `A_prox = A_wrist = 0` 时 `δa ≡ 0`，**与 τ 完全无关** ⇒ τ 的主效应在该处为 0。
3. 两组共用**同一个** τ ⇒ τ 同时与 `x₁`、`x₂` 交互。

⇒ 可加模型 `x₁+x₂+x₃` 是**构造上就错的**（misspecified by construction），不得使用。

**等价的饱和形式**：把 8 个顶点当作**一个 8 水平的分类因子**。这与完整 2³ 编码是
同一模型的旋转（都是 8 个参数、饱和）。
- 分类形式用于**选择与置信界**（不假设任何函数形式）
- 因子编码仅用于**解读**（哪个主效应/交互在动）

### 2.3 中心点是裸 ACT，τ 在那里无意义

`x₁ = x₂ = x₃ = 0` ⇒ `A_prox = A_wrist = 0` ⇒ `δa ≡ 0` ⇒ **就是裸 ACT**。
且 τ 在整个 `A = 0` 平面上**不可识别**。

因此中心点**不是**普通的响应面中心点。后果，逐条写明：

| 后果 | 说明 |
|---|---|
| 中心重复能做什么 | 只能检验「8 顶点均值 vs 中心」这**一个**总体曲率对比 |
| 中心重复**不能**做什么 | **不能证明整个箱体线性**；只是 1 个自由度的整体检验 |
| Box–Wilson / 中心复合设计（CCD）**不能直接套用** | CCD 的中心点与 τ 轴上的星点都落在 `A=0` 的退化面上，在那里 τ 不可识别 ⇒ 标准 CCD 在本参数化下**病态** |
| 8 顶点覆盖范围 | **只有 8 个顶点**。不能排除箱体**内部**存在更优点 |

⇒ **v3 明确只是筛选实验，不是响应面优化。** 内部最优点的搜索需要显式曲率模型 +
扩展设计（且需先解决 `A=0` 退化面的重参数化），**不在 v3 范围内**。

## 3. 样本量与排布

### 3.1 样本量 = **40 集**（已定 2026-08-24）

**设计 A：8 顶点 × 4 + 8 集裸 ACT，分两会话各 20 集。**

MC 依据（`σ_ep = 19.9%`，由实测 `SD_pair = 28.2%/√2` 得）：

| 设计 | 集数 | SE | 选中真最优 E=15% | E=20% | E=30% |
|---|---|---|---|---|---|
| **A（采用）** | **40** | **12.2%** | **50%** | **66%** | **91%** |
| C | 48 | 11.1% | 54% | 71% | 94% |
| D | 64 | 9.5% | 62% | 80% | 98% |

C 多 8 集只换来 4pp 命中率，不采用。

> **备选「32 集 16 matched block」已否决**，理由是它**更差而非更小**：
> 块内差把每观测方差翻倍（`σ√2`），而共享对照把 8 集裸 ACT 汇总使用
> ⇒ `SE` 19.9% vs 12.2%，命中率 33% vs 50%。若将来确需压到 32 集，
> 应改结构（8 顶点×3 + 8 裸，`SE` 13.7%），**不得**改用 matched block。

### 3.2 送确证的候选个数 = **Top-1**（已定 2026-08-24）

只把**排名第一**的顶点送入确认阶段。

**理由（决定性）**：Top-2 会让**确认阶段自身产生多重性** —— 两个候选都按
**未校正**的 `p < 0.05` 判定，等于把 H1 的族错误率打穿。若要送 2 个，
必须在确证阶段做多重性校正，那会把 §5 判据 1–4 全部改掉，而 §5 是沿用
v2 原样不改的。

（记录：Top-2 本可把 E=15% 的命中率从 50% 提到 70%，但代价是确证阶段的
统计有效性，不划算。）

#### 裸 ACT 位置 —— 调整案

**原案**（裸 ACT 在第 1、6、11、16 个顶点之后）有三个缺陷：

| # | 缺陷 |
|---|---|
| ① | 会话**以顶点开始** —— 起始热瞬态没有裸 ACT 锚定 |
| ② | 首个裸在第 1 个顶点之后，间隔 1/5/5/5 不均 |

```
B C C C C C B C C C C C C B C C C C C B          (B = 裸 ACT, C = 顶点)
1 2 3 4 5 6 7 8 9 ...    14 ...          20
```

- 每会话 4 裸 + 16 顶点 = 20 集
- 顶点间隔 5/6/5，近乎均匀
- **每个顶点都夹在两个裸之间** ⇒ 漂移校正全部是**内插**，无外推
- 会话**以裸 ACT 开始并以裸 ACT 结束** ⇒ 起止水准都被锚定

### 3.4 失败处理 = **同一逻辑 slot 原位重跑**（已定 2026-08-24）

沿用 v2 §6 全部六条（含 ⑥-5b 的**按帧数判据**：`0 帧崩` 原地重启、
`≥550 帧后崩` 本集有效、`1–549 帧` 作废）。

**⑥-5 的 v3 版本**：v2 的「整对作废」针对 SPSA 的 `θ⁺θ⁻` 对，v3 没有对。
改为 —— **A 类技术故障的那一集作废，并在同一逻辑 slot 原位重跑**
（同会话、同 slot 编号、同顶点）。设计平衡与时序结构都不受影响。
在册/作废分离记账沿用 v2。

#### 由此确定的漂移协变量（重要，避免事后歧义）

因为重跑是**原位**的，作废集不进入分析 ⇒ **对被分析的集，`slot` 编号
就等于会话内的实际采集序号**。故：

- **主分析的漂移协变量 = `slot`**（`1…20`，会话内）
- 时间戳仍全部落盘。若某个 slot 的重跑链导致墙钟间隔异常拉长，
  则**另做一次以实际经过时间为协变量的敏感性分析**并一并报告

#### ⑥-6（B 类候选失败）在 v3 的含义【待确认】

v2 ⑥-6：「保留记录、**判否**、禁止删掉重跑」。直接继承到 v3 即为 ——
**任何出现 B 类失败（`sat>1%` / NaN / 急停 / 异常碰撞）的顶点，
其记录保留并进入描述性模型，但该顶点被取消候选资格**（不得被选为 Top-1）。

这是 v2 冻结规则的直接继承，不是新发明；但因为它是选择规则的一部分，
**标为待确认**，可否决。

## 4. 分析

### 4.1 筛选

拟合 §2.2 的饱和模型（含 `session` 与 `block/time`）。以 8 个顶点 vs 裸 ACT 对照做
**Dunnett 单侧检验**（k=8 个处理 vs 1 个对照，`α = 0.05`，临界值 ≈ 2.45）。
Dunnett 而非 Bonferroni：本设计正是「多处理 vs 单一对照」，Dunnett 利用共享对照的
相关结构，比 Bonferroni 更有功效。

### 4.2 候选选择规则（已定 2026-08-24）

- **选择统计量**：顶点的 `log L` 单元均值（经对照与 `session`、`slot` 调整后）
- **取最小者为候选。**
- **无 3% 平局带** —— 不设容差区间，严格取最小
- **无 Dunnett 入围门槛** —— 不要求候选自身 `p < 0.05` 即可进入确证阶段
  （设门槛会在真实效应仅 15% 时经常误停）
- **精确数值平局**（测度为零，仅为代码确定性）：取枚举顺序
  `(−−−) (−−+) (−+−) (−++) (+−−) (+−+) (++−) (+++)` 中**下标较小**者

Dunnett 单侧检验仍然计算并报告（用于 §4.3 的负结论界），但**不作为入围门槛**。

### 4.3 负结论能写到什么程度（**比预想更严，必须照此写**）

全零情形下，8 顶点的**同时单侧下界**（Dunnett，`α=0.05`）给出
「所有顶点的真实改善 `< B`」：

| 设计 | 集数 | B | 能排除 15%？ |
|---|---|---|---|
| A | 40 | **37.4%** | ✗ |
| C | 48 | 34.8% | ✗ |
| D | 64 | 30.7% | ✗ |
| — | 96 | 26.5% | ✗ |
| 要 `B < 15%` | **≈ 414** | 15% | 需 `SE < 4.2%` |

界 `≈ 3.87·SE`（多重性使 `min` 再下移 1.42·SE，Dunnett 临界值另加 2.45·SE）。

⇒ **角点筛选在任何现实规模下都不能作出 15% 水平的负结论。**

| ✗ 不得写 | ✓ 只能写（以设计 A 为例） |
|---|---|
| 「排除整个箱体达到 15%」 | — |
| 「排除这 8 个顶点达到 15%」 | 「排除这 8 个顶点达到 **37%**（同时单侧 95%）」 |
| 「接缝脉冲族无效」 | 「本筛选未在这 8 个顶点上发现达到确证门槛的候选」 |

15% 水平的否定**只能**来自确认阶段（§5）对**单个**预先指定 θ 的检验 ——
无多重性，`SE = 5.1%`，单侧 95% 界 `8.4% < 15%` ⇒ 可以排除。

## 5. 确认阶段 —— 唯一能下结论的一步

最佳顶点（**唯一**候选，见 §3.2）**只是候选**。随后用**全新的 30 组 matched A/B**
（60 集）确证，判据、口径、matched 定义、安全门**全部沿用 v2 §5/§6 原样不改**：

1. `median(r) ≥ 15%`，`r = 1 − L_B/L_A`
2. 单样本 t 检验 `p < 0.05` 双侧，方向为改善
3. `≥ 20/30` 个 block 正向（H0 下 `α = 0.0494`）
4. 两会话各自中位数 `> 0`（各 15 block）
5. 安全门通过

三档解读沿用 v2 §5。**筛选阶段的数据不得进入确证阶段的统计。**
