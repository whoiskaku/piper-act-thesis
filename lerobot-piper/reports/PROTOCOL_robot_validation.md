# ③a — δa 复放探针（先做，因为它解锁 ③b 的参数）

## 目的（一句话）

**直接测出真机对 δa 的响应是 Ĝ 预测的几倍（增益 g）。**
这是 Ĝ 唯一从未被直接验证的部分——日志里 δa 恒为零。

## 为什么必须先做

1. **它是命门**：整个方法建立在"Ĝ 的增量准"之上。间接证据有四条（方向 0.758 /
   线性度 0.0% / 极点 3.68≈3.7Hz / ε 尺度传递 ≥1），但**没有一条是直接的**。
2. **它解锁 β**：`WORKLOG §8` 的表按 g 给出操作点——
   g≈1.0–1.1 → 换 β=100（pp2 +4pp）；g≈1.3–1.5 → 留 300；g>1.9 → 连 300 都要重评。
   **不先测 g，③b 就可能跑在错误的操作点上。**

## 设计

**三次复放同一段固定指令序列**（开环，不跑 ACT）：

| 次 | 内容 | 得到 |
|---|---|---|
| A1 | 裸指令 | 基线 |
| **B** | 裸指令 + **已知的 δa 探针** | A1 与 B 之差 = **真实增量** |
| A2 | 裸指令（重复 A1） | **复放噪声底**（A1 与 A2 之差）|

**判据前提**：`‖B − A1‖ 必须显著大于 ‖A2 − A1‖`，否则信噪不足，需加大探针或增加重复。

## 探针 δa 的设计

| 项 | 值 | 理由 |
|---|---|---|
| 幅度 | **5 mrad**（ε 的 50%）| 大到能压过复放噪声，小到仍在已认证的安全区 |
| 形态 | **单帧脉冲**，每 2 秒一发，各关节轮流 | 脉冲响应可直接与 Ĝ 的核逐点对照；间隔 2s > 800ms 尾巴，互不干扰 |
| 关节 | j2, j3, j5（墙的主载体）| 优先测最相关的；有余力再补 j1/j6 |
| 符号 | 正负各一半 | 顺带验奇对称性（线性度的直接检验）|
| 静止段 | **不发**（still-gate 逻辑同部署）| 那里传递增益只有 0.574，测不准 |

## 执行

```bash
# 复放脚本（待写: sim/replay_probe.py），用 BCORR_MODE=record + 外部注入 δa
# 或直接用 control_robot 的 replay 模式 + 一个固定 δa 序列文件
BCORR_LOG=outputs/probe/A1.json  <裸复放>
BCORR_LOG=outputs/probe/B.json   <加探针复放>
BCORR_LOG=outputs/probe/A2.json  <裸复放>
```

**每次 3 条 episode**（同一段轨迹），共 9 次复放 ≈ **25 分钟**（含复位）。

## 分析（脚本待写：`sim/analyze_probe.py`）

1. **对齐**：三次复放按指令帧对齐（同一序列，无 ACT 随机性）；
2. **噪声底**：`n = RMS(A2 − A1)`；
3. **真实增量**：`Δ_real = B − (A1+A2)/2`（用两次裸跑的均值降噪）；
4. **模型预测**：`Δ_model = Ĝ_δ[δa_probe]`（用 `g_model.increment_ref`）；
5. **增益** `g = argmin_g ‖Δ_real − g·Δ_model‖²`，即 `g = ⟨Δ_real, Δ_model⟩ / ‖Δ_model‖²`；
6. **方向** `cos = ⟨Δ_real, Δ_model⟩ / (‖Δ_real‖‖Δ_model‖)`；
7. **逐关节 / 逐轴 / 逐滞后**拆开报（不只报一个总数）。

## 判据（预注册，先于数据）

| # | 判据 | 阈值 | 不过怎么办 |
|---|---|---|---|
| ① 信噪 | `‖Δ_real‖ / n` | **> 3** | 加大探针到 8mrad 或增加重复次数 |
| ② 方向 | `cos` | **> 0.6** | Ĝ 的响应方向有问题 → 回去查辨识 |
| ③ 增益 | `g` | 报告值，**不设通过线** | 按 §8 的表选 β |
| ④ 线性 | `‖Δ(+5) + Δ(−5)‖ / ‖Δ(+5)‖` | **< 0.3** | 真机在 ε 尺度非线性 → 增量诀窍的前提动摇 |

**②或④不过 = 方法的根基有问题，必须停下来重新审视 Ĝ**，而不是继续 ③b。

## 产出

- **一个数字 g**（含逐关节分解）→ 直接决定 β
- **一张图**：Δ_real vs Δ_model 的脉冲响应叠图 —— **这是老师"Ĝ 到底准不准"的终极答案**，
  而且是他要的形式（波形，不是指标）
- 若 g 与四条间接证据一致 → **增量诀窍从"论证"升级为"实测"**

# ③b — 三臂 A/B（终审）

## 目的

在**部署形态**下比较三条腿，回答"这个方法在真机上到底有没有用"。

## 三臂

| 臂 | 命令 | 修什么 |
|---|---|---|
| **A** 裸 ACT | 不设 `BCORR_CKPT` | — |
| **B** 逆算前馈 | `BCORR_MODE=ff` | 滞后 + 边界续接（**= 先生的逆算案**）|
| **C** 本方法 | `BCORR_MODE=full` | 上述 + π 的实时残余补正 |

```bash
export BCORR_CKPT=outputs/p2_pi/pi_v1_s0.pt
export BCORR_CALIB=outputs/p2_labels/<tag>/manifest.json
export BCORR_LOG=outputs/ab/<arm>_<ep>.json
BCORR_MODE=ff    python lerobot/scripts/control_robot.py ...   # B
BCORR_MODE=full  python lerobot/scripts/control_robot.py ...   # C
```

**语义**：`B − A` = 先生方案的效果；**`C − B` = 反馈的净增值**。

## 集数与随机化

| 项 | 设置 | 理由 |
|---|---|---|
| 任务 | **insert 优先**，pp2 次之 | 效果强 3 倍且精度敏感；机时不足时先保 insert |
| 每臂集数 | **10** | 配对检验下足以检出 ~5pp 差异 |
| 顺序 | **块随机 A/B/C 轮转**，不是先跑完 A 再跑 B | 抵消热漂移、磨损、光照等时间效应 |
| 初始位姿 | 三臂**同一组随机种子**（配对设计）| 大幅降低方差 |
| 盲法 | 分析脚本读文件名前**先打乱标签** | 防止无意识偏袋 |

总计 3 臂 × 10 集 × ~60s ≈ **30 分钟纯执行**，加复位/重试约 **90 分钟**。

## 判据（预注册）

**主判据**（对应老师的度量）：
> 与 ideal 的**带通 gap 能量**（0.5–9Hz，剔接触帧，**分任务**）

- 统计：**配对 t 检验**（同初始位姿配对），报效应量与 95% CI
- 通过线：**C 显著优于 A**（p<0.05）且 **C ≥ B**（不劣于逆算案）

**副判据**（同等重要，用于确认无副作用）：

| 项 | 期望 |
|---|---|
| 任务成功率 | **C 不低于 A**（不得为了压振动而牺牲任务）|
| ‖δa‖ / 饱和率 | 与离线一致（≈1.1 mrad，sat≈0）|
| gate 触发率 | 与离线一致 |
| 异常计数 | stale / NaN = 0 |

**预注册的淘汰条款（重要）**：
> 若 **C − B ≈ 0**（π 的净增值不显著），**我们自己砍掉 π，保留 FF 层毕业**。
> 这不是认输——这是对「それっぽい指標じゃ意味がない」的正面回应：**我们敢让真机投票。**

## 首跑核对清单（`b_correction_deploy.py` 顶部同款）

1. `observation.state` 单位确为 mdeg（转 rad 后 |q| < 3.2）
2. **IMU 标定 R 用当日 rollout 重算**（安装可能变动）
3. ideal 渲染耗时 < 50ms（实测 32ms，但换机器要复核）
4. 前 16 帧 δa 恒为 0（暖机 gate）
5. 全程 `sat_pct ≈ 0`、gate 触发率与离线一致
6. **先跑 `BCORR_MODE=record`**（只观测不施加）一集，确认统计正常再开 `full`
