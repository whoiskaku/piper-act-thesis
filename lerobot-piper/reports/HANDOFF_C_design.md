### 1.3 结构（`AUDIT_G_structure.md` §5）

## 2. 本轮产出（`sim/select_poses_C.py`, `sim/power_analysis_C.py`）

### 2.1 位姿设计（**新的 C 默认**）

**16 训练 + 5 holdout**，holdout **保持 5 个，暂不扩容**，功效不足时再顺序追加。

- 配对约束全部达成：**3 grip 对 + 3 速度对**
- 速度配对**靠改往复频率**（0.25/0.40/0.80 Hz），**幅值固定** ⇒ q 覆盖不变
  （改幅值会同时改变 q 覆盖范围，是错的）
- Φ（去均值）**秩 7/7**，**条件数 53.0**
  （12 位姿硬塞 3+3 对时条件数崩到 4690 ⇒ 这是选 16 的理由）
- holdout 按**覆盖**选（中心/伸展/折叠 × 两夹爪 × 不同速度），**不追求 rank**
- φ 用**逐帧 `pose_features` 的窗内均值**，不用平均速度近似

**LOPO 按物理位姿分组**：16 条件 → **7 个物理位姿组**（组大小 4/4/4/1/1/1/1）。
同一位姿的 grip/速度条件必须**整组留出**，各组等权。

### 2.2 白化分块 Jacobian

- 白化用 B′ **3 个不重叠差分**（A1−A2 / A3−A4 / A5−A6），按运行聚类，收缩 0.5
- 参数按成员间 std 归一
- **规范固定**：纯缩放方向沿 **B_m 自身**（按当前 B 值加权，不是三列之和）
  ⇒ θ 投影掉 3 个方向，保留 **21 个调度自由度**
- **B-only 与 R(18) 是嵌套关系**，不能同时进合并矩阵（否则秩亏，条件数 1e16 是假的）

| 设计 | 合并[B-only] | 合并[R(18)] |
|---|---|---|
| D1 2–8 Hz | 秩 15/22，cond 2.9e2 | 秩 **21/31**，cond 6.7e2 |
| D2 6–8 Hz | 秩 12/22，cond 6.0e2 | 秩 16/31，cond 1.3e3 |

规范固定后 θ vs 残量最小主夹角 **0.1° → 16.7°**（仍有实质混杂，不能同时自由开放）。

**τ 局部 CRLB = 0.0070 ms**，但它**低于 `t_send_span` ≈ 1.4 ms**
⇒ **只能报为条件信息量指标**（分支/模型形状/时钟均已知下的局部量），
**不是绝对时延精度**；与 141 ms 分支间距相差 4 个数量级，
**局部 J_τ 满秩完全不能排除另一谷**。

### 2.3 功效分析（当前状态）

**两种口径并列**（用户定）：
- **主结果**：等能量·等机时·峰值 ≤2 mrad ⇒ 隔离频率分配效果
  `E* = min(E_D1,E_D2) = 2.011e−6`；**D1 峰值 1.729 mrad**、D2 保持 2.000
  （2 mrad 是**安全上限**，不是必须顶满的额度）
- **次结果**：等峰值 2 mrad·等机时·能量可不同 ⇒ 真实安全约束下的设计效率
  （D1 多出的 25% 能量来自更低的 crest factor 1.72 vs 1.99，是工程收益，不是造假）

**实现口径**：`Y = H·U_actual + N` ⇒ 幅值/crest/能量归一/**ZOH 衰减**全部自然进入，

### 2.4 shape/noise 三分解（已完成）

| 设计 | shape-only | noise-only |
|---|---|---|
| D1 | **124%** of 联合 | 12% |
| D2 | **111%** of 联合 | 13% |

⇒ **shape-error 主导成立**。目标在 **FRF 空间**（`obs = Ht + N/U`，已除 U），
所以乘性 shape error 与幅值近似无关 —— 这才是主/次结果几乎相同的机制。
**若目标在输出空间 SSE，它仍应随能量缩放。**

准确表述：
> 在当前替代模型与噪声近似下，能量归一没有明显改变分支选对率，也没有明显改变 ΔSSE，
> 因为目标函数由 shape error 主导而非噪声主导。频率跨度是分支判别力的主要候选解释，
> 但这一结论仍受替代模型限制。

## 3. 待办（严格按此顺序）

### 3.1 最不利 shape error 搜索 ← **下一步**

**必须防止的致命退化**：不能允许 shape error 包含**任意的跨位姿共享线性相位斜率**，
否则它可以直接伪装成另一个 τ 分支，搜索必然把问题做成不可辨识。

约束：
1. **共享线性相位归入 τ**；对 shape error 施加**零全局线性相位斜率**的规范
2. 允许**有界的位姿相关**相位斜率，但**跨位姿加权均值为零**
3. 搜索变量：平滑 log-gain、**非线性**相位曲率、三轴方向偏差、位姿依赖
4. 边界 = B′ 实测误差构成的**膨胀置信椭球**，并**限制频率二阶差分**
   （不能逐频点任意跳变）
5. shape error 表示**固定的真实系统失配**，**不能针对每个噪声 realization 单独优化**
6. 用一批 **common-random-number** seed 搜索最坏误差，再用**独立** seed 验证

对**前三锚点集合 + D1 + D2** 分别报告：
- 两个真值分支下的**最坏**选对率及 Wilson 下界
- 最坏 ΔSSE 中位数和 5% 分位
- **最坏误差是否顶到允许集合边界**
- shape-only / noise-only / 联合
- **最坏条件下锚点集合的排名是否改变**

**若混合 4 锚点在最坏情况下不过门槛，先测试 5 或 6 个宽带锚点，不要立刻跳到全 D1。**

### 3.2 接入真实 L0/L1/L2/L3 与 group-LOPO

- **每个 τ 网格点内分别完整优化 L1/L2/L3**，规范固定与正则保持一致
  （当前是「每位姿一个复增益」的**替代模型**，**不必然是乐观上界** ——
   可能帮错误分支，也可能掩盖正确分支下的模型失配）
- 7 个物理位姿组做 **group-LOPO**；同一位姿的 grip/速度条件**整组留出**，各组等权
- **超参数只在训练组内选择**；5 个真实 holdout **始终封存**
- **同时注入 L0/L1/L2/L3 真值**，报层级选对率与错误升级率
  （不能只测试复杂真值）

层级定义（`AUDIT_G_structure.md` §5.6）：
L1 = θ（规范后 21 dof）／L2 = L1 + j2/j3 有效模态残量 + 对应 D 列（先固定规范，做 LOEO）／
L3 = L2 + 全局 ω/ζ／L4 = W(φ)/B(φ)/D(φ) 或位形相关极点

> ② 第 2 级**不要**直接重拟合完整 W/B/D：探针只激励 j2/j3，其他列不可辨识，
> 且 W·B·α 有尺度自由度。

### 3.3 确定最终设计 → 1500–2000 seed 终跑

**放行门槛（用户定）**：
- 两分支选对率的 **95%CI 下界 ≥95%**
- **过度升级率 ≤10%**
- **holdout 白化误差改善的 CI 不跨零**
