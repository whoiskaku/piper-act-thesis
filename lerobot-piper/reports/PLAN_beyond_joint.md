# 编码器解释不了、IMU 看得到的运动偏差（方案 v1.4，2026-10-19；v1.1 用户已确认，v1.2–v1.4 按用户复核修正，见 §8）

问题（用户 2026-10-19）：开 TE 之后，还剩多少**编码器解释不了、但 IMU 能观测到**的运动偏差？编码器残差小只说明关节角跟踪好，
不能排除连杆、夹爪或安装结构的弹性运动；现有 IMU 残差也不能全部归因于弹性。做法：实测编码器轨迹 → 刚体运动学 → 预测 IMU，
在相同时间、坐标、频带下和实际 IMU 比。直接用实际关节运动，不把指令规划器的偏差混进来。先看清大小、波形、是否与之前的
IMU 状态有关，再决定：随指令稳定出现 → 前馈、ILC；随当次振动状态变化且历史 IMU 有信息 → 反馈。G 和 π 围绕这部分误差设计；
现在不选更强的网络，也不叠加 Shift+Blend。

## 0. 老师标准第 1–6 条

1. **只确定一件事**：开 TE 后，实测关节运动经刚体运动学解释之后，IMU 还剩多大的运动差异；它的频带和波形；它随指令稳定出现，
   还是随当次状态变化、能被之前的 IMU 预测。结果写成三个数（大小、可复现度、可预测度），按 §5 对应到后续路线。
2. **G：本次不涉及评估 G。** 但结果决定 G 该预测什么：这部分若可复现，G 要能从指令预测它；若依赖当次状态，补正器要用 IMU 历史。
3. **π：本次不涉及。**
4. **实现正确的证据**：合成数据测试（单关节转动时预测角速度 = 关节角速度；已知振荡加在实测侧或预测侧，能被分到对的一侧；
   按各遍帧时刻对齐；留一法与可预测度在已知过程上的数值）；**端到端因果测试**（只改 2 s 之后的编码器原始数据，因果分支在
   2 s 之前的残差与滤波输出逐位不变；离线分支会变，说明测试能抓到未来信息混入）；控制条件；常数延迟、固定旋转的敏感性。
5. **推理链**：残差 = 编码器之后的运动（连杆、减速器、夹爪、IMU 支架）+ 编码器侧的高频成分（量化、腕部粘滑跳变、间隙）
   + 标定、对时、模型误差 + 噪声。不预先归因于「弹性」；没有第二个传感器，分不开机械臂本体和 IMU 支架。「可复现」只说明
   前馈有东西可学；「历史可预测」只说明反馈有信息可用，还受 20 Hz 指令（最多修到 10 Hz）、固件加速度上限和回路延迟限制。
   另外（v1.2 订正）：线性相干分解给出的是两侧的线性不相干功率，不能直接当作「某个传感器独有的真实运动」；敏感性检查只说明
   本次搜索的常数延迟和固定旋转修正没能明显解释残差，不能排除所有对时、标定或模型误差；本分析推不出「G 从指令预测不了」，
   A、B、C 是不同的轨迹，也不能据此认定「TE 消除了大部分可复现成分」。
6. **真机**：只用已有的真机数据，不上机。

## 1. 数据（都已有）

- 正式基线 80 条：开 TE 40 条为主（抓放、插入各 20），不开 TE 40 条只作辅助。
- 可重复性回放 24 遍（A、B 开 TE 各 8 遍，C 不开 TE 8 遍）：同一指令重放，用来分可复现与不可复现。
- IMU 标定回放（静止姿态 + 单关节慢速来回）：控制条件，看这套预测在慢、平滑的运动下还剩多少（测量与模型误差的底）。
- 标定用 2026-10-18 的 `outputs/imu_calib/imu_calib.json`。

## 2. 预测与残差

- 离线分支（大小、频谱、可复现度）：实测编码器（200 Hz）→ 30 Hz 零相位低通（只为压住求导噪声，比较带最高 15 Hz）→ 样条
  → MuJoCo 安装点的角速度、比力 → 按标定转到 IMU 坐标（R、零偏、安装位置 dp、IMU 延迟）。会用到前后的数据，只作离线描述。
- 因果分支（可预测度）：见 §3.4。
- 残差 = 实测 IMU − 预测，两边用同一个频带：陀螺 <15 Hz（逐条去均值，零偏漂移不算运动）、陀螺 3–15 Hz；
  加计 3–15 Hz 只报告（标定只在 0–3 Hz 验证过，还含杆臂项）。
- 快速估计（v0，2026-10-19，开 TE 中位）：陀螺残差 <15 Hz 抓放 0.061、插入 0.069 rad/s；3–15 Hz 0.056 / 0.067，
  而 IMU 本身 3–15 Hz 0.062 / 0.074、编码器预测本身 0.045 / 0.056 ⇒ 两者在 3–15 Hz 只部分一致（由中位数粗算相关约 0.5）。
  编码器先 15 Hz 还是 30 Hz 低通，结果几乎不变。

## 3. 量什么

### 3.1 大小与频带
- 各频带残差 RMS，旁列实测、预测各自的量。
- 频谱：实测、预测、残差的功率谱，及实测与预测的相干 γ²(f)。分出实测侧的线性不相干功率（实测功率中与预测不相干的部分）
  和预测侧的线性不相干功率。它们不直接等于某个传感器独有的真实运动：非线性、时变的关系和噪声也会落在里面。
- 分段（整体之外单列，不删）：疑似接触段、chunk 边界（不开 TE）、其余。

### 3.2 波形
- 中位条和最难条的叠图（实测 vs 预测、残差），放大残差最集中的 2 s。

### 3.3 可复现度（回放 A、B）
- 各遍残差按指令帧对齐到同一时间轴（各遍按自己的 `t_send`），留一法 R²（同可重复性检验），并给可复现、不可复现部分的 RMS。
- 主值用疑似接触段以外的样本（研究对象是自由运动；同一指令下的接触响应天然容易复现）；接触段和全部样本另列。
  主频带 3–15 Hz，<15 Hz 另列（v1.2 订正：v1.1 误把 <15 Hz 当主值，见 §8）。

### 3.4 与之前 IMU 状态的关系（回放 A、B）
- 不可复现部分 d_r(t) = 第 r 遍残差 − 其余各遍的平均（留一，避免自耦合）。
- 用 d_r 过去 W 秒预测 d_r(t + h)（线性模型，留一遍外推），报 R²(h)，h = 0、50、100、150 ms；同时报「保持现值」这个最简单的预测作基线。
- 实现细节（v1.4；v1.2、v1.3 的预测侧有混叠伪影，见 §8）：
  - **预测分支全程因果，并先抗混叠**：编码器在 200 Hz 网格上（原始 CAN 样本线性插值）先过四阶 Butterworth 30 Hz 单向低通，
    再后向差分得到角速度，然后在「IMU 时刻 − 延迟」处线性插值；不用样条、不用零相位滤波。直接从约 200 Hz 的编码器取到
    100 Hz 的 IMU 时刻而不先低通，50 Hz 以上的成分会折叠进低频（v1.2、v1.3 就是这样）。刚体运动学同 `ideal_imu_traj`。
  - **两边相位对齐**：实测陀螺过同样设计的 30 Hz 单向低通（100 Hz 下），抵消编码器侧低通的滞后。
  - **可用时延**：网格插值、取值插值各会用到之后至多约 5 ms 的样本，所以残差晚一个 IMU 样本（10 ms）才拿来用：决策时刻 t 的
    历史特征从 t − 10 ms 那个样本开始往前取；前瞻 h 仍从 t 算起。决策时刻用到的原始数据都在 t − 1.75 ms 之前。
  - 残差在各遍自己的 IMU 采样点上计算，不重采样；单向四阶 Butterworth：主频带 3–15 Hz 带通，<15 Hz 低通另列；
    去零偏只用开头 1 s 保持段的均值。
  - 名义时间（查模板、标接触段用）= 上一个已发指令的帧号 × DT + 此后经过的时间，只用过去的 `t_send`。
  - 模板 = 其余各遍（事先已有的重复数据）在同一名义时间的平均；每一折里训练用的各遍只减去「除自己和留出那一遍之外」的平均，
    留出那一遍不进入训练。
  - 历史窗口 0.5 s（50 个样本 × 3 轴）；固定岭回归 λ = 1e-2·tr(XᵀX)/p（`train_rq.fit`，用户 2026-10-02 定的强度，不调参）；
    无截距（同 2026-10-02 的 AR 约定）。
  - 有效样本：从 t − 0.49 s 到 t + 150 ms 都在保持段之后、非接触段内；所有 h、模型和「保持现值」共用这一批样本。
  - h = 0 时历史里含当前样本，R² 恒为 1，改报一步（10 ms）。

## 4. 控制与敏感性

- 噪声底：回放开头 1 s 保持段、标定回放的静止姿态。
- 平滑运动下的残差底：标定回放的单关节慢速来回。
- 对时：逐条在 ±30 ms 内找最佳常数延迟（初版 ±10 ms，插入落在边界上，已放宽），报残差变多少；标定：逐条最佳固定旋转后残差变多少。
  只能说明这两种修正能不能明显解释残差，不能排除时变的对时误差、其他标定或模型误差。

## 5. 判据（用户 2026-10-19 定）

- **大小**：「平滑运动下残差底的 2 倍」只作量级参照：超过不能据此断言存在额外的机械运动，没超过也不能据此否定它。
- **可复现度**：A、B 分别判定：两条都 ≥ 0.6 → 支持把前馈、ILC 作为候选；两条都 < 0.3 → 暂不推进；其余无法判定。
- **可预测度（反馈）**：A、B 各自在 h = 100 ms 时都满足 R² ≥ 0.3，且优于「保持现值」→ 支持把反馈作为候选。
  R² 以预测零残差为基线（1 − Σ(d − d̂)² / Σd²）；模型和「保持现值」在同一批有效样本上比。
- 未通过只说明本轮方法没有提供推进依据，不能写成「前馈、反馈都不合适」。

## 6. 实现与测试

- 新脚本 `sim/beyond_joint.py`；复用 `cmd_tracking`（读取）、`repeat_reversal`（回放读取、帧对齐、接触标记）、`imu_calib`（标定约定）。
- 测试（5 个）：单关节转动时预测角速度 = 关节角速度；已知 8 Hz 振荡加在实测侧 / 预测侧 → 分到对应一侧的线性不相干功率；
  各遍按自己的帧时刻对齐后同一波形 R² = 1；端到端因果测试（改 2 s 之后的编码器原始数据，因果分支 2 s 之前逐位不变，离线分支会变）；
  可预测度在已知过程（轻阻尼振荡、白噪声）上的数值。

## 8. 版本记录与配置差异（如实记录）

- **v1.1 与此前设定不一致**：v1.1 实际用的是 0.2 s 历史 + 普通最小二乘（带截距），主判定用 <15 Hz；此前建议的是
  0.5 s 历史 + 固定岭回归，主频带 3–15 Hz。这是我写 v1.1 时自己定的，没有对照此前的设定。
- **v1.1 的可预测度有未来信息混入**：编码器预测先经过全段零相位低通和样条，时间对齐和重采样用线性插值，最后才单向滤波，
  消不掉前面混入的未来信息。用户的针对性检查：2 s 之前的编码器数据完全相同、只改 2 s 之后，「过去」的预测特征变化 0.00688 rad/s。
  ⇒ v1.1 的 100 ms R²（A 0.01、B −0.00）只算离线探索结果，不能作为在线反馈的证据。v1.2 按 §3.4 修正后重算。
- **可复现度的主频带**：v1.1 报的主值是 <15 Hz（A 0.29、B 0.21）；主频带 3–15 Hz 下是 A 0.24、B 0.17，两种都「暂不推进」。
  我先前说的「A 离 0.3 只差 0.01」指的是 <15 Hz，不是主频带。
- **v1.1 汇报里过强、已撤回的说法**：把线性不相干功率说成「IMU 有、编码器没有 / 编码器有、IMU 没有」的真实运动；
  把敏感性检查说成「不是对时、标定造成的」；「G 从指令预测不了」；「开 TE 去掉了大部分可复现的部分」。
- **v1.2（零阶保持 + 后向差分）判定形式上通过，但来自预测侧的伪影**：主频带 100 ms R² A 0.35、B 0.46（历史 0.2/0.5 s、岭/最小二乘
  都差不多；同一处理链上的白噪声零假设只有 0.04–0.05）。拆开看：只看实测陀螺的不可复现部分 0.08 / 0.08，只看因果预测的不可复现
  部分 0.37 / 0.48，同样采样点上换回零相位预测的残差 0.04 / 0.04 ⇒ 可预测的结构在因果预测一侧、实测里没有。可能的机制（未逐项验证）：
  CAN 约 200 Hz 与 IMU 100 Hz 时钟不同步，零阶保持的「样本年龄」0–5 ms 缓慢循环，后向差分的滞后随之周期变化，各遍相位不同。
  ⇒ v1.2 的判定不作为反馈依据。
- **v1.3（原始样本插值 + 可用时延）仍有同样的伪影**：主频带 100 ms R² A 0.33、B 0.45，诊断：只看实测 0.08 / 0.08，只看预测 0.34 / 0.46
  ⇒ 上面「零阶保持相位循环」的解释不对或不完整。诊断：编码器侧加因果 30 Hz 抗混叠低通（实测侧同样低通）后，只看预测降到
  0.03 / 0.01、残差 0.03 / 0.03，只看实测仍是 0.08 ⇒ 伪影来自混叠：编码器的高频成分没先低通就取到 100 Hz，折叠进 3–15 Hz，
  各遍相位不同（与记忆里「抗混叠口径不对称」是同一类问题）。⇒ v1.3 的判定也不作为反馈依据；v1.4 加抗混叠（§3.4），
  并加测试：编码器侧 95 Hz 的成分不得在 100 Hz 取样后出现在 3–15 Hz。
- **v1.4 结果**（2026-10-19）：主频带 100 ms R² A 0.03、B 0.03（保持现值 −1.16 / −1.11）→ **未通过：本轮方法没有提供推进依据**；
  <15 Hz −0.01 / −0.01；50 ms 0.39 / 0.37。诊断：只看实测 0.08 / 0.08，只看预测 0.03 / 0.01（预测侧不再高于实测侧）。
  同样的带通 + 模板 + 岭回归在白噪声上是 0.04–0.05（v1.2 时算），残差在这个水平。
- **目前可保留的结论**：按当前刚体预测与处理方法，实测 IMU 仍有约 0.05–0.07 rad/s 的残差；自由运动中的平均模板没有达到重复性门槛
  （主频带 A 0.24、B 0.17）；按 v1.4 因果版，不可复现部分 100 ms 后的线性可预测度在白噪声零假设水平。两项都只说明本轮方法
  （线性、只用自身历史、这组回放）没有提供推进依据，不能写成「前馈、反馈都不合适」。
