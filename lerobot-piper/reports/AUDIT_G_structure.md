问题：B′ 三轮测出真机 6–8 Hz 响应在两个位形间差 **3.92×**，而 Ĝ 只差 **0.80×**。
这是结构缺陷（该改模型）还是辨识缺陷（该换数据）？

工具：`sim/audit_G_structure.py`

**结论（v2，经用户指出四处不严谨后重做）**：

> Ĝ 包含位形调度，但现有训练得到的**小信号**调度在两个实测工作点上**方向错误**，
> 且**跨 bootstrap 成员不稳定** ⇒ **增量动力学的调度辨识不足**。
> 进一步的可表达性测试表明：**仅调 α 不足以同时拟合幅值、相位与方向** ——
> 需要极点/方向层面的改动，而不只是重辨识 θ。

**v1 的「不必改结构」结论过于乐观，已作废。** 见 §5。

## 0. 先纠正一个我先前的错判

在 `CALIB_G_band_RESULT.md` 里我写过「Ĝ 的柔性模态位形无关，原理上无法表达 3.92×」。
**这句话是错的。** Ĝ 的柔性层本来就有位形调度：

```python
α(t) = softplus(φ(t) @ θᵀ)
模态激励 = (W·u) * α(t)          # α 乘在输入侧(进振子之前)
输出     = 模态铃声 @ B + u @ Dᵀ  # D = 直通项, 位形无关
```

而 φ 恰恰就是为这件事设计的：

```
φ = [1, q2, q3, q2², q3², q2·q3, 速度, 夹爪]
```

`pose_features` 的注释写得很清楚：「肩肘的一次+二次+交叉项 = 表达『悬臂伸展度』的
最小二次曲面（残差画像确诊：位形是响度差 2.3× 的主因，载体是 q2/q3）」。
**模型本来就是冲着这件事设计的。**

## 2. 为什么没被约束住：不是能量加权

我先提出的解释是「监督频带 0.5–9 Hz 的裸 MSE 被低频能量主导，6–8 Hz 被饿死」。
**这个解释被数据否掉了。** 训练残差（墙，带通 0.5–9 Hz，10 集）的能量分布：

| 子带 | 占比 | 累计 |
|---|---|---|
| 0.5–1 Hz | 7.7% | 7.7% |
| 1–2 Hz | 12.7% | 20.4% |
| 2–3 Hz | 10.5% | 30.9% |
| 3–4 Hz | 11.2% | 42.0% |
| 4–5 Hz | 10.3% | 52.3% |
| 5–6 Hz | 12.4% | 64.7% |
| **6–7.5 Hz** | **19.5%** | 84.2% |
| 7.5–9 Hz | 15.8% | 100% |

6–7.5 Hz 占 19.5%（按每 Hz 算 13%/Hz，与 1–2 Hz 的 12.7%/Hz 持平）。
**该频段并没有被能量加权饿死。**

## 3. 真正的原因：口径不同 + 参数不可辨识

### ① 口径不同（更根本）

- Ĝ 的柔性层是拟合**墙**（`real − ideal`）辨识出来的 —— 由**完整的、大幅值的 ACT 指令**驱动
- π 用的是**增量**响应 `Ĝ(a+δa) − Ĝ(a)`，δa 只有 1–4 mrad
- **这两个量的位形依赖没有理由一致**

而且我们有独立证据表明系统对幅值不是纯线性：第 3 轮测出偶分量随 **δa¹** 缩放
（和频带幅值比 1.76–2.15，若是纯二次应为 4.0）。存在这样的符号不敏感分量，
说明小信号增量增益与大信号有效增益可以不同 —— 包括它们的位形依赖。

> **B′ 探针是第一次直接测量 π 真正需要的那个增量量。**
> 「增量诀窍」（`e_sim = e_log + Ĝ_δ[δa]`）让名义世界来自实测、模型只提供增量，
> 从而抵掉大部分模型误差 —— 但**增量增益本身**从未被直接辨识过，一直是墙拟合的副产品。

### ② 参数不可辨识（次要但确凿）

α 的成员间比值跨 0.00–1.40。墙残差的宽带拟合下，(W, B, α) 有大量等效组合：
同一条残差曲线可以用「大 W、小 α」或「小 W、大 α」拟合出来。
75 个参数拟合 1.7 万帧的宽带残差，α 的位形斜率是最弱约束的方向之一。

### ③ D 项压掉约一半杠杆（结构侧的次要问题）

D 占 6–8 Hz 响应的 47% 且**位形无关**。即使 α 重辨识到位，可达的总体位形比受限：

```
0.53·r + 0.47 = 3.92  ⇒  r = 6.5×
```

模态路径要摆动 6.5× 才能让总体到 3.92×。原理上可行（α 是 softplus，无上界），
但 **D → D(φ)** 值得作为次要结构改进 —— 它能把需要的 r 从 6.5 降到 3.9。

## 4. 结论与下一步

### 结论（v1，已被 §5 修正）

v1 的结论是「不是结构缺陷、不必改结构」。**§5 的可表达性测试推翻了后半句。**

### 这也修正了对 A 的定位

A（带限 π）**不是「摘掉对 Ĝ 的依赖」**，而是**降低依赖**：
- π 仍然依赖模型（`apply_G` 仍在训练回路里）
- 用**与部署一致的因果低通**；截止 <7 Hz 仍保留 6–7 Hz（仍在失配带内），
  要完全避开失配带需 **<6 Hz**
- 定位：**鲁棒基线 / 消融**，不是最终方案

### 重辨识时要注意（等 C 的数据）

1. **监督对象改为增量**：用探针实测的 `(B₊−B₋)/2` 直接约束 `Ĝ(a+δa)−Ĝ(a)`，
   而不是继续只拟合墙
2. **带内加权**：虽然能量没被饿死，但既然目标频段明确，显式加权仍能改善条件数
3. **保留墙的约束**：不要用增量数据把墙拟合破坏掉 —— 两者应联合，权重待定
4. **α 的正则**：成员间跨 0.00–1.40 说明该方向病态，需要先验/正则或更多位形
5. 可选结构改进：**D → D(φ)**，把需要的模态摆幅从 6.5× 降到 3.9×

## 5. 四处收紧（用户 2026-07-28 指出）与重做的结论

工具：`sim/audit_G_expressibility.py`，产物 `outputs/probe_b2/audit_expressibility.json`

### 收紧 1：θ 非零 ≠ 调度已被可靠辨识

θ 非零只说明**优化器移动过参数**。可靠性要看**数据是否约束了它**。
实测：α 的 w170/w280 比值**跨成员 0.00–1.40（跨零）** ⇒ 没被约束住。
更根本的是 §5.4 的 φ 秩分析。

### 收紧 2：α 的标量比值不能与总响应比直接比较

三模态 + 直通 + 三轴是**复数叠加**。必须看**总 FRF 对各 α_m 的灵敏度**
`∂|H|/∂ln α_m = Re⟨H, P_m⟩/|H|²`。实测（j2 w170，成员 k=2）：

| f | 模态1 | 模态2 | 模态3 |
|---|---|---|---|
| 6.0 | 0.436 | 0.027 | −0.005 |
| 6.5 | 0.347 | 0.015 | 0.091 |
| 7.0 | 0.402 | 0.011 | 0.036 |
| 7.5 | 0.337 | −0.004 | −0.013 |

- 灵敏度由**模态 1 主导**（0.34–0.44），模态 2/3 几乎无杠杆（≤0.09）
- **出现负值**（j3 w170 的 7.0 Hz 模态3 = −0.067）⇒ 复数叠加下，
  **增大某个 α 会减小 |H|**。标量比值 0.34 vs 3.92 的对比因此不合法

### 收紧 3：能量占比 ≠ 可辨识

19.5% 的能量占比只说明该频段没被加权饿死。可辨识性要看
**位形覆盖 + φ 的独立变化 + 参数 Jacobian/Fisher 的秩**。见 §5.4。

### 收紧 4：实数配比方程对复频响不合法

`0.53r + 0.47 = 3.92` 假设模态与直通同相。实测夹角：
j2 w170 为 [−46°, −11°, −5°, −20°]，j3 w170 为 [−59°, −35°, −30°, −10°]
—— 近同相但不严格，且**该方程本身仍不合法**（它忽略了三轴方向）。
D(φ) 是否需要，由下面的可表达性测试决定，而不是这个方程。

### 5.4 可表达性测试：仅调 α **不足**

α 是**频率无关的正标量**。求 `g_m ≥ 0` 使
`Σ_m g_m·P_m(f) + P_D(f) + P_rigid(f) ≈ H_real(f)`
在该工作点的 4 频点 × 3 轴 = 12 复数 = 24 实残差上最小：

| 工作点 | (i) 实数非负 g（物理） | (ii) 复数 g（非物理，隔离相位） | (iii) 实数 g + 全局时延 |
|---|---|---|---|
| j2 w170 | **100.1%** | 22.5% | 32.7%（τ = −44 ms） |
| j2 w280 | **121.3%** | 42.6% | 48.0%（τ = −48 ms） |
| j3 w170 | **103.3%** | 24.9% | 35.8%（τ = −48 ms） |

（残差 / \|H_real\|；100% 意味着「不如预测零」）

- **仅调 α 完全不够**：三处残差 100–121%
- **约 78 pp 来自相位**（三处一致：+77.5 / +78.6 / +78.5 pp）
- 即使允许**非物理的复数增益**，仍剩 **22–43%** ⇒ 那部分是**三轴方向 + 频率形状**
- 单一全局时延能补回 67–73 pp，但它是**诊断量而非物理修法**

⇒ **需要极点/方向层面的改动**：位形相关的模态频率/阻尼、位形相关的模态混合（W/B），
或 D(φ)。**不能只重辨识 θ。**

Jacobian 奇异值（对 [α₁,α₂,α₃]）：j2 w170 = [1, 0.198, 0.032]，条件数 31.7；
j3 w170 = [1, 0.684, 0.069]，条件数 14.5。数值秩 3/3，但最小方向弱一个数量级。

### 5.5 φ 空间的秩：现有数据只能约束 1 个方向（共 8 个）

`α_m(φ) = softplus(φ·θ_m)`，θ_m 有 8 个分量 ⇒ 需 **≥8 个线性无关的 φ**。

现有 3 个「工作点」去均值后的 φ 矩阵**数值秩 = 1 / 8**。
原因：**j2_w170 与 j3_w170 共用窗 170 ⇒ φ 完全相同**，实际只有 **2 个不同位形**。

⇒ **θ 的其余 7 个方向由初值/正则决定，不是数据决定** —— 这就是 α 跨成员不稳的根源。
⇒ **C 的位姿必须在 φ 空间里选**（不是关节角等距），目标让 Φ 满秩且条件数小，
   **至少 9 个不同位形**，另留完整 holdout 位姿。

### 5.6 对 A / C 的影响

- **A**（带限 π）不受影响，仍作为**鲁棒基线/消融**推进
- **C** 的目标要扩大：不只是「补数据重辨识 θ」，而是
  **先做 Jacobian 秩分析判断需要哪一层改动**（θ / D(φ) / 模态混合 / 极点），
  再决定结构。这与用户给 C 的设计目标一致
