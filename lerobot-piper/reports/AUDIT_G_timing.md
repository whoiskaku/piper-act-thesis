# 审计 ① / ①b：Ĝ 与真机的绝对时序（2026-07-28）

**结论：时序未定。相位残差存在至少两个相隔约 141 ms（≈1/7 Hz）的候选分支，
两个独立探针指向相反分支。Level 0-T 不能开工。**

工具：`sim/audit_G_timing.py`（①a）、`sim/audit_G_timing_b.py`（①b）
产物：`outputs/probe_b2/audit_timing.json`、`audit_timing_b.json`

---

## 0. ①a 的三处越界（已收回）

1. **`apply_G` 与 `increment_fast` 差正好 LSHIFT=3，只证明软件索引契约正确**，
   不证明模型与真机物理对齐。
2. **LSHIFT 是双方共同的坐标变换，消不掉相对延迟**：

   ```
   H_real^e = S₃ H_real^wall,   H_Ĝ^e = S₃ H_Ĝ^wall   ⇒  复数比值不变
   ```

   墙钟差 100 ms，e-index 下仍差 100 ms。故我先前「口径差」的归因**无效**。
   ①b 的测试 (5) 用数值确认了这一点（双侧同移 3 帧，τ\* 不变，差 0 ms）。
3. **「43+100=143 ms = 真机总时延」和「伺服 FIR 解释了 30%」都收回。**
   43 ms 只能叫「在 +100 ms 分支下模型自身 6–8 Hz 的有效群延迟」；
   Ĝ 是并联复数系统，群延迟不能按比例分摊给某一路径。

## 0b. ①a 仍然成立的部分

- `apply_G`（e-索引）与 `increment_fast`（墙钟）的峰值滞后差 **正好 +3 帧 = LSHIFT**，
  互相关最佳整数 shift 也是 **+3**（相关 **0.9924**）⇒ **π 训练用的 Ĝ 没有索引错位**
- 模型的非因果前伸只有 **1.8%** 峰值（LNEG=4 允许更多）⇒ 可忽略
- `kernels()` 取 `[T0−LNEG : T0+LPOS]` 与 `fir(·, ·, LNEG)` 的「第 l 格代表滞后 l−nfut」
  约定一致 ⇒ 核的时间原点自洽

## 1. 核心问题：相位分支别名

+100 ms 与 −40 ms 相差约 **140 ms ≈ 1/7 Hz**。四个音调只跨 6.0–7.5 Hz，
配上 3 个自由增益后**两个分支都能拟合**。①a 报的 ±1 ms 只是主谷内部的曲率，
**不是排除了另一分支后的绝对置信区间**。

## 2. ①b：宽带联合 τ 扫描

### (1) 频点选取

用完整「2 s 猝发 + 1.5 s 衰减」窗，对所有 |U| > 15% 峰值的频点做 NUDFT
（真实 100 Hz 时间戳，Δt 加权）：

| 工作点 | 频点数 | 跨度 |
|---|---|---|
| j2 w170 | 54 | 5.15–8.25 Hz |
| j2 w280 | 61 | 4.15–7.80 Hz |
| j3 w170 | 59 | 4.65–8.30 Hz |

总跨度 4.15 Hz ⇒ 时延分辨 ~1/(2·跨度) = **120 ms** —— 仍与 141 ms 的别名周期同量级。

### (2)(3) 联合扫描 τ ∈ [−250, 250] ms

| τ 局部谷 | 联合残差 | Δ vs 最优 |
|---|---|---|
| **+102 ms** | 55.4% | — |
| **−52 ms** | 68.6% | **+13.2pp** |
| −193 ms | 94.6% | +39.2pp |
| −245 ms | 98.1% | +42.7pp |

**相邻谷间距 ≈ 141 ms**，与 1/7 Hz 一致 ⇒ 确认是分支别名。

逐工作点**不一致**：

| 工作点 | 单独 τ\* | 前 3 谷 |
|---|---|---|
| j2 w170 | +104 ms (47%) | +104 / −48 / −203 |
| **j2 w280** | **−48 ms (70%)** | −48 / +114 / −197 |
| j3 w170 | +98 ms (56%) | +98 / −59 / −182 |

两个工作点偏好 +100 分支，一个偏好 −48。

### (4) 旧 5 Hz 小波探针（独立判别）

数据：`outputs/probe/probe_seq_pp2_ep0.npz` + `replay_ep0_{A1,B}.json`。
7 个注入窗（`hits` = [帧, 关节, 符号]，交替 j2/j3 与 ±），81 个频点，跨 **3.00–7.00 Hz**。

| τ 局部谷 | 残差 | Δ |
|---|---|---|
| **−14 ms** | 87.4% | — |
| +176 ms | 96.3% | +8.9pp |

在 B′ 的两个候选分支上：**τ=−52 ms（94.6%）优于 τ=+102 ms（105.6%），差 11.0pp**。

⇒ **旧探针指向相反的分支。**

旧探针的弱点（必须一并说明）：**单端**（B − A1，含复放变异，实测在 5.25 Hz 就有
42 mrad/s）、**20 Hz 采样**、`t` 用 `time.time()` 非 monotonic、无 100 Hz 数据、
与 B′ 只在 6–7 Hz 重叠。

### (5) 双侧同移 3 帧的不变性 ✓

未移位 τ\* = +102 ms；双侧窗原点同移 3 帧后 τ\* = **+102 ms，差 0 ms** ⇒ 与代数保证一致。

（旧实现有 bug：真机侧改变换的时间戳、模型侧改采样点，两者在窗边界不等价，
导致 τ\* 假变 −300 ms = −2×3 帧。已改为「双侧窗原点同移、U 在移位窗上重算」。）

|---|---|---|---|

## 3. 判读

合成对照给了标尺：**模型形状正确时，分支间的目标差应为 81.5pp**。

实测：B′ 联合只差 **13.2pp**，旧探针只差 **11.0pp 且方向相反**。

⇒ **分支未被解决。** 现有证据既不足以断定 +100 ms，也不足以断定 −52 ms。
矛盾可能来自旧探针自身的弱点，也可能来自模型形状偏差大到让分支判别失效
（残差 55–87% 本身就说明模型形状不对）。

**因此：**
- **Level 0-T 不能开工** —— 给 Ĝ 加一个符号或量值错误的共享延迟会把问题埋得更深
- ② 的嵌套可表达性测试也应等时序定下来，否则每一级的残差都混着未定的相位

---

## 4. 要定时序，缺的是什么

现有两个探针在频率上重叠太少：旧探针 3–7 Hz（单端、20 Hz），B′ 6–7.5 Hz（双端、100 Hz）。
两者都不足以单独拉开 141 ms 的别名。

**需要：同一次采集里覆盖更宽频段的双端探针。**

在 C 的受控工作点上加一组 **2.5–9 Hz 的 ± 配对多正弦/对数扫频**：
- 跨度 6.5 Hz ⇒ 时延分辨 ~1/(2·6.5) = **77 ms** ⇒ 能把 141 ms 的别名拉开
- 双端（± 配对）⇒ 噪声方差 0.5σ²，且免受复放变异污染
- 100 Hz 记录 + `t_send` + 稳健时钟映射 ⇒ 与 B′ 同级的时序质量
- **不需要额外机时** —— 并进 C 的位姿网格即可

已并入 C 的设计（见 `DESIGN_C_controlled_poses.md`）。
