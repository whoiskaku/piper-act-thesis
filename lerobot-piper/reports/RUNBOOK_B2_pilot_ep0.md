# B′ ep0 4 mrad pilot 上机手册（2026-07-28）

**放行范围**：仅 ep0、仅 4 mrad、逐条执行。
**4 mrad 的用途**：安全、记录完整性、奇对称性。
**4 mrad 不能做的事**：验证幅值线性度（必须 4 vs 8 mrad 对比）；下相位/增益/时延结论。
分析器会输出这些数字，**只作观察**。

## 1. 执行顺序（正负成对做平衡）

```
A1 → j2+ → j2− → j3− → j3+ → A2
```

j2 是 (+,−)、j3 是 (−,+)，对线性温漂与运行顺序做了平衡。
**后续 episode 反转中段**：`A1 → j3+ → j3− → j2− → j2+ → A2`（`probe_b2_gate.order_for()` 已实现）。

## 1b. 注入窗（已按 residual margin 重选，**按关节独立**）

| 关节 | 注入窗 | 最紧 residual margin（4 mrad） |
|---|---|---|
| j2 | 170, 280 | +5.58° |
| j3 | 170, 320 | **+1.10°** |

原先三窗共用（170/280/350）已作废：w280 对 j3 的 residual 为 **−2.70°**、
w350 对 j2 为 **−0.93°**。降幅值救不了（w280 j3 的 nominal 1.81° 本身就低于跟踪误差 4.51°，
探针只占 0.23°），只能按关节剔除。约束已写进 `make_probe_b2.pick_windows`（要求 ≥0.5°）。

代价：每关节 2 窗而非 3 窗，τ 精度实测下降（120 次实现，真值 g=1.8 τ=75 ms rot=12°）：

| 配置 | 白噪声 τ 1σ | 有色噪声 AR(.6) τ 1σ |
|---|---|---|
| j3 4 mrad | 11.0 ms（7 Hz 下 28°） | 15.7 ms（**40°，超 30° 判据**） |
| j3 8 mrad | 5.5 ms（14°） | 7.8 ms（20°） |
| j2 8 mrad | 6.7 ms（17°） | 9.5 ms（24°） |

即 **4 mrad + 2 窗在有色噪声下已不足以支撑相位结论** —— 这与「4 mrad 只作安全/记录/奇对称」
的定位一致，不构成额外限制。8 mrad 两窗仍满足 30° 判据。
CI 覆盖率在 2 窗下重测仍通过（92–94%）。

## 3. 停止条件（分两类，不要混）

**A. 物理立即停机**（人手/急停）
- 控制器报警、异常振动、异响
- 明显超出既有编码器速度/加速度包络
- 任何你觉得不对劲的

**B. 暂停继续采集并诊断**（机器已停稳，不是急停）
- ⓪ 有窗 residual ≤ 0 或发现削顶 → 该窗不得注入，重新生成序列
- ① 记录失败：缺样、设备时间回退/重复、时钟映射异常
- ④ SNR_p < 3 → 排查记录、对齐或注入响应。
  注意这条**天然是事后的** —— 必须先跑完 B+ 和 B− 才算得出 SNR，
  它不可能、也不应该作为物理急停条件。

两类都一样：停下之后不要接着跑下一条。

## 4. 六项门禁（六条齐了之后）

| # | 项 | 判据 |
|---|---|---|
| ⓪ | 逐窗 residual margin / 削顶 | 每个 (配置, 窗) 的 `min(B±)余量 − 跟踪p99` > 0；无命令削顶 |
| ① | 记录质量 / 设备时间 / 时钟映射 | 无回退、无重复、缺样 <2%、速率 100±3 Hz、晶振 <5000 ppm、延迟 p95 <50 ms |
| ② | 实际发送 B− ≡ −B+ | 查真实下发的 `cmd`，逐点 max\|δa₊+δa₋\| < 1e-9 rad；夹爪零差 |
| ③ | 起始状态 / 指令 hash 一致 | 六臂 `cmd_hash` 相同；起始关节离散 <0.5° |
| ④ | 奇分量 > 噪声 | **功率** SNR_p ≥3（链路门）／≥5（校准资格） |
| ⑤ | 偶分量 ≈ 噪声 | 基频 z ≤3；宽带（差频 0.3–1.7 Hz、二次谐波 11.5–15.5 Hz）能量比 <4.0 |
| ⑥ | 未逼近安全包络 | 探针**增量** <+10pp；绝对占比 <110%（护栏） |

### ④ 两档，且是功率 SNR

SNR_p = E_odd,tones / E_noise,tones,  与相干度的对应 γ² = SNR_p/(1+SNR_p)

- **SNR_p ≥ 3（γ²≈0.75）链路门**：低于它 → **暂停后续配置并排查**记录、对齐或注入响应。
  这不是物理急停条件 —— 必须先跑完 B+ 和 B− 才算得出 SNR。
- **SNR_p ≥ 5（γ²≈0.83）校准资格**：达不到 → 该频点**不得用于更新 Ĝ**，
  但不代表实验链路故障。4 mrad 达不到是预期内的。

代码按功率口径实现并做了去噪偏（`max(P_odd − P_noise, 0)/P_noise`），
不是 RMS 幅值比；输出同时打印推得的 γ² 以便与分析器的 γ² 交叉核对。

### ⑤ 的实际灵敏度

基频锁相**对二次非线性几乎是盲的** —— y² 把能量搬到 DC、差频（0.5/1.0/1.5 Hz）和
二次谐波（12–15 Hz），一点都不落在四个分析频点上。故加了宽带检查。实测灵敏度
（3 窗 @ 噪声底 45 mrad/s）：可检出峰值 **~20–30% 以上**的二次失真；更小的检不出。
**门禁「过」只代表在这个灵敏度内没发现，不代表不存在。**

### ⑥ 为什么判增量

安全包络取自含本集在内的 20 集的最大值，而探针复放的正是其中一集 ——
裸复放天然就在 ~100%。所以主判据是同一轨迹下 B 相对 A 的**增量**，干净归因到探针。
加速度的 20 Hz 二阶差分在 7 Hz 已近奈奎斯特，绝对值不可靠，但同轨迹增量可比；
**IMU gyro（100 Hz）才是这里的可靠仪器**。

## 5. 六项全过之后

**不是自动开放 8 mrad** —— 拿门禁输出回来一起看，再决定。

4 mrad 只验证**奇对称**。开放 8 mrad 还需要：偶分量与噪声相容、无削顶、
响应峰值留有余量。届时才谈幅值线性度（4 vs 8 对比）、Ĝ 校准、相位/增益/时延结论。

## 附：本轮为此做的三处改动

**① `t_send` 记在命令真正发出处。**
`PiperMotorsBus.write()` 里依次是 `MotionCtrl_2` → `JointCtrl` → `GripperCtrl`，
真正下发关节指令的是 `JointCtrl`。现在在那一行前后各取一次 `time.monotonic()`
存进 `last_jointctrl_t`，复放脚本取中点作 ZOH 起点，并把 `post−pre` 存成
`t_send_span` 以量化「实际发送时刻」本身的不确定度（门禁 ① 会打印其中位数）。
在 `send_action` 外面打时间戳会把前后两条 CAN 帧的耗时算进去。

**② IMU 时间用 device_ms → host monotonic 的稳健仿射映射。**
`host_t = 采样时刻 + 传输/调度延迟`，延迟 ≥0 且右尾很重（USB 批量收包、GIL、线程唤醒），
直接当采样时刻等于把 OS 抖动整个灌进相位。现在拟合**最小延迟线**（下包络）：

```
min Σ(host_i − a·x_i − b)   s.t.  host_i − a·x_i − b ≥ 0
```

线性规划（2 变量），失败时退回迭代截尾最小二乘。合成验证（真晶振 +200 ppm、
指数重尾延迟 + 2% 的 20 ms 尖峰）：恢复采样时刻 **RMS 0.001 ms**，
直接用 `host_t` 是 **4.77 ms**；速率复原 +200 ppm。
残差（= 每样本实际传输延迟）**全量存进** `gate_ep0.json`，门禁 ① 打印 p95。

> 遗留限制（时间口径）：JointCtrl 前后中点是**最好的软件发送时间**，但真实执行还含未知的
> **CAN 排队/传输延迟**；IMU 侧的最小传输延迟也是常数、被截距吸收、从数据里不可观测。
> 所以绝对 τ = **CAN 延迟 + IMU 固定传输延迟 + 动力学延迟**。三者都是常数，
> **配置间比较仍然有效**，但不可把绝对 τ 全记到动力学头上。

**③ 线性度措辞收紧。**
分析器原来在 4 mrad 单点就打「✓线性」。已改为「✓奇对称」，并显式注明
**幅值线性度须 4 vs 8 mrad 对比**。
