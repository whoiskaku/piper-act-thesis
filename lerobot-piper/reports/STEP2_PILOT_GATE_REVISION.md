# j4 pilot 稳定判据修订记录（2026-08-24 冻结）

> **这是失败之后的门槛修订。** 记录在此，不隐去。

## 1. 起因

j4 分级 pilot 的 **P03 连续两次**被旧判据拦下：

```
第 1 次  末段峰速 3.220 °/s   (阈 0.5)
第 2 次  末段峰速 2.080 °/s   (阈 0.5)
```

两次都在 **j4**，位置偏差却极小（0.001–0.089°，容差 1°）。

## 2. 20 秒静置诊断（`--settle-probe 20`）

预移动到 P03 起始位姿后静置 20 s，只观测、不跑激励：

| 关节 | 位移范围 | 峰速 | 跳变次数 |
|---|---|---|---|
| j1 / j2 / j3 / j5 | **0.0000°** | 0.000 | **0** |
| **j4** | 0.2840° | 3.040 °/s | **29** |
| **j6** | 0.1140° | 2.260 °/s | **11** |

分四段计数：**10 / 8 / 10 / 11** —— **不衰减**，稳定在约 1.5 次/秒。

跳变幅度 **0.104–0.152°**，j4 位置始终在 0.284° 带内**往复**（首末仅差 0.111°）。
编码器细分辨率 ≤ 0.005° ⇒ **不是量化噪声**，是真实机械滑移。

⇒ **j4/j6 存在有界、不衰减的腕部极限环**（齿隙内伺服找位）。这是 j4 **首次被移动**
才暴露的固有属性 —— pp2 全部 17 集里 j4 的指令范围恒为 `0.0…0.0`。

## 3. 旧判据错在哪

旧判据测**速度**（末段 0.5 s 峰速 ≤ 0.5 °/s），但其设计意图是
「预移动的余振停了没有」。**极限环不是余振**：有界、不衰减、不发散。

事件率约 1.5 次/秒 ⇒ 0.5 s 窗口撞上跳变的概率约一半 ⇒ **门变成抛硬币**。

证据：P01/P02 通过时 `settle_vmax_dps` **恰为 0.0**（那 0.5 s 内一次跳变也没有）。
按 1.5 次/秒估，连续两次窗口无事件的概率约 22% —— 它们通过是**运气**，
不是条件不同。

## 4. 修订后的判据（冻结）

```
稳定时间           5.0 s（原 1.5 s）
判据窗口           最后 2.0 s
逐关节             R_j = max(q_j) − min(q_j)
通过条件           所有 j：R_j ≤ 0.5°
最终位置到位门槛   **保留不变**
峰速 / 跳变次数 / 方向 / 净位移   **完整报告，但不再决定通过或失败**
位置带超限         **立即停机，不自动重试**
```

**不对 j4/j6 做任何隐藏豁免** —— 它们和其余关节用同一条判据。

用第 2 节的 20 s 数据验算：最后 2 s 的
`R_j = [0, 0, 0, 0.228, 0, 0.105]°` ≤ 0.5° ⇒ 放行。

## 5. 既有数据的处置

| | 处置 |
|---|---|
| **P01 / P02** | **无法用新规则回算** —— 当时只落盘了标量 `settle_vmax_dps`（均为 0.0），没有稳定段轨迹。见下方决定。 |
| **P03 第 1 次** | **未进入激励**，作为**诊断失败记录**保留（`settle_fail_*.json`） |
| **P03 第 2 次** | 同上 |
| **20 s 诊断** | 保留为本次修订的依据（`settle_probe_*.json`） |

**已修补的缺口**：稳定段轨迹此后**每次都落盘**（不只失败时），
以免再出现「门槛修订后无法回算」。

## 6. 附带修掉的两个诊断 bug

1. `np.unravel_index` 返回 `(采样, 关节)`，此前赋成 `(关节, 采样)` ⇒ 报错里的
   关节号是错的（把 j4 报成 j2）。
2. 「毛刺 vs 持续」的判读只统计**末段 0.5 s 窗口**，而三次跳变里只有一次落在
   窗口内 ⇒ 误判为「单次毛刺，可重试一次」，用户据此重跑了一次 P03。
   现改为统计**整个稳定段**。判据的作用恰恰是防止靠重试绕过真问题。

## 7. 对后续标定的影响（非门槛问题，但必须记）

0.11° 的随机跳变占 P01 幅值 2.061° 的 **5.4%**。这直接解释了
P01/P02 的可重复性只有 **81.1%**（全臂天花板 93–97%，`step2_ceiling.py`），
且 j4 的确定性内容在 **6 Hz** 就截止（全臂 9–12 Hz）。

⇒ **j4 的辨识带可能需要收窄到 0.5–6 Hz**，且其参数精度受此极限环封顶。
满幅档（P05/P06）跑完后应重测，届时信噪比更高。
