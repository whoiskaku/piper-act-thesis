# j4 pilot 判据修订记录（2026-08-24 冻结）

本文件记两次修订：**A. 稳定判据**（速度 → 位置带）、**B. 跟踪判据**（绝对阈值 → 固定滞后补偿后的残差）。两次都是**失败之后的修订**，理由与依据如实留档。

---

# A. 稳定判据

> **这是失败之后的门槛修订。** 记录在此，不隐去。

## 1. 起因

j4 分级 pilot 的 **P03 连续两次**被旧判据拦下：

```
第 1 次  末段峰速 3.220 °/s   (阈 0.5)
第 2 次  末段峰速 2.080 °/s   (阈 0.5)
```

两次都在 **j4**，位置偏差却极小（0.001–0.089°，容差 1°）。

## 2. 20 秒静置诊断（`--settle-probe 20`）

预移动到 P03 起始位姿后静置 20 s，只观测、不跑激励：

| 关节 | 位移范围 | 峰速 | 跳变次数 |
|---|---|---|---|
| j1 / j2 / j3 / j5 | **0.0000°** | 0.000 | **0** |
| **j4** | 0.2840° | 3.040 °/s | **29** |
| **j6** | 0.1140° | 2.260 °/s | **11** |

分四段计数：**10 / 8 / 10 / 11** —— **不衰减**，稳定在约 1.5 次/秒。

跳变幅度 **0.104–0.152°**，j4 位置始终在 0.284° 带内**往复**（首末仅差 0.111°）。
编码器细分辨率 ≤ 0.005° ⇒ **不是量化噪声**，是真实机械滑移。

⇒ **j4/j6 存在有界、不衰减的腕部极限环**（齿隙内伺服找位）。这是 j4 **首次被移动**
才暴露的固有属性 —— pp2 全部 17 集里 j4 的指令范围恒为 `0.0…0.0`。

## 3. 旧判据错在哪

旧判据测**速度**（末段 0.5 s 峰速 ≤ 0.5 °/s），但其设计意图是
「预移动的余振停了没有」。**极限环不是余振**：有界、不衰减、不发散。

事件率约 1.5 次/秒 ⇒ 0.5 s 窗口撞上跳变的概率约一半 ⇒ **门变成抛硬币**。

证据：P01/P02 通过时 `settle_vmax_dps` **恰为 0.0**（那 0.5 s 内一次跳变也没有）。
按 1.5 次/秒估，连续两次窗口无事件的概率约 22% —— 它们通过是**运气**，
不是条件不同。

## 4. 修订后的判据（冻结）

```
稳定时间           5.0 s（原 1.5 s）
判据窗口           最后 2.0 s
逐关节             R_j = max(q_j) − min(q_j)
通过条件           所有 j：R_j ≤ 0.5°
最终位置到位门槛   **保留不变**
峰速 / 跳变次数 / 方向 / 净位移   **完整报告，但不再决定通过或失败**
位置带超限         **立即停机，不自动重试**
```

**不对 j4/j6 做任何隐藏豁免** —— 它们和其余关节用同一条判据。

用第 2 节的 20 s 数据验算：最后 2 s 的
`R_j = [0, 0, 0, 0.228, 0, 0.105]°` ≤ 0.5° ⇒ 放行。

## 5. 既有数据的处置

| | 处置 |
|---|---|
| **P01 / P02（原始）** | **无法用新规则回算**（只落盘了标量 `settle_vmax_dps`，均为 0.0）⇒ 已在新判据下**重跑**；原始两条移开保留为 `.superseded_*.json`，未删。 |
| **P03 第 1 次** | **未进入激励**，作为**诊断失败记录**保留（`settle_fail_*.json`） |
| **P03 第 2 次** | 同上 |
| **20 s 诊断** | 保留为本次修订的依据（`settle_probe_*.json`） |

**已修补的缺口**：稳定段轨迹此后**每次都落盘**（不只失败时），
以免再出现「门槛修订后无法回算」。

## 6. 附带修掉的两个诊断 bug

1. `np.unravel_index` 返回 `(采样, 关节)`，此前赋成 `(关节, 采样)` ⇒ 报错里的
   关节号是错的（把 j4 报成 j2）。
2. 「毛刺 vs 持续」的判读只统计**末段 0.5 s 窗口**，而三次跳变里只有一次落在
   窗口内 ⇒ 误判为「单次毛刺，可重试一次」，用户据此重跑了一次 P03。
   现改为统计**整个稳定段**。判据的作用恰恰是防止靠重试绕过真问题。

## 7. 对后续标定的影响（非门槛问题，但必须记）

0.11° 的随机跳变占 P01 幅值 2.061° 的 **5.4%**。这直接解释了
P01/P02 的可重复性只有 **81.1%**（全臂天花板 93–97%，`step2_ceiling.py`），
且 j4 的确定性内容在 **6 Hz** 就截止（全臂 9–12 Hz）。

⇒ **j4 的辨识带可能需要收窄到 0.5–6 Hz**，且其参数精度受此极限环封顶。
满幅档（P05/P06）跑完后应重测，届时信噪比更高。

### 7.1 四次复放的实测（2026-08-24，判据修订后补齐）

原始 P01/P02 + 新判据下重跑的 P01/P02 = **同一序列四次复放**，
0.5–9 Hz 两两可重复性：

```
        旧P01   旧P02   新P01   新P02
旧P01     —    81.1   77.5   79.6
旧P02   81.1     —    83.9   87.5
新P01   77.5   83.9     —    75.0
新P02   79.6   87.5   75.0     —

六对平均 80.8%   范围 75.0–87.5%
旧×旧 81.1%   新×新 75.0%   旧×新平均 82.1%
```

**判据修订没有扰动数据**：旧×新（82.1%）不比旧×旧（81.1%）或新×新（75.0%）差，
组间差异小于组内散布 ⇒ 75–87.5% 的分布是**复放噪声**，不是 5 s 静置带来的系统偏移。

⇒ **j4 在最低幅值档的可重复性 = 80.8%（六对平均，n=4）**，
对比全臂天花板 93–97%。这是 j4 参数精度的上限。

### 7.2 位置带判据的稳定性

两次重跑的 `R_j`：`[0,0,0,0,0,0]°` 与 `[0,0,0,0.125,0,0]°`，均远低于 0.5° 阈值；
而同两次的**末段 0.5 s 峰速都是 0.000 °/s**，全稳定段跳变却分别是 **7 次和 3 次**
—— 再次印证旧判据的抛硬币性质（跳变有没有落进那 0.5 s 窗口纯属偶然）。

# B. 跟踪判据修订（2026-08-24 冻结）

> **同样是失败之后的门槛修订。** 起因是原指标里混入了已知的固定延迟。

## B.1 起因

P03 的 `跟踪误差 p99 = 2.705° > 2.0°` 判否。但实测三条：

| 集 | 幅值 | p99 原始 | 最优滞后 | p99 补滞后 | 滞后占比 |
|---|---|---|---|---|---|
| P01 | 2.061° | 1.443° | **2 帧** | 0.121° | 92% |
| P02 | 2.061° | 1.212° | **2 帧** | 0.314° | 74% |
| P03 | 4.122° | 2.705° | **2 帧** | 0.239° | 91% |

幅值 ×2.00 ⇒ p99 ×1.87，**滞后恒为 2 帧**，补后残差始终 < 0.32°。
⇒ **跟踪能力本身没有退化**，原判据量到的主要是滞后。

## B.2 原判据错在哪

`p99 ≤ 2.0°` 是**绝对阈值**，而误差主体 = 滞后 × **速度**。在幅值阶梯上速度
随之增长，故必然在某一级撞墙，且撞的是**量纲错误**而非物理极限。
滞后（约 100 ms）本身是 **G 要建模的对象**，不是故障。

## B.3 冻结的新判据

```
e_t = q_state[t + LAG] − q_cmd[t]        LAG = 2 帧（100 ms），**固定**
通过条件            p99(|e_t|) ≤ 0.5°
**不逐条搜索最优滞后** —— 那会把异常延迟一起拟合掉，使门禁失效
未补偿 p99、每条估计的最优滞后   **继续报告，但不参与门禁**
稳定位置带 / 最终到位 / 限位 / 速度门        **保持不变**
```

若真实滞后变化，固定 2 帧后的残差会增大并**触发门禁**，不会被自动隐藏。

## B.4 既有数据

P01 / P02 / P03 用固定 2 帧回算**均通过**（0.121 / 0.314 / 0.239° ≤ 0.5°），
三条报告的最优滞后**都是 2**，与冻结值一致。**P03 数据完整，不必重跑。**

## B.5 一处计算更正

我此前称「阶梯上半段都会被旧门拦死」，**这是错的**：原始误差 ∝ **速度**，
不是行程。按峰速重算全阶梯的滞后贡献（= v × 0.1 s）：

| 序列 | 幅值 | 峰速 | 滞后贡献 | 旧 2° 门 |
|---|---|---|---|---|
| P05 快阶跃 | 8.245° | 58.3 °/s | **5.83°** | ✗ |
| **P07 慢扫** | **8.245°** | **2.0 °/s** | **0.20°** | **✓ 本可过** |
| P11 慢扫 v8 | 6.375° | 9.1 °/s | 0.91° | ✓ |
| P09 快阶跃 | 2.125° | 42.5 °/s | 4.25° | ✗ |

⇒ 同为 8.245° 行程，快阶跃与慢扫的原始误差差 **29 倍**。只有快速的那几条会被
旧门拦下，慢扫本来就能过。

# C. j4 正式激励包络的确定（2026-08-26）

## C.1 pilot 结果汇总（幅值均 8.245°，只改上升时间）

| 包络 | 峰速 | 峰加速 | 补 2 帧残差 | 最优滞后 | 门禁 |
|---|---|---|---|---|---|
| rise=5（P05） | 52.4 °/s | 683 °/s² | **2.042°** | **3 帧** | ✗ |
| rise=7（P07c） | 41.2 °/s | 383 °/s² | 0.492° | 2 帧 | ✓（余量 **1.6%**） |
| rise=7（P08c） | 46.0 °/s | 383 °/s² | **0.608°** | 2 帧 | ✗ |
| rise=10（P05b） | 28.6 °/s | 187 °/s² | 0.347° | 2 帧 | ✓ |
| rise=10（P06b） | 30.2 °/s | 187 °/s² | 0.258° | 2 帧 | ✓ |

**rise=7 的两次重复跨在阈值两侧**（0.492 / 0.608）⇒ 系统性地贴线，不是偶然。
同一指令的实测峰速也差 12%（41.2 / 46.0 °/s）。

## C.2 决定（按事前写定的规则）

> 事前规则：**两条都通过 ⇒ 用 rise=7 单一包络；任一不通过 ⇒ 退回双包络。**

P08c 判否 ⇒ **正式 j4 阶跃激励采用双包络**：

```
包络 A   4.122°  rise=5    峰速 29.1 °/s   峰加速 342 °/s²
包络 B   8.245°  rise=10   峰速 28.6 °/s   峰加速 187 °/s²
```

## C.3 双包络的频段覆盖（实测激励能量，陀螺绝对值）

| 频段 | A 单独 | B 单独 | **A+B** | 主导 |
|---|---|---|---|---|
| 0.5–1 Hz | 1.569 | 5.654 | **7.223** | B |
| 1–2 Hz | 2.254 | 5.864 | **8.118** | B |
| 2–3.5 Hz | **2.166** | 0.801 | **2.967** | A |
| 3.5–6 Hz | **0.841** | 0.239 | **1.080** | A |
| 6–9 Hz | 0.112 | 0.142 | **0.255** | B |

**双包络在每个频段都不弱于任一单包络**：A 补 2–6 Hz（转子惯量与伺服带宽的
信息所在），B 补 0.5–2 Hz。这正是单包络做不到的 —— rise=10 在 3.5–6 Hz 只有
A 的 0.28 倍，rise=5 在 0.5–2 Hz 只有 B 的 1/3。

## C.4 j4 的已验证工作区间

```
✓ 已验证干净   ≤ 30.2 °/s / ≤ 342 °/s²   （P03/P04/P05b/P06b）
✗ 已验证失败   ≥ 46.0 °/s / 383 °/s²     （P08c、原 P05）
~ 边缘         41.2 °/s / 383 °/s²       （P07c，余量 1.6%，不采用）
```

**边界位于 30–46 °/s 之间，不再细分** —— 目标是找到可用的干净激励，
不是精确定位极限。

## C.5 可重复性随幅值（0.5–9 Hz）

| 档 | 可重复性 |
|---|---|
| 2.061° rise5 | 75.0% |
| 4.122° rise5 | **94.2%** |
| 8.245° rise10 | **96.6%** |

**但总分会骗人**：8.245° rise10 的 96.6% 是低频能量 ×3 把加权拉上去的，
它在 3.5–6 Hz 的可重复性反而从 81.4% 掉到 54.1% —— 因为该频段激励被压掉了
72%。**这正是必须用双包络的理由。**

j4 的 0.11° 极限环（见 A 节）是**固定幅度的加性噪声**：幅值翻倍 ⇒ 信噪比 ×4，
故 j4 的辨识**不需要**收窄频带，只需要足够大的幅值。
