**冻结日期 2026-09-27。在拟合之前写成。** 修改须在 §8 改动记录留条目与理由。

## 0. 本轮要回答的**唯一**一句话

> **相比固定核，增加这 12 个随位形变化的系数，有没有折外收益？**

- **①（固定核）= 基准**，由 `c ≡ 0` 分支给出
- **②（不随位形变化的低秩核）本轮不单独跑** —— 理由见 §1.2
- **不启动拟合，直到本预注册冻结。**

## 1. 模型

### 1.1 形式

$$\widehat{\mathrm{gap}}[t]=\sum_{\tau=0}^{15}\Bigl(H_0[\tau]+g(s[t-\tau])\cdot\Delta K[\tau]\Bigr)\,\delta a[t-\tau]$$

$$\Delta K[\tau,a,j]=\sum_{p=1}^{3}\sum_{q=1}^{4}c_{pq}\,L_p[\tau]\,M_q[a,j]
\qquad\Longrightarrow\qquad \textbf{12 个系数}$$

- `H₀ ∈ ℝ^{16×3×6}`（288）· `c ∈ ℝ^{12}` · 合计 **300**
- **`c = 0` ⇒ 退化为固定核 ①。此分支在 §3 中被显式列出，不用大有限 `λ` 近似。**
- `G-2` **不进拟合也不进评分**（沿用 `PREREG_BINNED_KERNEL.md` §2.0）

### 1.2 ⚠ 为什么 **不**为 ② 另开一条线

**`H₀` 本来就能表示任意固定核**，因此 `H₀ + 常数 ΔK` **仍在同一个函数空间内**。
两种 ridge 惩罚**可能改善拟合，但改变的是正则化方式，不是增加了位形表达能力**。
⇒ ② 不是一类新的响应模型，不单独立项。

### 1.3 ⚠ 撤回「跑 ③ 自动覆盖 ②」

前一版设计表写「`g ≡ 1` 时 ③ 退化为 ②」——**错，已撤回**。
`g(s)` **已标准化固定**，**不能通过调 `λ` 变成 `g ≡ 1`**。
③ 只能通过 **`c = 0`** 退回 **①**。

### 1.4 调度量 `g(s)`

```
s[t] = q̄₂[t] + q̄₃[t]        q̄ 取名义指令 chunks[].raw（不含 δa）
g(s) = (s − s̄) / σ_s
```

- **在输入发生时取值**：滞后 `τ` 的输入用 `g(s[t−τ])`
- ⚠ `s̄` 与 `σ_s` **只能用该折的训练种子算**，**不得提前用全 P1**
- `g` 居中 ⇒ `H₀` 吸收平均响应，`ΔK` 只承载**随位形的变化**

## 2. 折内流程（**顺序写死**；先固定基底，再联合拟合，才保证凸性）

每个 P1 训练折内，**严格按此三步**：

| 步 | 内容 |
|---|---|
| **① 临时核** | 在**该折训练种子**上拟 `H̃`（普通 ridge，`λ̃ = 1e-3`，**写死不选**） |
| **② 冻结基底** | 把 `H̃` **展开为 `16×18`**（lag × (axis·joint)）→ SVD → 取**前 4 个右奇异向量** → 各还原为 `3×6` 得 `M_1…M_4`。**归一化为单位 L2 范数。此后不再更新。** |
| **③ 联合拟合** | 固定 `M_q` 与 `L_p`，对 `(H₀, c)` 做**联合 ridge**（两个惩罚项）。对参数**线性 ⇒ 凸，无局部极小。** |

> ⚠ **拟合过程中不再更新 SVD。** 前一版写「`M_q` 取自折内重拟的 `H₀`」是**循环**，已修。
> ⚠ **临时核的正则规则、基底归一化、`g` 的 `s̄`/`σ_s`，全部只能用该折的训练种子。**

**滞后剖面基 `L_p`（事前写死）**：前 3 个 DCT-II 基，
`L_p[τ] = cos(π·p·(τ+0.5)/16)`，`p = 0,1,2`，各归一化为单位 L2 范数。
（选它是因为**平滑、低阶、与数据无关**；**不按 `H` 的形状裁剪**，避免事后定制。）

> ⚠ **范围说明（订正前一版）**：这 3 个基**覆盖整个 16 帧滞后**，
> 代表**平滑的核变化**，**不再代表「短滞后集中」**。
> 前一版设计表写「与 `H` 的 lag 0–3 集中一致」——**错，已撤回**。
> ⇒ **阴性结果只针对这个预定基空间**，不推广到其它滞后结构。

## 2bis. 正则化的尺度（**写明确**）

$$L=\lVert \mathrm{gap}-\widehat{\mathrm{gap}}\rVert^2
+\lambda_H\lVert H_0\rVert_F^2+\lambda_\Delta\lVert c\rVert^2$$

| | |
|---|---|
| `λ_H` | `m_H ×` **旧固定核设计矩阵**的 `ridge_scale` |
| `λ_Δ` | `m_Δ ×` **12 列修正设计矩阵**的 `ridge_scale` |
| 临时核 | `λ̃ = 1e-3 ×` 其自身设计矩阵的 `ridge_scale` —— **`1e-3` 也是 multiplier** |

> ⚠ **两个尺度分别计算，不得用拼接后的整个设计矩阵统一算** ——
> 否则**增加修正列会连带改变固定核的惩罚**，两个模型就不同口径了。

⚠ 旧代码里的 `RIDGE_GRID` 是 **multiplier**，不是实际 `λ`。本预注册全部按 multiplier 记。

## 2ter. 基准 ① **必须独立选出**

| | 搜索空间 |
|---|---|
| **① 固定核（基准）** | **五个 `c≡0` 分支**中用 P1 CV 独立选最佳 `m_H` |
| **③ 本候选** | **全部 30 个组合** `(m_H, m_Δ)` 中选 |

> ⚠ **不得**拿 ③ 选中的 `m_H` 再临时构造一个较弱的 ① —— 两者**各自选参**。
> 二者选中的 `m_H` 可以不同，这是允许的。

**平局优先顺序（写死，确定性全序）**：
① CV 误差升序 → ② **`c≡0` 分支优先** → ③ **`m_Δ` 大者优先** → ④ **`m_H` 大者优先**

## 5. 判据（事前写死）

**主指标**：P2 的 0.5–9 Hz 预测误差削减

$$d_s=\frac{E_{①,s}-E_{③,s}}{E_{①,s}},\qquad s\in\{2000,2001,2002\}$$

先对同一种子的**两集误差取平均**，再对**三个种子等权汇总**得 `d̄`；
**必须同时报告三个 `d_s`。**

> **通过 ⇔ 三个 `d_s` 全为正 且 `d̄ ≥ 5%`。** 其余记为**不通过**。

**`5%` 沿用上一轮，未下调。** 理由：该阈衡量的是
**「是否值得投入后续工作」**，而后续工作（把模型接进 π 的训练）的成本
**不随参数量缩放** —— 参数增幅从 +100% 降到 +4% **不构成下调理由**。
（**明确记下：我考虑过下调，选择不调，以免事后移动球门。**）

**次要判据（P3）**：四个 `d_s` 全正且 `d̄_{P3} ≥ 5%` 记为压力验证通过；
其他情况照实报数，**不以「均值略大于零」替代通过**。

**分频**（0.5–3 / 3–9 Hz）与 `beta_ols` **只报告，不参与判决**。

**定位：开发筛查，不是确认性检验。** P2 只有 3 个独立种子 ⇒
**不把帧当独立样本，不报 p 值作主判据。**

### 5.1 ⚠ 若 CV 选中 `c ≡ 0`

**如实报告「本轮没有证据支持增加位形修正」，
不临时扩模型、不改基底、不换调度量、不重跑。**
