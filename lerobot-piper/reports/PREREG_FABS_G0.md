# 预注册 —— 阶段 A：`F_abs` 与 G0（**冻结**）

2026-09-27。**只做阶段 A。不训练增量分支，不训练 π。**
`G-2` 冻结 · ③c 不动 · 零机时。

## 1. 学什么（直接学「墙」）

$$\hat e_{\rm base}(u)\ \approx\ e_{\rm bare}=\omega_{\rm bare}-\omega_{\rm ideal}(u)
\qquad\Longrightarrow\qquad F_{\rm abs}(u)=\omega_{\rm ideal}(u)+\hat e_{\rm base}(u)$$

`ω_ideal(u)` 由 `IdealChunkRenderer` + 冻结标定 `(R,b)` 渲染（**零参数，不训练**）。
⇒ **网络只学墙**，与 G0 的定义同构。

## 2. 数据与划分（**按会话**，整集不切）

| 会话 | 集数 |
|---|---|
| `ab2/A` | 12 |
| `ab4/P0` | 5 |
| `ab5/A` | 40 |
| `ab6/A` | 30 |
| `ab7/Apost` | 15 |
| **合计** | **102** |

> **划分 = leave-one-session-out（5 折），整集不切。**
> 理由：**会话漂移是已知的大效应**（ab5 A 前后段 +26.9%），
> 按集随机划分会让同会话数据同时进训练与留出 ⇒ 高估泛化。
> **不按集随机划分；不做集内切分。**

⚠ `ab4/P0` **无探针**，属裸集，可用。它与 P1/P2/P3 **同会话**——
阶段 B 若用到，须在当时注明；**本阶段不涉及**。

## 3. 评价口径（**写死**，与既有一致）

| | |
|---|---|
| 目标 | `e_bare = ω_bare − ω_ideal(u)`，**raw 对齐空间**，`L = ALIGN_L = 3` |
| 滤波 | `bandpass41`，`METRIC_BAND = (0.5, 9.0)` |
| 有效帧 | 丢首尾各 **20** 帧 |
| 去均值 | 与既有一致：残差扣**逐集常数**（全集上算）→ 带通 → 取有效帧 |
| 归一 | 误差能量 `/ (3·T_e)` |

### G0（**主门槛**）

$$\text{redu}=1-\frac{\sum_e\lVert \mathrm{bp}(e_{\rm bare}-\hat e_{\rm base})\rVert^2}
{\sum_e\lVert \mathrm{bp}(e_{\rm bare}-\bar e_{\rm bare})\rVert^2}\ \ \ge\ \mathbf{30\%}$$

**分母 = 「逐集常数预测墙」的误差**（**不是总 IMU 能量**）。
**按会话汇总**：5 个留出会话各算一个 `redu`，**等权平均**，并**逐会话报告**。

> **通过 ⇔ 平均 `redu ≥ 30%` 且 5 个留出会话全为正。**
> ⚠ **通过只说明机制前提成立，尚未证明响应更容易辨识。**

### G1（同一批留出集、同一口径）

**冻结 `G-2` 在同一 5 折留出集上按上式重新评分**，与 `F_abs` 并列报告。
⚠ **不引用历史的 `0.520`**（不同数据、不同口径）。

## 4. 训练配置（**写死**）

| | |
|---|---|
| 输入 | 名义指令 `u`（7 通道）+ 一阶/二阶差分 = **21 通道**（复用 `train_pi_g2env.build_inputs` 的特征口径） |
| 架构 | **因果**空洞一维卷积：4 层 · `k=5` · `dilation 1/2/4/8` · 64 通道 · GELU ⇒ 感受野 **61 帧（3.05 s）**；`Conv1d 1×1 → 3` |
| ⚠ 因果 | **左侧填充**（与 `PiNet` 的对称填充**不同**）——臂的响应只依赖过去指令 |
| 输出 | `ê_base`（3 轴，20 Hz） |
| 损失 | 带通后 MSE（`bandpass41` 实现为**固定权重** conv1d，可微） |
| 优化 | Adam · `lr 1e-3` · 梯度裁剪 1.0 · 输出头**零初始化**（从 `ê_base ≡ 0` 起步 = 逐集常数基准） |
| 步数 | **3000 步**（每步一整集）· 每 200 步评留出 · **保留最优权重** |
| 种子 | `seed = 0`（**不做种子扫描**） |
| 预算 | **≤ 2 GPU·小时**；5 折一次跑完 |

**输出头零初始化 ⇒ 训练起点恰好是 G0 的分母（逐集常数）。**

## 5. 停止条件

- **G0 不过 ⇒ 立即停**，不调架构、不扩步数、不换种子、不进 G1 以外任何环节
- 超预算 ⇒ 停并如实报告
- **本阶段不训练 `F_inc`，不训练 π**

## 6. 事前预测

1. `redu` 点预测 **≈ 40%**，区间 **15%–60%** ⇒ **较可能过 30%**，但不稳。
2. **跨会话方差大**：至少 1 个留出会话的 `redu` 明显低于均值。
3. `G-2` 在同一口径上**很可能优于** `F_abs`（G-2 是零参数物理模型，
   而 `finding_predictor_is_the_bottleneck` 记着 G-2 曾打赢学出的 MLP）。

⚠ 这些是预测，不是门槛。门槛只有 §3 的 G0。
