## 1. 学什么（直接学「墙」）

$$\hat e_{\rm base}(u)\ \approx\ e_{\rm bare}=\omega_{\rm bare}-\omega_{\rm ideal}(u)
\qquad\Longrightarrow\qquad F_{\rm abs}(u)=\omega_{\rm ideal}(u)+\hat e_{\rm base}(u)$$

`ω_ideal(u)` 由 `IdealChunkRenderer` + 冻结标定 `(R,b)` 渲染（**零参数，不训练**）。
⇒ **网络只学墙**，与 G0 的定义同构。

### G0（**主门槛**）

$$\text{redu}=1-\frac{\sum_e\lVert \mathrm{bp}(e_{\rm bare}-\hat e_{\rm base})\rVert^2}
{\sum_e\lVert \mathrm{bp}(e_{\rm bare}-\bar e_{\rm bare})\rVert^2}\ \ \ge\ \mathbf{30\%}$$

**分母 = 「逐集常数预测墙」的误差**（**不是总 IMU 能量**）。
**按会话汇总**：5 个留出会话各算一个 `redu`，**等权平均**，并**逐会话报告**。

> **通过 ⇔ 平均 `redu ≥ 30%` 且 5 个留出会话全为正。**
> ⚠ **通过只说明机制前提成立，尚未证明响应更容易辨识。**

## 4. 训练配置（**写死**）

| | |
|---|---|
| 输入 | **`x_t = [u_t, Δ⁻u_t, Δ⁻²u_t]`**，**21 通道**，差分**向后**计算（因果）。⚠ **保留绝对指令 `u_t`** —— 现有 `build_inputs` 的前 7 维实际是「减去本 chunk 首帧的**相对**指令」，**本轮不用它**；**旧 π 的特征路径不改** |
| 架构 | **因果**空洞一维卷积：4 层 · `k=5` · `dilation 1/2/4/8` · 64 通道 · GELU ⇒ 感受野 **61 帧（3.05 s）**；`Conv1d 1×1 → 3` |
| ⚠ 因果 | **左侧填充**（与 `PiNet` 的对称填充**不同**）——臂的响应只依赖过去指令 |
| 输出 | `ê_base`（3 轴，20 Hz） |
| 损失 | 带通后 MSE（`bandpass41` 实现为**固定权重** conv1d，可微） |
| 优化 | Adam · `lr 1e-3` · 梯度裁剪 1.0 · 输出头**零初始化**（从 `ê_base ≡ 0` 起步 = 逐集常数基准） |
| 步数 | **3000 步**（每步一整集）· **每折固定取第 3000 步权重** |
| ⚠ 不选最优权重 | **外层留出会话只在最后评分一次**，**不参与模型选择**（「每 200 步评留出保留最优」会让留出参与选择，**已删**） |
| 归一化 | 输入的均值/标准差**只用该折的训练会话**统计 |
| 种子 | `seed = 0`（**不做种子扫描**） |
| 预算 | **≤ 2 GPU·小时**；5 折一次跑完 |

**输出头零初始化 ⇒ 训练起点恰好是 G0 的分母（逐集常数）。**

## 4bis. 两句定位（写准，不阻断实验）

1. **标签**：`L = 3` 下，`e_bare[t] = ω_real[t+3] − ω_ideal[t]`。
   本轮检验的是**对齐墙**的预测。
   ⚠ **左填充不能把「包含整 chunk 渲染参考」的完整 `F_abs` 自动变成
   严格逐帧因果的物理模型** —— `ω_ideal` 由 `IdealChunkRenderer`
   （CubicSpline + `filtfilt`）在**整 chunk** 上渲染，**本身非因果**。
   左填充只保证**学出的 `ê_base` 这一支**因果。
2. **`G-2` 是冻结的已拟合模型，不是零参数物理模型** ——
   它含拟合过的 `rs_fir` / `rq_fir` 权重；**只是本轮不重新拟合它**。
   （前文我两次写成「零参数」，**已订正**。）
