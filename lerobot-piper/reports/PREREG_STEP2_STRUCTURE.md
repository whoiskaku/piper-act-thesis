## §1 候选 F：传动 / 连杆柔性自由度

在关节 `j` 处把执行器留在**电机侧**，连杆侧加一个被动铰：

```
link(j-1) → [link{j}_rotor: joint{j} 电机侧, 带 G-q-v1 的 Ia_j]
             → [link{j}: joint{j}_flex 被动(stiffness K, damping C)] → 下游
编码器读电机侧 joint{j}；IMU 看连杆侧下游 —— 与真机测点位置一致
```

| | |
|---|---|
| 离散因子 | `j ∈ {j2, j3, j5}`（j2 = 臂下垂模载体；j5 = 腕部载体；j3 = 肘） |
| 连续参数 | `ω_f`（Hz）、`ζ_f` |
| 换算 | `K = M_eff·(2πω_f)²`，`C = 2ζ_f(2πω_f)M_eff`；`M_eff` 取模型在 HOME 的质量矩阵对角元 |

**与旧 G-flex 的两处关键不同**：

1. 旧版把电机侧带宽**硬钉在 40 Hz**（`armature = kp/(2π·40)²`）作为数值稳定的
   建模选择。**本版不需要** —— `Ia_j` 已由 G-q-v1 辨识（`Ia2 = 0.4163` kg·m²，
   ωn = √(kp2/Ia2) ≈ 9.5 Hz，`dt = 2 ms` 下稳定）。
2. 旧版基线是 **XML 默认 kp×1**，且**只试了 j2**。本版底座是 G-q-v1，
   并把 `j` 作为离散因子。

> 旧 G-flex 判否（12/24 分组，物理频率处 0/24）是在**关节误差约 1°** 的底座上做的，
> 现在是 **0.3–0.4°** ⇒ **不能直接外推**，这是一个不同的实验。

## §2 候选 B：IMU 支架的二阶旋转模态

现状：`ee_imu_site` 是**直接挂在 `link6` 上的无质量 site**
（`pos="0 0 0.13"`，有径向伸出）—— **支架完全没有建模**：无 body、无质量、无自由度。

```
link6 → [imu_bracket: 继承 site 的 pos/quat, 被动铰(K, C)]
          → ee_imu_site @ (0,0,0)  ← 陀螺/加速度计挂在这里
```

| | |
|---|---|
| 离散因子 | 铰轴 `∈ {bracket x, y, z}` |
| 连续参数 | `ω_b`（Hz）、`ζ_b` |
| 支架质量惯量 | **声明的建模选择**，非辨识量。TSND151 ≈ 22 g，含支架取 `m = 0.05 kg` |

**因为支架很轻，它几乎不反作用于臂** ⇒ 实际上是个**传感器侧的二阶滤波器**，
可辨识量只有 `(ω_b, ζ_b)`；质量只影响它对臂的负载（可忽略）。
**⇒ 必须做质量 ×0.5 / ×2 的灵敏度检查**：若结论随之翻转，该候选不可用。

## §7 结果

代码 `sim/step2_g/structure_compare.py` · 产物 `outputs/step2_g/structure/{grid,gate}.json`

### 7.1 三点收紧的落实

1. **pp2 升级为开发门禁**（条件 4–7），不再只报告。
   A/B 选结构，现有 pp2 作开发门禁；冻结后再用**新采** pp2 做最终确认。
2. **不声称 `Ia` 已被物理辨识**：去掉旧 G-flex 的 `MOTOR_HZ=40` 硬钉，
   改用 G-q-v1 冻结的 `armature` **仅作数值底座**，只称「有效参数」。
   并加了**可解析性判据** `dt·ωn ≤ 0.25`：

   | 关节 | j1 | j2 | j3 | j4 | j5 | j6 |
   |---|---|---|---|---|---|---|
   | 柔性模型电机侧 ωn | 669 Hz | **9.5 Hz** | 248 Hz | **7.3 Hz** | **17.8 Hz** | 66 Hz |
   | `dt·ωn` | 8.41 ✗ | 0.119 ✓ | 3.12 ✗ | 0.091 ✓ | 0.223 ✓ | 0.831 ✗ |

   ⇒ 离散集 = **{j2, j4, j5}**。**被排除的三个是 `Ia` 不可辨识的数值后果，
   不是物理判断**（要用它们得把 `dt` 缩小约 34 倍）。
3. **候选 B 不建物理支架**（0.05 kg 不足以定义转动刚体，缺 COM/惯量/铰点，
   而我们没有支架尺寸）。改建**传感器侧有效二阶模态**：
   `H(s) = (2ζω s + ω²)/(s² + 2ζω s + ω²)`，**只有 (ω, ζ) 两个参数**。
   **不声称辨识了真实支架的物理参数。**
   实现自检：候选 B 的关节输出与 G-q-v1 **逐位相同**（max|Δ| = 0.00e+00）。

### 7.2 训练集选格（只看训练侧）

训练基线 G-q-v1：关节 0.0311 · IMU 0.4836。两候选各 84/84 格满足关节不劣化 5%。

| 候选 | 最优格 | 训练 IMU | vs 基线 |
|---|---|---|---|
| **F 柔性** | **j5**，ω = 8.49 Hz，ζ = 0.40 | 0.4726 | **−2.3%** |
| **B 支架模态** | 轴 **y**，ω = 8.49 Hz，ζ = 0.10 | 0.4775 | −1.3% |

> ⚠ **两者的 ω 都落在网格次高点（8.49 Hz）、F 的 ζ 落在网格最高点** ⇒
> 最优可能在**固定网格之外**。按预注册「固定 168 格、不追加」，**未扩网格**。
> 此为该预算下的已知局限，如实记录。

### 7.4 判定

> **按预注册，两候选都未通过（F 只差条件 4）⇒ 不冻结任何候选。**

**但「两候选在 pp2 上都不改善 ⇒ 立即收口」的触发条件没有满足**：
F 在 pp2 上**确实改善**（聚合 −3.5%、逐集 16/17、中位 +3.9%），
只是聚合幅度低于 5% 的门槛。

三点如实记录：

1. **F 的留出集改善远大于训练集**（训练 −2.3% vs 留出A −8.6%、留出B −22.2%）。
   这不寻常，但可解释：θ* 是按**编码器**拟合的，训练集的 IMU 从未是优化目标；
   而柔性模态的收益取决于激励内容，**留出B（多关节多正弦）受益最大（−22.2%）**
   与「多关节运动更能激起腕部模态」一致。
2. **胜出的是 j5、ω ≈ 8.5 Hz，不是先前假设的 ~3 Hz 腕部余振。**
   「~3 Hz」这一具体假设**未被数据选中**。
3. **ω/ζ 落在网格边缘**，最优可能在固定网格外；按预注册未扩网格。
