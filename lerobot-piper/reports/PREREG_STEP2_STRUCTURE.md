## §1 候选 F：传动 / 连杆柔性自由度

在关节 `j` 处把执行器留在**电机侧**，连杆侧加一个被动铰：

```
link(j-1) → [link{j}_rotor: joint{j} 电机侧, 带 G-q-v1 的 Ia_j]
             → [link{j}: joint{j}_flex 被动(stiffness K, damping C)] → 下游
编码器读电机侧 joint{j}；IMU 看连杆侧下游 —— 与真机测点位置一致
```

| | |
|---|---|
| 离散因子 | `j ∈ {j2, j3, j5}`（j2 = 臂下垂模载体；j5 = 腕部载体；j3 = 肘） |
| 连续参数 | `ω_f`（Hz）、`ζ_f` |
| 换算 | `K = M_eff·(2πω_f)²`，`C = 2ζ_f(2πω_f)M_eff`；`M_eff` 取模型在 HOME 的质量矩阵对角元 |

**与旧 G-flex 的两处关键不同**：

1. 旧版把电机侧带宽**硬钉在 40 Hz**（`armature = kp/(2π·40)²`）作为数值稳定的
   建模选择。**本版不需要** —— `Ia_j` 已由 G-q-v1 辨识（`Ia2 = 0.4163` kg·m²，
   ωn = √(kp2/Ia2) ≈ 9.5 Hz，`dt = 2 ms` 下稳定）。
2. 旧版基线是 **XML 默认 kp×1**，且**只试了 j2**。本版底座是 G-q-v1，
   并把 `j` 作为离散因子。

> 旧 G-flex 判否（12/24 分组，物理频率处 0/24）是在**关节误差约 1°** 的底座上做的，
> 现在是 **0.3–0.4°** ⇒ **不能直接外推**，这是一个不同的实验。

## §2 候选 B：IMU 支架的二阶旋转模态

现状：`ee_imu_site` 是**直接挂在 `link6` 上的无质量 site**
（`pos="0 0 0.13"`，有径向伸出）—— **支架完全没有建模**：无 body、无质量、无自由度。

```
link6 → [imu_bracket: 继承 site 的 pos/quat, 被动铰(K, C)]
          → ee_imu_site @ (0,0,0)  ← 陀螺/加速度计挂在这里
```

| | |
|---|---|
| 离散因子 | 铰轴 `∈ {bracket x, y, z}` |
| 连续参数 | `ω_b`（Hz）、`ζ_b` |
| 支架质量惯量 | **声明的建模选择**，非辨识量。TSND151 ≈ 22 g，含支架取 `m = 0.05 kg` |

**因为支架很轻，它几乎不反作用于臂** ⇒ 实际上是个**传感器侧的二阶滤波器**，
可辨识量只有 `(ω_b, ζ_b)`；质量只影响它对臂的负载（可忽略）。
**⇒ 必须做质量 ×0.5 / ×2 的灵敏度检查**：若结论随之翻转，该候选不可用。

## §8 事后诊断性网格外延 ⇒ **收口**

本节位于原始“固定 168 格、不追加”的主要实验之外，**不回写或改变 §7 的主要判定**。
外延范围先单独提交于 `dfed8ee`，结果后提交于 `c9a486c`，因此它是预算事前固定的
**后续诊断**，不是原始 168 格预注册的一部分。

### 8.1 订正：ω 本来就不在边缘

§7.2 曾写「两者的 ω 都落在网格次高点 ⇒ 最优可能在网格之外」。**那是错的。**
从 `grid.json` 逐点读出：

| F 沿 ω（固定 ζ=0.40） | 1.50 | 2.12 | 3.00 | 4.24 | 6.00 | **8.49** | 12.00 |
|---|---|---|---|---|---|---|---|
| 训练 IMU | 2.6401 | 1.3578 | 0.7858 | 0.5591 | 0.4824 | **0.4726** | 0.4770 |

**8.49 是内点**，两侧都试过且更差。**只有 F 的 `ζ` 真在边缘**
（0.05:0.6434 → 0.10:0.5234 → 0.20:0.4772 → **0.40:0.4726**，单调向上）。
**B 的最优在两维都是内点**（ζ profile 0.4778/0.4775/0.4782/0.4799）
⇒ **B 不外延**，理由是证据而非偏好。

### 8.2 外延设计（固定 83 格，不追加）

`ζ ∈ {0.6, 0.8, 1.0, 1.4, 2.0}` × `ω ∈ {6.00, 7.13, 8.49, 10.10, 12.00}` ×
`j ∈ {j2, j4, j5}` = 75 格；加 j5 的 ω 细化 `{7.13, 10.10}` × 原 ζ = 8 格。

### 8.3 结果：**没有更好的格**

83/83 格满足训练关节不劣化 5%。外延内最优 j5 ω=7.13 ζ=0.40 → 0.4741，
**仍差于原最优 0.4726**。

| 沿 ζ（ω=8.49） | 0.20 | **0.40** | 0.60 | 0.80 |
|---|---|---|---|---|
| 训练 IMU | 0.4772 | **0.4726** | 0.4743 | 0.4761 |

| 沿 ω（ζ=0.40） | 6.00 | 7.13 | **8.49** | 10.10 | 12.00 |
|---|---|---|---|---|---|
| 训练 IMU | 0.4824 | 0.4741 | **0.4726** | 0.4745 | 0.4770 |

⇒ **`ζ = 0.40` 原来只是粗网格恰好结束在那里；外延后 0.60 更差 ⇒ 内点。**
**167 格合并后的最优与外延前逐字相同**：j5、ω = 8.49 Hz、ζ = 0.40、训练 IMU 0.4726。
**网格边缘的疑虑已消除。**

外延前固定的解释约束（`ζ ≥ 0.7` 时不得称「柔性共振模态」）**未触发**
（胜出 ζ = 0.40）。

### 8.4 判定：收口

选中格未变 ⇒ **门禁数字不变，F 仍只差条件 4**（pp2 IMU −3.5% < 5%）。

按这次后续诊断预先固定的终止规则：

> **这是唯一一次外延 ⇒ 收口，不再扩大柔性结构。**

**最终记录**：

| 层 | 结论 |
|---|---|
| 常系数伺服参数（23 个） | **已到顶**（§18） |
| 结构扩展（柔性 / 传感器侧二阶模态） | **两候选均不过门禁；F 是更好的结构但 pp2 只到 −3.5%；最优已在两维夹住 ⇒ 收口** |

**F 的证据如实保留**（它不是"无效"，是"不够"）：
留出A IMU **−8.6%**、留出B **−22.2%**、pp2 逐集 **16/17**、中位 **+3.9%**，
