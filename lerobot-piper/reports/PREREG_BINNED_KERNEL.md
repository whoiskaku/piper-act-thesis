# 预注册 — 位形分箱响应核 vs 固定核（概念验证，零机时）

冻结日期 **2026-09-20**。**在拟合任何分箱核之前写成。**
修改须在 §9 改动记录留条目与理由。

本轮回答的问题（已按能力收窄）：

> **这个预先指定的两箱模型，是否比固定核具有可复现的预测收益？**

通过 ⇒ 支持**这一种**位形调度；**不通过不能否定所有位形依赖**，
只表示本轮没有证据支持增加复杂度。

## 2. 两个模型（除核的结构外，其余一切相同）

### 2.0 ⚠ 本轮预测的是什么：**只比响应核，`G-2` 不进拟合、也不进评分**

$$\widehat{\mathrm{gap}}_m \;=\; H_m \circledast \delta a$$

$$E_{m,e}\;=\;\frac{1}{3\,T_e}\,
\bigl\|\operatorname{bp}\!\left(\mathrm{gap}_e-\widehat{\mathrm{gap}}_{m,e}\right)\bigr\|_F^2$$

分箱模型**按输入时刻选核**（见下方「位形指标」）。拟合仍沿用原有的**逐集常数**处理。

> **`G₂(u) + K_φ ⊛ δa` 标为「后续组合形式」，不是本轮已评价的完整模型。**
> 加入 `G-2` 之后还必须改变拟合目标，那已经不是当前约定的**核比较**了。
> 本轮报告里**不得**把结论表述成「对 `ω̂ = G₂ + K⊛δa` 的评价」。

| | 固定核 | 分箱核 |
|---|---|---|
| 形式 | `ĝap = H ⊛ δa` | `ĝap = H_{b(t−τ)} ⊛ δa` |
| 参数 | `H ∈ ℝ^{16×3×6}` = 288 | `{H₀, H₁}` = **576** |

### 2.0.1 评分口径（写死）

| 项 | 取值 |
|---|---|
| **有效帧** | 丢弃每集**首尾各 20 帧**。头部 20 ≥ `N_LAGS−1 = 15`（因果设计矩阵零填充历史）**且** ≥ 滤波半窗 20；尾部 20 = 滤波半窗。`T_e` = 剩余帧数 |
| **滤波边界** | `bandpass41` 是 41 抽头**中心** FIR、`mode="same"` ⇒ 两端各 20 帧被零填充污染，由上一行丢弃 |
| **去均值顺序** | ①`res = gap − ĝap`（raw 对齐空间）→ ②扣除**该集**的 `res` 常数（在**全集**上算）→ ③`bandpass41` → ④取有效帧 → ⑤算能量。①②③线性可交换，顺序写死只为可复现 |
| 归一 | `E` 除以 `3·T_e` ⇒ **每帧每轴**的均方，集长不同也可比 |

> ⚠ **验证集上的去均值只是「离线评分处理」。**
> 它用到了该集自身的数据，**不是部署时可获得的信息**。
> 报告里**不得**把由此得到的 `E` 说成「部署可达的误差」。
> （沿用它是为了与 `fit_H` 的 nuisance 处理一致，使两个模型同口径。）

**位形指标（已写死，不得改）**

```
s[t] = q̄₂[t] + q̄₃[t]          q̄ 取名义指令 chunks[].raw（不含 δa）
分界 = 仅由 P1 的名义指令算出的中位数 = +0.10234 rad
b(t) = 1{ s[t] ≥ +0.10234 }
```

- **不**依据 IMU、拟合收益或 P2/P3 调整分界。
- ⚠ 这只是一个**预先选定的位形指标**，**不是已证实的主导物理变量**。
- **在输入发生时选箱**：滞后 `τ` 的输入 `δa[t−τ]` 用 `b(t−τ)`；
  **不得**把不连续的同箱片段拼接后再卷积。

**两个模型必须完全一致的项**（否则比较无效）：

| 项 | 取值 |
|---|---|
| 时序对齐 | `gap[t] = real[t+L] − ideal[t]`，`L = ALIGN_L = 3` |
| 滞后数 | `N_LAGS = 16` |
| 背景处理 | **逐集常数**作 nuisance 从两侧扣除（与 `fit_H` 一致，**不是**带通） |
| 拟合空间 | raw aligned gyro gap |
| 评价滤波 | `bandpass41`，`METRIC_BAND = (0.5, 9.0)` |
| **`j4` 处理** | **两个模型都保留全部 6 个关节输入** |
| 标定 | 冻结 sidecar 的 `R`, `b` |

### ⚠ `j4` 的两件事必须分开

1. **辨识时不删已有探针里的 j4 响应** —— 数据确实激励了它（P1/P2/P3 六关节全激励）。
   固定核与分箱核**必须一致地处理这一路**，避免它污染其余关节的比较。
2. 「**新部署候选固定 `δa_j4 = 0`**」是**实验范围选择**，
   **不是**断言 H 没有 j4 信息，且**与本轮辨识无关**。
   C / D / D′ **保持原样**；事后去掉 j4 就是新候选，**不能沿用旧结果**。
3. ⚠ **通过只能证明「六输入分箱模型有预测收益」。**
   **收益可能来自 `j4`** ⇒ **不能**据此推出「固定 `δa_j4 = 0` 的五关节部署候选也会获益」。
   若要那个结论，必须**另做**五输入的拟合与评价（不在本轮）。

### 正则化：在 **P1 内部**选，两个模型各自选

P1 的角色含「内部选参」。两个模型**各自**在 P1 上做
**leave-one-seed-out 交叉验证**（8 折，按种子分），
在与冻结 sidecar 相同的 ridge multiplier 网格上，
选使**留出种子**的 0.5–9 Hz 预测误差最小的那一个。

> 理由：**同一个 multiplier 对两个模型未必对应相同的有效正则化强度，可能影响比较。**
> 各自选参是为了给两个模型**相同的机会**，不是断言哪一方会吃亏。
> **选参只看 P1，绝不看 P2/P3。**

**写死的三条**：

| | |
|---|---|
| **网格** | `RIDGE_GRID = (1e-3, 1e-2, 1e-1, 1.0, 10.0)`（`fit_step1_candidate.py:75`，两个模型**同一个**） |
| **折划分** | P1 的 **8 个种子** leave-one-seed-out，**两个模型同一套折**；选参指标 = 留出种子的 **0.5–9 Hz `E`**（与 §2.0 同一公式） |
| **平局** | CV 误差相等时取**更大**的 multiplier（更强正则化，保守侧） |
| **边界** | 若选中落在网格端点（`1e-3` 或 `10.0`），**照实报告并就此打住，不外延网格**。⚠ 冻结的 `H` 选中的正是下端点 `1e-3`，所以这条大概率会触发 |

## 3. 主判据（P2）

**主指标 = P2 的 0.5–9 Hz 预测误差削减**

```
        E_固定核,s  −  E_分箱核,s
d_s  =  ─────────────────────────          s ∈ {2000, 2001, 2002}
              E_固定核,s
```

- `E_{m,s}` = 该种子**两集**的 0.5–9 Hz 预测误差，**先对两集取平均**；
- 再对**三个种子等权汇总**得 `d̄`；
- **必须同时报告三个 `d_s`，不能只报总平均。**

### ⚠ `E` 是什么 / 不是什么

`E` 是对**观测总 gap** 的预测误差，公式与有效帧/去均值顺序见 **§2.0 / §2.0.1**。

> **不得**称它为「已分离的真实增量误差」。
> `gap` 含任务基线 `e_base`，而 `e_base` **不可观测**
> （`AUDIT_2026-09-20_exogeneity_chain.md` §〇）。

### 分频与辅助诊断

- **0.5–3 Hz** 与 **3–9 Hz** 分别报告（除主指标的全带外）。
- **辅助**（不参与判决）：`beta_ols`、逐关节残差—探针相关。
  ⚠ `beta_ols` 是**过原点的投影尺度**；真实响应若有两个正交分量而模型只抓到一个，
  **β 仍可为 1**，故它**不能独自判定**。

### 通过门槛（事前写死）

> **通过** ⇔ 三个 `d_s` **全为正** **且** `d̄ ≥ 5%`。
> 其余一律记为**不通过**。

`5%` 的来源：这是**事前拍的筛查阈** ——
**是「是否值得投入后续工作」的筛查标准，不是统计显著性、也不是可辨识性证明。**
理由只有一条：低于这个量级即便为真，也不足以支撑把参数量翻倍。

> ⚠ **不得**拿真机的 `C−A = −8.0%` 来支撑这个 5%。
> **「预测误差下降 5%」与「控制后真机误差下降 8%」不是同一个指标，不能互相换算。**

### ⚠ 本轮是**开发筛查**，不是确认性检验

P2 只有**三个独立种子**。
**不把帧当独立样本**，**不靠数千帧制造很小的 p 值**。
判据就是上面的效应量 + 三个种子的符号一致性，**不报 p 值作为主判据**。

## 4. 次要判据（P3）：跨幅值压力验证

同一个**由 P1 拟合**的分箱核，在 P3 上按同样口径算 `d_s`（4 个种子），报告 `d̄_{P3}` 与四个 `d_s`。

**P3 必须使用日志中的实际（裁剪后）请求补正 `frames[].da`，
不得按「严格 2× P1 波形」代替。**
依据：`make_probe` 在**生成时**就按 `ε = 10 mrad` 裁剪，P3 有 **0.14%** 的帧触界
⇒ 与 P1 **并非严格成比例**（审计 §1）。实现时须断言
`da == make_probe(seed, 3.0)[:n]` 而**不是** `2 × make_probe(seed, 1.5)[:n]`。

### P3「有收益」的数字定义（与主判据同标准）

> **压力验证通过** ⇔ **四个** `d_s` **全为正** **且** `d̄_{P3} ≥ 5%`。

其他情况**照实报数**，**不以「均值略大于零」替代通过**。
P3 仍**不能挽救** P2 主判据，也**不直接授权部署**。

### 事前定死的判读规则

| P2 | P3 | 只能这样报告 |
|---|---|---|
| 有收益 | 有收益 | 支持进入**独立确认**；**仍不直接授权部署** |
| 有收益 | 无收益 | 「**小幅值开发条件下有收益，跨幅值未获支持**」 |
| 无收益 | 有收益 | **不能用 P3 挽救主判据** ⇒ 记为主判据不通过 |
| 无收益 | 无收益 | 不通过 |

> **若下一步要声称模型覆盖 3 mrad RMS，`P3` 就必须成为该范围的必要门禁**，
> 不能仍以「辅助」略过。

## 5. 事前预测（跑之前写下，用于事后判读）

依据 2026-09-20 的审计：

1. **`d̄_{P2}` 点预测 ≈ +3%，区间 0%~+10% ⇒ 大概率不过 5% 的筛查阈。**
   依据：审计在 P2 上**发现**了 H 未解释、且两箱间有差异的结构（p=0.004），
   所以预期 `d̄ > 0`；但对比图样的层内跨 seed 一致性只有 **cos +0.139**，
   ⇒ 可利用的共同成分方向一致性低。
2. **`d̄_{P3} < d̄_{P2}`，且可能 ≤ 0。**
   依据：P2 与 P3 的对比图样 **cos 仅 +0.085**（两个折外层之间最低，审计 §3.2）。
3. 三个 `d_s` **同号**的可能性中等（审计里最强格逐 seed 同号，但整张图样不是）。

⚠ 这些是**预测，不是门槛**。门槛只有 §3 那一条。

## 6. 口径与措辞约束（引用时必守）

- **不得**写「外生性通过／失败」。`e_base` 不可观测，
  `r_H = e_base + (Δω_real − H⊛δa)` 两项不可分离。
  残差诊断只许写「**发现／未发现 冻结 H 尚未解释的探针相关结构**」。
- **不得**由「两箱都有帧、种子且 RMS 接近」推出「辨识覆盖充分」。
  它只排除**空箱**与**明显的幅值失衡**，
  **不能**排除条件内的频谱／方向激励不足或设计矩阵秩不足。
- **不得**把图样余弦换算成能量份额（`cos ≈ 0.14` ≠「共同成分占 14%」）。
- 置换 p 值用 `(k+1)/(B+1)`，**B 次置换报不出 `p = 0`**。
- 本轮的对象是「**请求补正** `δa_req`」的响应 —— 日志无伺服指令回读。
- **排除一个候选 ≠ 证明另一个候选。**
