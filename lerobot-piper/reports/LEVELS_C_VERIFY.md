### 三项阻断测试定位

| 测试 | 结果 | 判读 |
|---|---|---|
| 3 · 组间复相关 | 非对角均值 **0.336**，最高 g2–g6 **0.957**、g1–g6 0.905 | **共享 A-run block** |
| 1 · 逐组独立高斯 | 0.866–1.230（均值 1.06） | 管线正确 |
| 2 · 训练组不变、留出换新独立噪声、**参数不动** | 0.815–1.168（均值 1.02） | 不是训练残差、不是外折再选超参 |

⇒ 根因 = **同一 A-run block 被复用到所有 key**：`noise_rows` 让每个 key 共用同一个
`nb` 数组，`make_obs` 每次只抽**一个**块索引作用到全部 key。

### 修复：显式 session + run 两层噪声

- **session** = 采集轮次（r1: A1/A2，r2: A3/A4，r3: A5/A6）—— 同轮共享漂移
- **run/window** = 轮内窗口 —— 近似独立

`draw_noise`：先抽 session（**在 key 之间共享**），再为每个 key **独立抽轮内窗口**。

## 关键区分：100 trial 里的 g0 偏高**不是**由 shape error 造成的

那批观测**根本没有 shape error**。同口径（无 shape、仅注入信号）的拆解是：

| 维度 | 分解 |
|---|---|
| 陀螺轴 | **轴0 = 2.191**，轴1 = 0.368，轴2 = 0.441 |
| 频率 | 6.0 = 1.195，6.5 = 0.902，7.0 = 0.871，7.5 = 1.032（近似平坦） |

**轴结构与 shape 情形正好相反**（轴0 主导 vs 轴1 主导），频率也平坦。
⇒ 100 trial 中 g0 偏高来自**注入扰动 Aη 在 g0 行上的投影更大**，
是该工作点的模型响应属性，随层级升高而衰减（L0 25.2 → L3 2.0）。

**两条机制不同，不能混为一谈**：
- 无 shape 时的 g0 偏高 = 注入信号在该工作点响应更强（轴0）
- 有 shape 时的 g0 偏高 = 该工作点对失配更敏感（轴1 / 6.5·7.5 Hz / j2）
