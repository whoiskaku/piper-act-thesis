# `K_φ` 候选设计表（**只为选一个**，不拟合）

2026-09-27。**本表的唯一用途：选出一个新候选，进入固定预算的开发验证。**
**不先把所有路线跑完再挑。** 本轮**不做任何拟合**。

## 0. 共同形式（用户 2026-09-27 定）

$$K_\phi(\bar q)=H_0+\Delta K_\phi(\bar q)$$

- `H₀` = 固定核（现有形式，`16×3×6 = 288`）
- **`ΔK_φ` 必须能退回零** ⇒ 退化为固定核。检验的是
  「**平滑、受约束的变化能否带来收益**」。
- **低秩不是与位形并列的方向**：**位形决定响应随什么变化，低秩限制可学习容量。**
- 预测量与评分沿用已冻结口径（`PREREG_BINNED_KERNEL.md` §2.0 / §2.0.1）：
  `ĝap = K ⊛ δa`，`G-2` **不进拟合也不进评分**。

### 两条边界（写在前面，防止误用）

1. **`cos = 0.085` 只说明「那一组残差图样跨折外层一致性低」，
   没有否定所有位形参数化。** 它是**事前风险提示**，不是判决。
2. **本轮不按低频收益另开频带路线，也不启动幅值扫描。**

### ⚠ 容量的判定方式

参数量**只作规模描述**。
**容量是否合适，由 P1 内部的 leave-one-seed-out 交叉验证决定，
不用任何「有效方程数 ÷ 参数量」之类的比值判定**（该估算此前已撤回）。

## 1. 三个候选

### 低秩的具体实现：**预设基**（凸）

为保持**凸性**与**可复用现有 ridge 机制**，`ΔK` 不用 CP 分解（非凸、有局部极小），
而是约束在一个**预先指定的小基**里：

$$\Delta K[\tau,a,j]=\sum_{p=1}^{P}\sum_{q=1}^{Q}\ c_{pq}\;L_p[\tau]\;M_q[a,j]$$

- `L_p[τ]`：**滞后剖面基**，`P = 3`（平滑、短滞后为主；与 `H` 的 lag 0–3 集中一致）
- `M_q[a,j]`：**(轴,关节) 方向基**，`Q = 4`，取自**该折内重拟的 `H₀`** 的前 4 个奇异方向
- ⇒ **`ΔK` 只有 `P×Q = 12` 个系数**，且对 `c` **线性** ⇒ 仍是 ridge

> 对照：已判否的两箱核是**不连续**地把参数从 288 **翻倍到 576**。
> 本设计是**连续**地在 288 之上**加 12**，并向零收缩。**这是不同的赌注，不是重跑。**

## 2. 设计表

| | **① 固定核（基准）** | **② 不随位形变化的低秩核** | **③ 连续位形调度的低秩核** |
|---|---|---|---|
| **要回答的问题** | 基准 | **单靠结构约束能否改善泛化** | **位形信息是否提供额外预测收益** |
| **公式** | `ĝap[t] = Σ_τ H₀[τ] δa[t−τ]` | `ĝap[t] = Σ_τ (H₀[τ] + ΔK[τ]) δa[t−τ]` | `ĝap[t] = Σ_τ (H₀[τ] + g(s[t−τ])·ΔK[τ]) δa[t−τ]` |
| **`ΔK` 定义** | — | `ΔK = Σ_pq c_pq L_p M_q` | 同②，外乘连续标量 `g(s)` |
| **`g(s)`** | — | — | **预先固定**：`g(s) = (s − s̄)/σ_s`，`s = q̄₂+q̄₃`（名义指令）；`s̄,σ_s` **只由 P1 算** |
| **退回固定核** | 本身即是 | `c = 0` ⇒ `H₀` ✓ | `c = 0` ⇒ `H₀` ✓ |
| **参数量** | **288** | 288 **+ 12** | 288 **+ 12** |
| **模型输入** | `δa` | `δa` | `δa` + **`q̄`（名义指令）** |
| **输入可得性** | — | — | `q̄` 来自 ACT chunk，**chunk 生成时即全部已知** ⇒ 训练 π 时可得 ✓ |
| **对 `δa` 可微** | ✓（线性） | ✓（线性） | ✓（线性；`g(s)` 与 `δa` 无关，是已知系数） |
| **因果性** | ✓ 只用 `δa[t−τ]`，`τ≥0` | ✓ 同左 | ✓ 同左；**调度量取输入发生时的 `q̄[t−τ]`**，不用未来位形 |
| **凸性 / 局部极小** | 凸，无 | **凸，无** | **凸，无**（`g(s)` 已知 ⇒ 对 `c` 仍线性） |
| **P1 内部选参** | ridge `λ_H`；8 种子 leave-one-seed-out；网格 `RIDGE_GRID` | **两个 ridge**：`λ_H`（H₀）+ **`λ_Δ`（ΔK，向零收缩）**；同一套折；同一评分 | 同② |
| **`H₀` 的处理** | 折内重拟 | **折内与 `ΔK` 联合重拟**（避免用全 P1 拟的 `H₀` 泄漏进留出种子） | 同② |
| **计算预算** | 秒级（一次 ridge） | **秒~分钟级**（网格 5×5 × 8 折） | 同② |
| **主要失败风险** | — | **约束不 binding**：若 `H₀` 本身已近低秩，`ΔK` 学不到东西 ⇒ 结果是「没差别」，**信息量低** | **位形信号弱**：审计**没有**给出正面证据；`s` 仍是**预选指标、非已证实的主导变量**；若 ② 已无收益，③ 的增量更难显现 |
| **次要风险** | — | 基 `M_q` 由折内 `H₀` 的 SVD 定 ⇒ **基本身随折变**，须固定取法并记录 | `g(s)` 的中心/尺度只由 P1 定，**不得**按 P2/P3 调 |

## 3. 三者的关系（决定了它们**不是**三条要各跑一遍的路线）

**② 是 ③ 的零调度特例**（`g ≡ 1` 时 ③ 退化为 ②）；**① 是二者的 `c = 0` 特例。**

⇒ 选 **③** 即可**同时**得到 ①②：在同一次 P1 内部 CV 里，
`λ_Δ → ∞` 给出 ①，`g ≡ 1` 给出 ②。**不需要分别立项。**

> 用户的初始偏好是「连续位形调度 ＋ 低秩约束 ＋ 向固定核收缩」——
> 即 **③**。上表给出它的完整定义、与 ①② 的嵌套关系、以及事前风险。
