## 1. 研究对象与最低契约

### 1.1 Step 2 要构建什么

Step 2 的对象是一个**能从标定数据自动估计真实系统动力学参数、再执行前向 rollout
的动力学模拟器**。暂称第一版为 `G0`：

```text
phi = Calibrate(D_cal; fixed_schema, fixed_bounds, fixed_algorithm)

(q_hat[0:T], qdot_hat[0:T], imu6_hat[0:T])
    = G0_phi(x0, command[0:T], t_send[0:T], environment)
```

其中：

- `phi` 是由固定标定程序从 `D_cal` 自动产生的参数及必要的传感器/时序标定量；
- `x0` 是 rollout 开始时允许获得的初始状态；
- `command[0:T]` 是完整的控制指令时序，不是单个扰动或摘要；
- `t_send[0:T]` 是指令发送时间；`environment` 是预先声明的环境、安装与负载条件；
- 输出至少覆盖关节位置 `q`、关节速度 `qdot` 与 6 轴 IMU（3 轴加速度、3 轴角速度）。

验证/测试 rollout **不得读取起点之后的真实关节状态或真实 IMU**，不得用未来实测量
作 teacher forcing、误差反馈或重置，也不得逐集搜索延迟、增益或其他参数。测试集上
唯一允许的计算是：用冻结的 `Calibrate` 得到一次 `phi`，以预先允许的 `x0` 和输入
执行前向预测，再按冻结指标评分。

### 1.2 不是什么

`G0` 不是旧的 `H`、modal `G-hat` 或只预测 `delta-a` 的响应核，也不是为每个测试 episode
重新拟合的回放器。旧模型可以做开发基线，但不能借名称变化成为 Step 2 的目标模型。

“可自动标定”至少要求：相同格式的数据输入同一个非交互程序，程序按冻结的参数模式、
边界、目标函数和优化/推断算法输出 `phi`；不得由操作者看结果后逐数据集手调参数。

## 3. 数据角色与防泄漏规则

建议冻结时明确四类互斥角色：

| 角色 | 用途 | 可否影响模型/阈值 |
|---|---|---|
| `legacy_development` | 调试、提出候选参数化、估算量级 | 可以，但永不进入最终检验 |
| `D_cal` | 自动标定 `phi` | 仅通过冻结的 `Calibrate` |
| `D_dev` | 选择冻结前的模型族、损失与算法 | 可以；选择完成后封存决定 |
| `D_test` | 最终一次性验证 | 不可以；揭盲后不得回写模型 |

冻结版本必须规定数据划分单位（至少避免同一轨迹、相邻切片、同一随机激励实例跨集合），
并在查看 `D_test` 结果前固定数据清单与 SHA-256 manifest。若会话漂移可能造成近重复，
优先按完整 session 或独立命令实例分组切分，而不是逐帧随机切分。

禁止的泄漏包括但不限于：

- 用 `D_test` 选择参数边界、模型结构、滤波、延迟、损失权重、优化器或 checkpoint；
- 在测试 episode 内逐集对齐/搜索最佳 lag，或用真实未来状态重置模拟；
- 将已经看过的 Step 1/B′/C 数据改名为 `D_test`；
- 因结果不理想而替换测试集、删集或改变聚合方式；
- 先看未盲化标签再决定哪些工况属于“域内”。

任何需要测试反馈的改动都必须产生新版本；原 `D_test` 随即降格为下一版本的
`legacy_development`，新结论需要全新的、未查看的测试集。

## 5. 第一里程碑 M0：零新增机器人时间

M0 是 Step 2 当前唯一获准开展的执行阶段。它不采集新真机数据，目标是先证明研究契约
能在已知答案的合成系统上运行，而不是直接追求真实数据上的好看误差。

### M0.1 参数 schema、边界与 gauge

建立机器可读的参数 schema，至少逐项声明：名称、单位、物理含义、初值、上下界、
是否自由、变换方式与共享关系。候选参数族可包括刚体惯量、关节摩擦/阻尼、执行器/伺服
参数、命令与传感器时延、编码器零位、IMU 安装变换/偏置/尺度和噪声模型；**最终自由集
尚未批准**。

冻结前必须处理不可辨识性/gauge，例如惯量与力矩尺度、世界/传感器姿态、编码器零位、
时间原点与多个延迟项之间的混淆。处理方式只能是固定 gauge、独立测量、参数共享或明确
不估计；不得把不可辨识方向留给优化器任意漂移后再解释为物理参数。

### M0.2 统一标定 harness

实现一条非交互流水线：

```text
raw logs + immutable manifest
  -> validated/calibrated input artifact
  -> Calibrate
  -> phi artifact + diagnostics + provenance manifest
  -> frozen forward rollouts
  -> metrics report
```

同一输入、配置、代码提交和随机种子必须产生可复现结果。原始数据永不原位改写；所有
派生物记录父 manifest、代码 commit、依赖版本、配置哈希与随机种子。

### M0.3 合成恢复与密封合成 holdout

构造参数已知的合成生成器，分开生成 synthetic calibration/development 与密封 synthetic
holdout。开发者可在前两者上调试，但在冻结算法前不得查看 holdout 的真实参数或标签汇总。
测试至少覆盖：

- 无噪声条件下的参数/预测恢复；
- 预注册噪声、采样、延迟与缺帧条件下的 rollout 恢复；
- 参数位于边界附近与多个预定域内工况；
- 故意不可辨识的反例，确认程序能报警或按固定 gauge 返回，而非伪造唯一解；
- 与冻结基线在同一 synthetic holdout 上比较。

合成生成器、真值抽取、密封方式、随机种子生成规则和揭盲流程均须在 M0 运行前写定。

> **当前实现边界（M0a）**：仓库中的 `sim/step2_g/` 目前只完成已知二阶系统上的
> schema/bounds/gauge、可辨识性检查、角色隔离 API、可复现 artifact 与防覆盖机制。
> holdout seed、标签和评分仍在同一进程/仓库内可见，也可换代码后重跑，因此它不是本节
> 所说的密封 holdout。M0.3/M0.4 尚未执行、尚未通过。真正密封版须把冻结 artifact 与
> 外部 evaluator 拆成两阶段，由 evaluator 外保管 seed/标签，并核验冻结 manifest、源码
> 与 calibration artifact hash 后只执行一次揭盲。

### M0.4 M0 完成条件（阈值 TBD）

M0 至少交付：schema/bounds/gauge 文档、raw-log 到 artifact+manifest 的可运行 harness、
synthetic recovery 报告、sealed synthetic holdout 报告、重复运行一致性测试、参数敏感度/
可辨识性测试，以及已知失败模式清单。数值通过阈值未定，因此当前不能宣称 M0 通过。

## 7. 候选评价指标与通过逻辑（全部 TBD）

指标必须同时评价整段 rollout，而不只评价单步拟合。候选指标包括：

- `q`：逐关节/聚合的 RMSE 或按冻结动态范围归一化的误差；
- `qdot`：逐关节/聚合误差；
- IMU：6 轴时域误差，并分别报告加速度与角速度；
- 频域：冻结频带内的谱误差/相干性，用于暴露相位与共振错误；
- 长时稳定性：误差随 rollout horizon 的增长及数值发散/非物理状态率；
- 相对基线改善：G0 对运动学、当前 XML 和旧 modal 基线的配对差异；
- 自动标定稳定性：跨初始化/种子/校准子集的参数与预测变异。

冻结版本须为每个主指标写明单位、预处理、滤波、时间对齐、episode 内聚合、episode 间
聚合、置信区间/多重性处理和**数值通过阈值**。当前不得用“明显更好”“足够准确”或
事后挑选最好轴/频带替代阈值。

通过逻辑建议分层，但尚未批准：

1. 工程有效性：无泄漏、无非物理 rollout、复现检查通过；
2. 绝对准确性：所有预定主输出达到冻结的误差上限；
3. 相对价值：对冻结基线达到预定改善且不以其他主输出恶化为代价；
4. 泛化：在未用于标定的域内命令/会话上保持上述标准。

任何一层的正式判定、容忍非劣边界及多指标门控方式均为 TBD。

## 8. 安全、失败与停止规则（冻结清单）

M0 只运行离线/仿真，不发送机器人指令。M1 前至少冻结：

- 允许的关节位置、速度、加速度/jerk、指令增量、工作空间与自碰/环境碰撞边界；
- IMU、执行器状态、急停、NaN、通信超时、缺帧与时间戳异常门；
- 每个激励的启动检查、在线停止条件、人工急停权限和安全恢复流程；
- A 类技术失败与 B 类安全/系统失败的定义、是否入分析、是否/如何原位重跑；
- 重复录制、部分轨迹、启动重试、退出期崩溃和操作者干预的记账规则；
- 会话/温度/重启状态记录，以及达到时间、失败或安全上限时的预定停止规则。

安全停止不因统计平衡而延迟。任何越界样本必须保留审计记录，不得静默删除。
