## 1. 任务与评价框架

模块 B（IMU 在环学习残差）的骨干选型。训练目标 = 模仿 DAgger round-0 标签
δa\*（`outputs/p2_labels/`，17,748 帧，pp2/ins 两 deploy 数据集）。

- **主指标**: 未见集(每数据集 ep8-9)标签拟合 RMS = √mean((δ̂−δ\*)²)，mrad；
  四切片: 全帧 / 活动帧 / 接触窗 / 分任务。
- **副轴**: 参数量、CPU 单帧延迟、种子稳定性、收敛速度、可解释产物。
- **公平性**: 同数据(按集切分防泄漏)、同输入流(45维/步)、同输出头(tanh×ε, ε=10mrad)、

- **预注册裁决**: 须赢 predict-0 与 ridge; 种子带不重叠才算赢; 平局取简单/小/快者;
  小胜即定案; 单切片夺冠不算。

## 3. 家族结论与论文素材

- **平台效应(本轮最大发现)**: 六种异构架构(FIR深/浅、LSTM/GRU、TCN+Attn、IIR)
  全部收敛于 0.68–0.73 → **瓶颈在标签信息上限, 不在架构**; 下一 mrad 在标签质量
  (逐关节增益、DAgger 迭代)而非网络。
- 定量消融: 门控值 ~0.07 mrad(RNN→GRU/LSTM); 深度值 0.6%(TCN→deep);
  注意力 ≤0(两面: 纯Transformer差26% + TCN加Attn微退化); 选择性为负(S4D→Mamba);
  结构先验两极夹逼(Gray-box 0.95 ↔ MLP 0.73, 最优在中间)。
- 信号三段式: 1.83 = 线性41% + 非线性/时序21% + 当前不可学残余38%。
- 参数量与成绩无关(3.9k 与 101k 同带; 965 与 43.5k 同尾)。
- S4D 侧证: 可解释极点自发对齐实测共振 3.7Hz。
- MLP-window 谦逊注: 纯窗口展平离赢家仅5% — 大部分信号在当前0.8s窗的静态映射。

## 4. 评价边界(引用本报告时必须带上)

1. 全部为**标签拟合**口径; 真实校正效果与"平台里多少是标签噪声"只有真机三臂A/B能答;
2. 验证集4集(种子带+四切片缓解, 未消除);
3. 延迟数含实现债(Gray-box 292µs 为 python biquad 循环, 非架构属性);
4. 同"优化步数"而非同"墙钟"(方向利慢者, 慢者仍败 → 结论稳健);
5. 预览特征在边界附近~8%帧乐观(round-0 正式训练以 boundary-hold 修正)。

## 5. 判决

**TCN**(3层因果膨胀卷积 45→32, d=1/2/4, 感受野0.75s, tanh×ε 头; 10.8k参数; lr 5e-3)。
部署训练附加: 谱归一化(Lipschitz 不变量)+输出平滑正则+边界预览hold。
后备: TCN-deep(接触段指标日后关键时)。Mamba 预备队关闭。

# §7 race3 — 修复 apply_G 后的正式重赛（2026-07-21）· §6 及以前全部作废

## 7.1 为什么又重赛：apply_G 三处 bug

逐行讲解代码时发现 `train_pi_e2.apply_G`（π 的对练场）与被验收的 Ĝ **不是同一个模型**：

| # | bug | 后果 |
|---|---|---|
| ① | 漏 `FlexL2` 的 `D` 直通项 | 占柔性层输出 42–48%；逐关节符号不同（j2 低估 27% / j5 **高估 75%**）|
| ② | 核用解析二次差分推导 | 比训练路径的样条精确二阶导**晚 1 帧**，且丢掉 `filtfilt` 的 ~5% 非因果能量 → `psi` 自始至终是错的 |
| ③ | 激励核与谐振核**预乘成单核** | 迫使 α 退到输入端，而训练时 α 夹在两次卷积**之间** → 数学不等价（实测 80–108%）|

修法：核改**数值探针**（直接拿训练路径的 `excitation()` 打脉冲量，线性算子的脉冲响应即算子本身）＋ 模态改两段式保留 α 的位置。

**新增回归测试** `sim/verify_apply_G.py`：判据 = `apply_G` 必须逐点等于训练路径算出的
Ĝ(a+δa)−Ĝ(a)。修前最坏 149%，修后 **0.222% / 相关 1.00000 / δa≡0 恒等精确**。
另有单文件参考实现 `sim/g_model.py`（三重自检 PASS，最坏 0.224%）。

## 7.4 结论与边界

- **π v1 骨干 = TCN-deep**（3 层→5 层膨胀卷积，感受野 63 帧≈3.15s，34.7k 参数）。

# §8 骨干终审（2026-07-22）— **π v1 = TCN**（§7 的 TCN-deep 结论在新条件下不成立）

## 8.1 为什么复核

§7 的 race3 是在 **old16 + β=1000** 下判的。此后默认配置改为 **new25 + β=300**
（数据 +56%、力度价松 3.3×，见 `finding_caliber_audit_task_gap` / `ab_expand.json`）。
本项目已两度出现"条件变→排名变"（标签任务↔闭环、含bug Ĝ↔修复后 Ĝ），故按先例复核。

## 8.2 结果（new25 + β=300，TCN/TCN-deep 各 5 种子，S4D/Transformer 3 种子）

| 骨干 | pp2 | ins | fork | 最差成员(pp2) | 参数 | 部署改动 |

| **TCN ◀ 当选** | 14.64±0.56 | 43.91±1.14 | 12.33 | 13.48 | **11,334** | **零** |

差值（标准误口径）：pp2 **+0.87pp (1.46σ)** · ins **−0.67pp (1.14σ)** · fork **+0.78pp (2.10σ)**。

## 8.3 逐条适用预注册规则

- ① 须胜底线：TCN-deep / TCN / S4D 全过。
- ② **带交叠或小胜 → 取更简单者**：pp2、ins 均不显著（1.46σ / 1.14σ），且**方向相反**
  （TCN-deep 赢 pp2，TCN 赢 ins）。TCN 参数少 **3.1×**、部署**零改动** → 指向 TCN。
- ③ 种子稳定性：TCN pp2 标准差 0.56 vs TCN-deep 1.22（**稳 2.2×**）。
- ④ 饱和率：全员 0%，无红旗。
- ⑤ **单指标夺冠不算**：TCN-deep 仅在 fork 上达 2.10σ（唯一显著项），pp2/ins 均不显著且
  ins 落后 → **未横扫**，不构成推翻规则②的理由。

**判决：π v1 = TCN**（3 层因果膨胀卷积 51→32，d=1/2/4，感受野 15 帧≈0.75s，
tanh×ε 头，dropout 0.1，11,334 参数）。权重 `outputs/p2_pi/pi_tcn_s{0..4}.pt`。

## 8.4 翻盘的解释与保留项

- **为何翻盘**：race3 条件下深模型的容量优势买的是"从少数据里多榨"；数据 +56% 且力度
  放松后，浅模型追平，同时 TCN 的种子方差显著更小（已"吃饱"、训练良态）。
- **保留项**：TCN-deep 在 **fork 变体**上显著更好（+0.78pp, 2.10σ）——若后续跨任务泛化
  （P4）成为主要目标，应重新评估；本次以"部署简洁 + 主任务打平"取 TCN。
- **口径**：全部为模型内（Ĝ 判卷）；真实排序由三臂真机 A/B 终审。
