# 预注册 — Step 1 v2：真机在环直接优化（无 G、无 H、无求逆）

冻结日期 2026-08-19。**在采集任何 v2 数据之前写成。** 修改须在下方改动记录留条目与理由。

---

## 0. 与 v1 的关系：整条模型路线停用

v1（`PREREG_STEP1.md`）走的是「辨识响应 `H` → 求逆 → 生成补正」。它被自己的离线闸门判否
（2.65% < 8%，`STEP1_RESULT_v1.md`）。

**更重要的是定位错了**：指導教員对 Step 1 的要求是

> 1. 先不用 G
> 2. 直接根据真机 IMU 结果学习补正
> 3. 先证明补正确实能缩小 gap
> 4. 只有成功后，才研究 G 来减少真机采集成本
> 5. **G 若要做，必须是能自动标定真实动力学参数的通用模拟器，而不是简单的 Δa 响应模型**

`H` 恰恰就是第 5 条排除的那个东西 —— 一个简单的 Δa 响应模型。v1 等于绕回去做了一个
明确不算数的对象。

**v2 全程不出现任何模型**：
- 不用 `G`，不用 `H`，不做任何求逆
- `sim/fit_step1_candidate.py` 这条线（`W → H⁻¹ → Θ`）**停用**
- `step1_correction_runtime.py` 中读取 `H`/`Θ` 的部分**不再使用**
- v1 的 `H` 仅作为**诊断成果**保留在报告里（说明机器人对小补正的响应可测、近似线性），
  不参与 v2 的任何计算

## 1. Step 1 v2 的形式

```
固定 θ  →  真机跑完整 episode  →  用实测 IMU 算 gap loss
        ↑                                        ↓
        └────────  episode 之间用 SPSA 更新 θ  ────────┘
```

- episode **内**只推理，θ 固定不变
- episode **之间**才更新
- 每次只调整少量参数（3 个）
- 表现异常可立即回退到上一版本的 θ

术语上这是 **episode 级、双边 SPSA（Simultaneous Perturbation Stochastic Approximation）**
的真机在环零阶优化。不需要 `H`，不需要 `G`。

## 2. θ 的参数化（冻结）

### 2.1 分组

| 组 | 关节 |
|---|---|
| 近端 `prox` | j1–j3 |
| 腕部 `wrist` | j4–j6 |
| 夹爪 | **不修改** |

### 2.2 每个新 chunk 到来时

已知的接缝差（纯指令，决策时可得）：

```
d = q_prev,last − q_new,first                    ∈ R⁶
```

每组归一化：

```
v_G = d_G / max( ‖d_G‖∞ , 2 mrad )               G ∈ {prox, wrist}
```

输出（`k` = 接缝后第几帧）：

```
δa_G(k) = A_G · v_G · exp(−k/τ)
```

### 2.3 为什么方向取自 `d` 而不是固定向量

- **跨会话稳健**：本次 25 个接缝里 j6 恰好 25/25 同号、j2 80% 同号，但 n=25 且这可能是
  本任务结构的偶然；把方向绑死在实测符号上，换任务/换会话就可能反向。
  取自 `d` 则方向永远由当时的指令自己决定。
- **按跳变幅度缩放**：大跳变得到大补正，小跳变得到小补正，无需额外参数。
- **`A_G < 0` 是允许的** ⇒ SPSA 可以发现"应该强化而非平滑接缝"，方向由真机 loss 判定。
- 全程只用已记录的指令，**不涉及任何响应模型**。

### 2.4 参数范围（冻结）

```
A_prox , A_wrist ∈ [−2, +2] mrad
τ                ∈ [2, 10] 帧            (100–500 ms)
```

因 `‖v_G‖∞ ≤ 1`，故 `|δa_G| ≤ |A_G| ≤ 2 mrad`，与硬限幅一致。

### 2.5 其它冻结项

- **首个 chunk 不补正**（没有 `q_prev,last`）
- **每集状态清零**（不跨 episode 继承）
- 保持 **±2 mrad 限幅** 与 **接触窗归零**（沿用 v1 实现，见 §6）
- 夹爪指令原样透传

## 3. 损失与更新（冻结）

### 3.1 损失

```
L = mean_t ‖ bandpass(real − ideal)(t) ‖²          陀螺三轴，0.5–9 Hz，41 抽头 FIR
```

**全程**口径，含接触帧 —— 与 H1 主指标（§5）**完全相同**，不使用任何代理指标。

> 曾考虑只用「接缝窗 0–9」做 SPSA 的 loss 以提高信噪比。实测：接缝窗集间 CV 15.1%
> vs 全程 12.3%，但效应也集中（接缝窗占总能量 61.6%）⇒ 净 SNR 增益约 **1.32×**
> （所需集数 ≈0.57 倍）。**不采用** —— 增益不改变量级，而"优化的量 ≠ 评价的量"
> 会引入代理失配风险。

### 3.2 归一化

```
x₁ = A_prox  / 2 mrad
x₂ = A_wrist / 2 mrad
x₃ = (τ − 6) / 4
```
全部限制在 `[−1, 1]`。

### 3.3 两段式（因 `A=0` 时 `τ` 无意义）

| 阶段 | 轮次 | 学什么 |
|---|---|---|
| 一 | 1–10 | **固定 τ=6**，只学 `x₁, x₂` |
| 二 | 11–40 | 三个参数一起学 |

共 **40 轮**。每轮**重新采样** `Δ`（各分量独立 ±1），`θ⁺`/`θ⁻` 的**执行顺序逐轮交替**。

### 3.4 SPSA 系数（冻结）

```
c_k = 0.20 / (k+1)^0.101
a_k = 0.35 / (k+6)^0.602
y   = log L                                  ← 用对数, 尺度无关
ĝ_k = (y⁺ − y⁻) / (2 c_k) · Δ_k              ← Δ 为 ±1, 故 1/Δ = Δ
θ_{k+1} = clip( θ_k − a_k ĝ_k )
```

**每个归一化参数单轮最大变化 0.12**（信赖域，防噪声大步）。

### 3.5 任务失败的处理（必须预先定，否则优化器会作弊）

任务失败的集**仍保留记录**，但在**更新 θ 时**赋予

```
L_failed = 2 × (最近一次裸 ACT 的 L)
```

理由：不这样做，优化器可以通过「少运动 / 不完成任务」把 IMU loss 压低 —— 那是
在优化一个我们不想要的东西。

### 3.6 最终参数

取**最后 10 个安全中心 `θ_k` 的平均**。

**不**取 loss 最低的那一轮 —— 单集 CV 12.3%，挑最低等于在噪声上做选择。

## 5. 成功判据

> **2026-08-24 改订**：`n` 由 10 → **30 对**，符号判据由「≥8/10」改为
> **保持 H0 下 α≈0.05 的二项临界值**（n=30 ⇒ **≥20/30**）。
> 依据与合规性见 §5.1。**门槛 15%、t 检验、两会话规则、安全门全部不变。**

在 SPSA 结束、θ 冻结之后，用**全新的 30 个 matched A/B block** 检验：

1. `median(r) ≥ 15%`，其中 `r = 1 − L_B/L_A`
2. 对 `r` 做单样本 t 检验，`p < 0.05` 双侧，且均值方向为改善
3. **`≥ 20/30`** 个 block 正向（H0 下 α = 0.0494）
4. 两个会话各自的中位数 `> 0`（各 15 block）
5. 安全门通过（§6）

matched block 的定义沿用 `PREREG_STEP1.md` 附录 B。
**顺序**：`AB` / `BA` 逐 block 交替，会话1 = block 1–15（AB 8 / BA 7）、
会话2 = block 16–30（AB 7 / BA 8）—— 全体 AB 15 / BA 15，位置平衡。

### 5.1 为什么改，以及为什么现在改是干净的

**起因**：SPSA 的 39 轮实测给出**同轮两侧 log 差的 SD = 28.5%**
（会话 A 24.5% / 会话 B 36.0%），而本预注册的功效计算沿用了 v1 的
**假设值 17.4%**。噪声被低估了 64%。

**合规性**（三条同时成立才动手）：
1. **H1 一集都还没跑** —— 不存在看了 H1 数据再改判据；
2. 依据来自**另一个实验**（SPSA 的 θ± 对），不是 H1 自身；
3. 属于**方差驱动的样本量再估计**，只用到离散度，不涉及效应方向或大小。

**为什么符号判据也必须改**：「≥80% 为正」是**固定比例**，随 n 增大反而更难满足
——天真加大 n 会让功效**下降**。Monte Carlo（SD=28.5%，五项合取）：

| n 对 | 集数 | 真实 15% | 真实 20% | 真实 30% |
|---|---|---|---|---|
| 10（旧） | 20 | 24% | 42% | 77% |
| 30，仍用「≥80%」 | 60 | 14% | **37%（更差）** | 86% |
| **30，固定 α（≥20/30）** | **60** | **45%** | **76%** | **99%** |

**真实效应恰为 15% 时功效仍只有 45%** —— 这是「门槛 = 效应」的必然，加 n 救不了
（与 v1 §4 同一性质），设计已知并接受。

### 5.2 机时

v2 是**两臂**（A = 裸 ACT / B = 补正），不是 v1 的三臂。故

```
30 block × 2 集 = 60 集     分两会话各 15 block（各 30 集）
```

故障预留另计（本机崩溃率实测约 9%，建议留 6 集）。

### 结果の三档解读（预先写定，不变）

| 结果 | 结论 |
|---|---|
| 显著 `> 0` 但 `< 15%` | **证明「真机 IMU 学出的补正确实缩小 gap」**，但未达实用门槛 ⇒ **不**进入 Step 2 |
| 满足完整 H1 | **Step 1 完成** ⇒ 可以开始研究通用 `G`（按指導教員第 4、5 条） |
| 不显著或反向 | 这个**三参数接缝补正族**不够；**不得**推出「SPSA / model-free 整体无效」 |

## 6. 安全门（沿用 v1 §4.1）

| # | 规则 | 阈值 |
|---|---|---|
| ⑥-1 | 每集 `sat_pct`（裁剪前越界帧比例） | ≤ 1.0% |
| ⑥-2 | 每集 `stale` 与 `nan` | 均 = 0 |
| ⑥-3 | 每集帧数 | ≥ 550 |
| ⑥-4 | 接触窗内 δa | 强制 0；主指标仍保留这些帧 |
| ⑥-5 | A 类纯技术故障（通信/记录/stale/帧数不足） | 整对（`θ⁺θ⁻`）作废重跑 |
| ⑥-5b | **启动期崩溃且一帧未录**（本机已知的偶发 SIGSEGV） | **原地重启该集**，不算 ⑥-5 事件；见下 |
| ⑥-6 | B 类候选失败（sat>1%/NaN/急停/异常碰撞） | **保留记录、判否，禁止删掉重跑** |

`GRIP_FULL = 0.035`、`threshold_ratio = 0.02`、`half_window = 10` 沿用 v1 冻结值（见 §7 说明）。

### ⑥-5b 的理由（对 ⑥-5 的实现级解读）

本机存在**已知的偶发启动期 SIGSEGV**（退出码 −11，随机，重试即可；
`scripts/train_resilient.sh` 用的是同一绕法）。区分两种失败：

| 情形 | 处理 | 理由 |
|---|---|---|
| **0 帧就崩** | **原地重启该集**（上限 8 次），记 `launch_attempts` | 一帧都没录到 ⇒ 这一次**根本没产生 episode**，不是"跑坏的一集" |
| **≥550 帧后崩（退出期）** | **本集有效**，只记 `exit_code` | 见下方「退出期崩溃」 |
| 录到 1–549 帧才崩 | 抛 `PartialEpisode` ⇒ 按 ⑥-5 **整对作废重跑**；**残件移开保留**，不删 | 确实产生了不完整的一集 |
| 连续 8 次 0 帧崩 | 抛错停止 | 不再是偶发，先查环境 |

**判据是帧数，不是退出码。** `frames ≥ 550`（⑥-3 本来的门槛）即视为完整。

#### 退出期崩溃（2026-08-19 实测遇到）

本机还有第二类崩溃：**录完之后**在进程退出期崩。实测输出的顺序是

```
Map: 100%|...| 584/584          ← 全部帧写入数据集
Creating parquet ... 100%       ← parquet 写完
Stop recording / piper disable / Exiting     ← 机器人正常关闭
QThreadStorage: entry ... destroyed before end of thread
free(): invalid pointer          ← 之后才 abort, 退出码 −6 (SIGABRT)
```

所有录制与落盘都已完成（最终 flush 由 `control_robot` 在 record 循环后显式调
`policy.summary()` 完成），崩溃只在 Qt/glibc 的 teardown。**此类不影响数据，本集有效。**

原地重启比"整对作废"更**保** `θ⁺`/`θ⁻` 的时间邻近性（重试只隔数秒），
而 ⑥-5 定成对级正是为了漂移对照。每集的 `launch_attempts` 与 `exit_code` 全部落盘。

#### ⑥-5 的自动化与机时记账

⑥-5 要求「整对作废重跑」。编排器**自动**执行这一条（上限 **3** 次/轮，超过则停止），
因为这就是 ⑥-5 规定的动作，不是偏离。伴随的记账规则：

| 集 | 归入 | 理由 |
|---|---|---|
| 本轮已跑完的 SPSA 侧集 | **作废** | 所属轮次未提交，对优化无贡献 |
| 崩掉的那一集 | **作废** | — |
| 本轮的裸 ACT 基线 | **在册** | 已提交进 `baselines`；重跑时**去重复用**，数据有效 |

状态里 `episodes_used`（在册）与 `episodes_wasted`（作废）分开记，
**两者之和 = 实际机时**，用于对齐 §4 的 100 集预算。侧集只在**整轮提交时**才入册。

## 7. 已知限制（预先写明，不是事后解释）

### 7.1 接触门控抹掉了约一半的接缝

实测（P0 5 集、25 个接缝，`scripts/`-同源的 `command_contact_mask`）：

| | 覆盖率 |
|---|---|
| 第 1 个接缝 | **96%** |
| 第 2 个接缝 | **98%** |
| 第 3、4 个接缝 | 0% |
| 全部接缝平均 | 46.8% |
| **100% 被抹掉的接缝** | **40%** |
| 完全不受影响的接缝 | 52% |

⇒ **补正实际只作用在约一半的接缝上**，且**头两个接缝几乎完全失效**。

**这不是参数错误**：把 `GRIP_FULL` 从 0.035 改为实测量程 0.081，第 1/2 接缝仍为 96%/96%
—— 那两处是**真实的夹爪动作**，门控在正常工作。缩窗到 ±5 才部分缓解（48%/78%），
但那会削弱接触保护，本预注册**不采用**。

因此 **15% 仍是有挑战的目标**。若失败，结论只能是「这个三参数接缝补正族不够」。

### 7.2 近端组的方向逐接缝变

主导关节：j2 14/25、j1 6/25、j3 5/25。`v_prox` 的形状因此逐接缝变化，而
`A_prox` 是**单个标量**，必须在变化的方向上都有效。若做不到，SPSA 会把 `A_prox`
收敛到 ≈0 —— 那本身就是可解读的结果。

（腕部组相反：j6 主导 **25/25**，`A_wrist` 含义稳定；j4 在接缝处占比 **0.0%**，
实质不参与。）

### 7.3 `2 mrad` 下限是死代码

`max(‖d_G‖∞, 2 mrad)` 中的下限**从未触发**：`‖d_G‖∞` 中位数为 98 mrad（近端）
/ 121 mrad（腕部），0% 的接缝低于 2 mrad。保留作为安全网，但不起作用。

### 7.4 单轮梯度极吵

单集 `L` 的集间 CV 实测 **12.3%**（本会话 P0 5 集；与另一会话 A 臂的 11.59% 一致）。
双边差的 SD 约 `12.3% × √2 ≈ 17%`。单轮梯度信噪比很低 —— 这是 SPSA 的设计工作点，
但也意味着**不能从任何单轮的 loss 变化下结论**。

系数自洽性核对（冻结前算）：

| 轮次 | `c_k` | `a_k` | `\|ĝ\|` 噪声 SD | 单轮步长 SD | 信赖域 0.12 触发率 |
|---|---|---|---|---|---|
| 1 | 0.2000 | 0.1190 | 0.435 | 0.0518 | 2.0% |
| 10 | 0.1585 | 0.0686 | 0.549 | 0.0376 | 0.1% |
| 40 | 0.1378 | 0.0354 | 0.631 | 0.0223 | ~0% |

- 信赖域 0.12 基本不触发 ⇒ 是**安全网**而非实际约束（设计意图正确）
- `Σa_k` = **2.28** ⇒ 真实梯度需 `≥ 0.44`（归一化单位）才能让参数走满 0→1
- 纯噪声下 40 轮的随机游走 SD ≈ **0.21**（范围 ±1）⇒ 不会被噪声推到边界

### 7.5 未涉及的

- 只做 **pp2**；insert 不参与 v2 结论
- 只在**一个平台参数点**（20 Hz、141 ms 滞后、chunk 开环）
- 运行时 IMU 的**实时**反馈不在 v2 范围内（v2 的 IMU 用在 episode 之间）；
  这与指導教員 2026-07-06 的「实时 IMU 在环」要求的关系**尚未与他确认**
