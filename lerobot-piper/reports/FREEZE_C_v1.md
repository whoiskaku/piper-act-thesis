## 0. 唯一不可省的阻断项：0.63 数据泄漏 —— **已关闭**

问题：纯噪声 group-LOPO = 0.626–0.675 < 1。若留出组噪声与训练组独立，则

```
E‖n_test − ŷ_train‖² = E‖n_test‖² + E‖ŷ_train‖² ≥ 1
```

### 判定证据（三项阻断测试）

| 测试 | 结果 | 结论 |
|---|---|---|
| 组间复相关 | 非对角均值 0.336，最高 g2–g6 = **0.957** | **确认是噪声复用** |
| 逐组独立高斯噪声 | LOPO 回到 0.87–1.23 | 管线本身无泄漏 |
| 训练组不变、只换留出组独立噪声、**参数不动** | 0.82–1.17 | 排除「报训练残差」「外折再选超参」 |

**根因确认**：`noise_rows` 让所有 key 共用同一 `nb` 数组，`make_obs` 每次只抽
**一个**块索引作用到全部 key ⇒ 训练组能预测留出组的噪声。
**这正是"训练/留出噪声复用造成的数据泄漏"，不是别的原因。**

### 修复与验收

显式 session + run 两层（`noise_blocks_tagged` + `draw_noise`）：
先抽 session（key 间共享，对应同轮漂移）→ 每个 key **独立**抽轮内窗口。

24 次抽样平均后：

| | g0 | g1 | g2 | g3 | g4 | g5 | g6 |
|---|---|---|---|---|---|---|---|
| 均值 | 1.017 | 1.019 | 0.989 | 1.013 | 1.080 | 1.058 | 0.988 |
| ±SE | 0.035 | 0.024 | 0.025 | 0.056 | 0.058 | 0.028 | 0.032 |

**七组等权总均值 1.024 ± 0.020 ≥ 1；显著低于 1 的组：无。** ✓ 阻断项关闭。

残余组间 |ρ| ≈ 0.26 来自**共享 session 分量**（物理真实）
⇒ group-LOPO **只在同一 session 内有效**，不验证跨 session 泛化。

## 1. 冻结的层级定义

参数空间规范：`c_m(θ) = Σ_c w_c·log α_m(φ_c;θ) − c_m(θ_0) = 0`，
`G = ∂c/∂θ ∈ R^{3×24}`，`N = null(G) ∈ R^{24×21}`，`δθ = Nξ`，`J_fit = W·J_θ·N`。
φ 网格 = **固定的 16 个计划位姿**，不随 fold 改变（只用设计协变量，无标签泄漏）。

| 层级 | 开放块 | 列数 | 数值秩 |
|---|---|---|---|
| L0 | gain | 2 | 2 |
| L1 | gain + θ_shape(21) + theta_mean(3) | 26 | 26 |
| L2R | + R18 | 44 | 44 |
| L2 | + D6 | 50 | 50 |
| L3 | + poles6 | 56 | 56 |

- `theta_mean` **保留在 L1 及以上全部层级**（实测其落在 span(R18) 内仅 0.057，
  排除会破坏嵌套性）。
- B-only(9) **不作为独立块**。
- 嵌套性 `rank(L_k ∪ L_{k+1}) == rank(L_{k+1})` 四项全 ✓。

## 2. 冻结的判据与超参

| 项 | 值 |
|---|---|
| 数值秩阈值 | σ_i > σ_max · **1e-8** |
| λ 网格 | [1e-8, 1e-5, 1e-3, 1e-2, 1e-1, 1, 10]（含接近零档） |
| λ 选择 | **嵌套**内层 LOPO，只在训练组内 |
| τ 网格 | 外折 1 ms 全程 [−250, +250] ms + 前两谷 Brent 精修；内层 CV 5 ms 全程 |
| 层级选择 | LOPO 预测误差 + **one-standard-error rule** |
| 组划分 | 7 个物理位姿组整组留出，**七组等权** |
| 真值定标 | 正交输出 SNR `Δy⊥ = (I−P_{k−1})J_kΔp_k`，扫 0.5/1/2/3/5 |
| 放行门槛 | 错误升级率 ≤10%；两分支选对率 95%CI 下界 ≥95% |
| holdout | 5 个真实 holdout **始终封存**，层级确定后才用一次 |

**Wilson CI 口径**：只表示「给定这三个实测 session 构成的经验噪声模型」下的
Monte Carlo 不确定度，**不含真实 session 分布的不确定性**。

## 3. 已有结果的定位

| 结果 | 状态 |
|---|---|
| 参数空间规范三项验收（rank/‖GN‖/换基一致性/均匀缩放单元测试） | **有效** |
| 离格 τ + Brent 精修（−370 μs → 0.0 μs） | **有效** |
| 无泄漏检查（holdout 未入矩阵、破坏留出组参数不变、组间重叠 0） | **有效** |
| g0 四项隔离（非 bug；shape 下高风险工作点；轴/频率结构） | **有效** |
| 100 trial 的**层级选对率 / 混淆矩阵 / 检测曲线** | **作废** —— 该批用的是有 bug 的噪声模型（组间高度相关 ⇒ 偏乐观） |
| 最不利 shape 搜索（各向同性椭球版） | **预验证**；结构化允许集合尚未实现 |

> 若需要一个合法的预验证选对率数字，用修复后的噪声重跑 100 trial 约需 35 分钟。
> 本冻结不依赖它。

## 4. 延后项（论文定稿 / 最终模型验收阶段再做）

## 5. 下一步（真机，按既定顺序）

1. **C 开环 pilot（少量）**：记录完整性、SNR、时钟链路、奇偶对称、安全余量。
   沿用 B′ 已验证的六道门禁，针对静止/慢动位姿重做 ⓪ residual margin。
2. pilot 正常 → 采集完整 C 数据，**holdout 暂不打开**。
3. 用 train 数据做临时 Ĝ 拟合，结果标为**探索性版本**。
4. 若上 DAgger：只做**低幅值、小批量** pilot，不直接扩大到正式闭环实验。

**采集设计注意**：若后续跨 session 结果明显下降，不能靠增加 Monte Carlo trial 修复。
应让**四个宽带锚点在每个 session 重复**，其余位姿顺序随机化，
否则位姿效应与 session 漂移会混杂。
