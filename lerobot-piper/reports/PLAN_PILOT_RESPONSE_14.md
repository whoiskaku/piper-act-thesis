## 0、定位：**不把「能测到响应」和「能比较模型」合成一道门槛**

**这份 pilot 只估三件事**：

| | |
|---|---|
| **重复性** | 同波形重复之间的散布 |
| **漂移** | 交错裸复放之间的系统性变化 |
| **响应的不确定性** | 上两项 + **共享基线的相关结构**合起来的传播结果 |

**它<u>不</u>回答**：
- ✗ **不判定**「响应是否存在」（**②：不采用「响应点估计低于 MDE」的自动判决**）
- ✗ **不比较模型**（`H` vs 神经响应模型的比较**不在本轮**）
- ✗ **不产出**通过／不通过的门槛判决

> ⚠ **这 14 次<u>不是</u>训练神经网络的数据规模承诺。**
> 每种条件只有**两次**重复，方差估计仍会很粗；
> 它只帮助判断**正式采集是否值得投入、需要多少预算**。

### 2.1 ⚠ ABBA 的作用是**有条件**的

**ABBA 只在下面两个条件同时成立时才抵消该漂移项**：

1. **正负两侧的平均采集时刻相同**；
2. **共同漂移近似线性**。

⚠ **须按<u>实际时间戳</u>核对**，不得假定「名义顺序 = 实际采集时刻」。
⚠ **`P`/`Q` 起始符号相反<u>不保证</u>任意漂移相消** ——
它只是一个**对称化安排**，不是相消的证明。
⚠ 若现场出现漏跑／补采，**必须记录实际执行顺序与时间戳**并在分析中按实际处理
（③a 有过 `Bp(r4)` 漏跑后补采、落在 `A2` 之后而非 ABBA 第 4 位的先例）。

## 3、⑥ 评分口径（**冻结**）

**带通 `0.5–9 Hz`。** ⚠ **「先平均」的对象要分清：<u>平均波形</u> ≠ <u>平均预测误差</u>。**

### 3.1 pilot：**展示响应**（本轮做这个）

**可以先平均波形**：

```
① 先平均**同符号重复的波形**：r̄_{P,+} = mean(P+₁, P+₂)   r̄_{P,−} = mean(P−₁, P−₂)
② 再**正负等权**
③ 最后**探针组等权**
```

### 3.2 正式阶段：**比较模型**（本轮**不做**）

**必须先逐次复放算 `MSE`，再平均重复 → 正负 → 探针组**：

```
① 对**每一次复放**单独算 MSE_i
② 再平均**同符号重复**：MSE 的均值（**不是**先平均波形再算 MSE）
③ 再正负等权 → ④ 最后探针组等权
```

> ⚠ **`MSE(平均波形) ≠ 平均 MSE`** —— 先平均波形会压掉重复间的散布，
> **改变误差降幅的<u>分母</u>**，使「相对 `H` 下降 ≥5%」这类阈值失真。

⚠ **当前 pilot 不比较模型，不必因此追加工作**；此条为正式阶段预先写明。

### 3.3 两条通用规则

- **正负分别报告**（不得只报合并值）；**奇／偶分解作<u>辅助</u>**，不作主口径。
- ⚠ **所有模型使用<u>同一</u>基线估计和对齐** —— `ē_bare` 与 `(R, L)` 对所有被比较的模型
  是同一份，不得各用各的。

## 4、不确定性：**共享裸基线会让不同响应估计相关**

响应估计 `r̄ᵢ = mean(同符号重复) − ē_bare`，其中 `ē_bare` 是**同一份** 5 次裸复放的均值
⇒ **各响应估计之间必然相关**。

> ⚠ **下表是「独立重复、同方差」假设下的<u>示意</u>，<u>不是</u>本轮的实测结论。**
> 以单次复放方差 `s²` 为单位（`M = 5` 裸，`n = 2` 同符号重复）。

| 量 | 值 | 说明 |
|---|---|---|
| `Var(r̄)` | `1/n + 1/M` = **0.70 s²** | 含基线**估计误差** `1/M` |
| 若基线**已知且无估计误差** | `1/n` = 0.50 s² | ⚠ **这不是「不共享基线」** |
| 若各响应**各用独立、同精度**的裸基线估计 | **仍是 0.70 s²**，只是 `Cov = 0` | 共享与否改变的是**协方差**，不是单个方差 |
| `Cov(r̄ᵢ, r̄ₖ)` | `1/M` = **0.20 s²** | 来自**共享**的 `ē_bare` |
| **相关系数 `ρ`** | **0.286（= 2/7）** | |
| 4 个响应估计（2 探针 × 2 符号）取均值 | 误作独立 0.175 s² vs 实际 0.325 s² | **方差比 ≈ 1.86** |
| 同一件事换成标准误 | `√1.86` | **标准误比 ≈ 1.36** |

⚠ **`1.86` 是方差比，`1.36` 才是标准误比** —— 引用时须说明是哪一个。

> ⚠ **计算不确定性时必须一起处理**：**不能**把正负两侧当独立样本。
> 另：若在**帧级**上做不确定性计算，**不能**把各帧当独立样本（带通后帧间强自相关）；
> ⚠ **但这与下面 §4.1 的复放级自由度是<u>两件事</u>**，见该节。

### 4.1 单次复放散布 `σ` 的**名义**卡方区间（iid 正态假设）

这里的自由度来自**整次复放层面的独立标量观测**：

| | `σ` 的 95% CI | 跨度 |
|---|---|---|
| 裸复放 **5 次**（df = 4） | `[0.599, 2.87] × ŝ` | **4.8×** |
| 同符号重复 **2 次**（df = 1） | `[0.446, 31.9] × ŝ` | **71.5×** |

⚠ **不能说帧间相关必然降低这两个自由度。**
`df = 4 / 1` 针对的是**整次复放得到的独立标量观测**，**帧内相关不会自动再降低它**；
而且**同符号重复之间作差时，共享的裸基线会抵消**。

⚠ **这两个区间是<u>单次复放标量散布</u> `σ` 的名义示例，
<u>不是</u>整条波形或能量指标的通用置信区间。**

**「方差估计仍会很粗」的量化含义就在这里**，也是本 pilot 不设判决门槛的直接理由。

## 5、① 预算（**建议，非授权**）

| | |
|---|---|
| **复放次数上限** | **≤ 14 次** |
| **现场总耗时上限** | **≤ 40 分钟**（**含复位与等待**） |
| 单次运动时长参考 | ≈ 29 s（581–592 帧 @ 20 Hz） |

**两者任一触顶即停。**

历史锚点（③a，供现场对表）：

- 13 次复放全部 581 帧
- 复放噪声 `σ = 0.03911 rad/s`（比按**另一会话**预估的 0.03083 **高 27%**）
- `A1↔A2` 互相关 **0.985–0.989**
- **漂移**：`A1` 组均 vs `A2` 组均（相隔约 14 分钟）差 **0.02508 rad/s**，
  而**纯复放噪声即可解释 0.02614** ⇒ **14 分钟内<u>未测出</u>净漂移（上界 ≈ 噪声）**。

⚠ **「未测出」<u>不是</u>「漂移为零」的证明**（**排除≠证明**）。
⚠ 该锚点只覆盖 **14 分钟**；本轮现场耗时上限是 **≤ 40 分钟**，**超出的时段不被它覆盖**。
⚠ 早期 v1 的教训：**白噪声模型低估噪声底 3×** ⇒ **必须实测，不得靠模型推算**。
