## 第 1 節 — Ĝ とは何か（2 枚）

**答える問い**：先生の指摘 ①（入力）

**図**：`reports/figures/G_schematic.png`（(A) 内部三層 / (B) 使い方＝増分トリック）

**台詞**
- 「Ĝ は**紙のロボット**です。**入力は機械に送る command 列そのもの**（+ 修正量 δa）、出力は IMU ジャイロの読み。姿勢の幾何も共振の鳴りやすさも、その command 列から自分で計算します」
  → **先生の指摘①への直接回答**。「同じ 5 mrad でも腕が伸びていれば結果が違う、混同は起きません」
- 三層：① サーボ FIR（遅れ・鈍り）② ヤコビアン（幾何、**当てはめ無し**）③ 柔軟モード（3 つの減衰振動子、姿勢で鳴りの強さを調整）。**合計 135 パラメータ**
- 「**ideal は Ĝ に入れません**。同じ command から運動学で別途レンダリングし、外で引き算して gap を出す —— 先生が板書された経路そのものです」

**(B) 面 ＝ 本題（ここが方法の要）**
$$e_{sim}=\underbrace{e_{log}}_{\text{実測、100\% 事実}}+\underbrace{\hat G_\delta[\delta a]}_{\text{モデルは増分だけ}}$$
- 「名義の世界は**測定**が与えます。Ĝ は『**そこに修正を少し足したら、どれだけ変わるか**』だけを答える」
- 「だから Ĝ に必要なのは**値の精度ではなく微分の精度**です。モデル誤差は引き算で大部分が相殺されます」

**図**：`evidence_act2_{ins,pp2}_ep{8,9}.png`（**留出集 4 本すべて、課題別に並べる**）

**台詞**
- 「π は**毎フレーム**、過去 150 ms 前までの誤差と chunk 内の既知の未来を見て、**±10 mrad 以内**の修正を出します。**上限は構造で保証**（tanh）、静止中は出力ゼロ」

## 第 5 節 — pick-place が弱かった：診断 → 治療 → 検証（2 枚）

**図**：`beta_data_tradeoff.png`

**台詞**
- 「pick-place は最初 **6.2±2.8%** でした。弱い。原因を二段階で切り分けました」
- **診断 1（物理の天井）**：δa を自由に最適化する「神託」探針（非因果・全知）で上限を測定 → pick-place 42–48%、挿入 73–77%。**壁のスペクトルが違う**（挿入は 3–6 Hz 集中、pick-place は広帯域に平坦）
- **診断 2（データか予測可能性か）**：訓練集を 2 / 4 / 8 本と増やす → **−7.2% / +1.4% / +6.3%**。急峻に単調、飽和なし ⇒ **データ律速**（先生の「データを増やせ」が的中）
  - 曝露の偏りは**排除済み**（均衡再訓練で 9.0 → 9.9% のみ）
- **治療**：データ 16 → 25 集（fork 系を追加）＋ 力の価格 β を 1000 → 300
- **検証**：**6.2±2.8% → 13.9±2.2%（2.2 倍）**、挿入も **35.6 → 41.1%**。そして**種子分散が縮小**（pp2 ±2.8 → ±2.2、同条件の 3 種子比較では ±2.9 → ±0.3）
  - 「**分散の縮小がデータ飢餓の一番硬い指紋です。**平均が上がっただけなら偶然かもしれませんが、ばらつきが 9 分の 1 になるのは飢餓が解消した証拠です」
- β について：「β は**調整パラメータではなく交換レート**です。1 mrad の動きで約 4 pp。**モデル内は下げるほど良い（拐点なし）**。それでも 300 で止めているのは、実機の高周波ゲインが Ĝ の 1.3–1.5 倍と実測されたからです。**モデル内最適 ≠ 実機最適**」
