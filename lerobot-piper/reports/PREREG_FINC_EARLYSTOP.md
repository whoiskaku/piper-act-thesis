## 2、② 只在 `P1` 内部选训练时长

### 2.1 留一验证

`P1` 的 8 集**各属一个不同探针种子**（`1000–1007`）⇒ **按探针种子留一，8 折**。
每折训练 7 集、验证留出的 1 集；**归一化统计只用该折的 7 集**。
共 **8 折 × 3 训练种子 = 24 次训练**。

### 2.2 检查点（**固定，不插点、不扩网格**）

```
CKPTS = { 0, 50, 100, 200, 400, 800, 1500, 3000 }
```

- **第 0 步**：输出头零初始化 ⇒ `F_inc ≡ 0` **逐位** ⇒ **(c) 与 (a) 完全相同**，
  即「**不加这个增量分支**」这一档。
- **第 3000 步**：上一轮的配置 ⇒ **新实验把旧配置<u>嵌套</u>在内**。

### 2.3 选择规则

```
V(step) = mean over { 8 折 } × { 3 训练种子 }  of  E(该折留出集, 该 step)      （24 项）
step*   = 在 V 取最小的检查点中**取最早者**
```

**选一个<u>统一</u>步数**（不是逐折、逐种子各选）。**`P2`/`P3` 完全不参与选择。**

⚠ **平局判定使用<u>完整精度</u>评分，不先四舍五入。**
容差固定 **`rtol = 1e-12`、`atol = 1e-15`**；
满足平局条件的检查点中**取最早者**。

⚠ **留一模型训练在 7 集上，最终模型训练在 8 集上** ⇒ 最优步数可能略有差异。
设计固有，非缺陷，结论中须提及。

## 3、③ 最终重训并一次性评价

**若 `step* > 0`**：用**全部 8 集 `P1`**、三个训练种子各训一次，
**训练到第 3000 步**，途中**同时保存第 `step*` 步与第 3000 步的权重**。

| # | 预测 | 角色 |
|---|---|---|
| (a) | `ê_base` | 对照 |
| (b) | `ê_base + H ⊛ δa` | 对照 |
| (b′) | `ê_base + β·(H ⊛ δa)`，`β = +0.960643` | 对照 |
| **(c)** | `ê_base + F_inc@step*` | **主判据对象** |
| (c₃₀₀₀) | `ê_base + F_inc@3000` | **固定参照**（同初始化、同采样轨迹） |

**推进三条（全部满足才算推进）**，**只施加于 (c)@`step*`**：

1. vs **(b)**：三探针种子 `d_s` 全正 **且** `d̄ ≥ 5%`
2. vs **(b′)**：同上
3. **(c)** 的等权平均误差 **低于 (a)**

**聚合顺序不变**：先同探针种子的两集**误差**平均 → 再三训练种子的评分平均
（**不是先平均预测**）。`P3` 仍为**次要压力评价，不挽救 `P2`**。

⚠ **`step*` 在查看 `P2`/`P3` 之前已经锁定。
第 3000 步只作固定参照，<u>不得</u>根据 `P2` 改选权重。**

### 3.1 参照臂的完整性检查（**报告，不阻断**）

(c₃₀₀₀) 与上一轮是**同种子、同数据、同采样器、同初始化** ⇒ 其 `P2` 的 `redu`
应复现上一轮的 **+0.98% / +2.05% / +5.16%**（训练种子 0/1/2）。
**若不符，必须在结论中声明「参照臂无效」**；`step*` 侧的判决**不受影响**
（`step*` 由 `P1` 留一选出，不依赖该参照）。

### 3.2 `step* = 0` 的分支

**如实报告「内部验证不支持加入该增量分支」，不继续搜索，
且<u>不为取得参照额外训练</u>。**

此时 `F_inc ≡ 0` ⇒ `(c) ≡ (a)` **逐位**。

⚠ **按构造必然失败的只有条件 3**：`(c) = (a)`，不满足「**严格**低于 (a)」。
**条件 1、2 取决于 `H` 与 `βH` 的实际评分，<u>不能</u>称数学上必然失败。**
⚠ 这种情形**不叫**「早停无效」，而是「**内部验证判定这个增量分支不该加入**」。
