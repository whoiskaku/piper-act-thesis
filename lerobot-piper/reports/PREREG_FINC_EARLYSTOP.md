## 0、只检验一个假设

> **H_es：固定训练 3000 步，是否让增量网络过度拟合了 `P1`。**

**为什么这次有具体依据**（与前两轮不同）：
- **名义分支有效**（`redu(a)`：`P1` +26.47% / `P2` +26.93%），
- **`H` 对照也有效**（`P2` 上 (b) +31.49% > (a) +26.93%），
- 而**神经分支训练损失很低、折外预测却明显恶化**（`P2` 的 `d̄ = −42%`，
  且 `(c)` 比 `(a)` 还差）。

⇒ 「**通过折内选择训练时长，能否改善泛化**」是一个有具体依据的问题。

⚠ **但这还不是已经确认的失败原因。本轮不预设早停一定有效。**

## 2、② 只在 `P1` 内部选训练时长

### 2.1 留一验证

`P1` 的 8 集**各属一个不同探针种子**（`1000–1007`）⇒ **按探针种子留一，8 折**。
每折：训练 7 集，验证留出的 1 集。**归一化统计只用该折的 7 集训练数据。**

共 **8 折 × 3 训练种子 = 24 次训练**。

### 2.2 预先固定的检查点（**未定 ①**）

> **建议：`{0, 50, 100, 200, 400, 800, 1500, 3000}`（8 个，对数间隔）。**

- **必须含第 0 步**：此时输出头零初始化 ⇒ `F_inc ≡ 0` **逐位**，
  即 **(c) 与 (a) 完全相同** ⇒ 这一档就是「**不加这个增量分支**」。
- **也含第 3000 步**：即上一轮的配置 ⇒ **新实验把旧配置<u>嵌套</u>在内**。
  若内部验证选中 3000，就说明失败**不在训练时长**这个变量上。

### 2.3 选择规则

```
V(step) = mean over { 8 折 } × { 3 训练种子 }  of  E(该折留出集, 该 step)
step*   = argmin_step V(step)
```

**选一个<u>统一</u>步数**（不是逐折、逐种子各选一个）。
**平局取最小步数**（未定 ②）。**`P2`/`P3` 完全不参与选择。**

⚠ **留一模型训练在 7 集上，最终模型训练在 8 集上** ⇒ 最优步数可能略有差异。
这是本设计固有的，不是缺陷，但结论中须提及。

## 3、③ 最终重训并一次性评价

用**全部 8 集 `P1`**、按 `step*`、三个训练种子各训一次，然后**只评一次**：

沿用**本轮的对照与门槛**（`PREREG_FINC_AB4.md` §5–§6，逐字不变）：

| # | 预测 |
|---|---|
| (a) | `ê_base` |
| (b) | `ê_base + H ⊛ δa` |
| (b′) | `ê_base + β·(H ⊛ δa)`，`β = +0.960643` |
| (c) | `ê_base + F_inc(u, δa)`，`F_inc` 取第 `step*` 步 |

**推进三条（全部满足才算推进）**：
1. vs **(b)**：三探针种子 `d_s` 全正 **且** `d̄ ≥ 5%`
2. vs **(b′)**：同上
3. **(c)** 的等权平均误差 **低于 (a)**

**聚合顺序不变**：先同探针种子的两集**误差**平均 → 再三训练种子的评分平均
（**不是先平均预测**）。`P3` 仍为**次要压力评价，不挽救 `P2`**。

### 3.1 `step* = 0` 的分支

**如实报告「内部验证不支持加入该增量分支」，不继续搜索。**

此时 `F_inc ≡ 0` ⇒ `(c) ≡ (a)` 逐位 ⇒ 条件 1、2 **按构造失败**
（`d_s` = (a) 相对 (b) 的劣势，为负），条件 3 取等号而非小于 ⇒ **不推进**。
⚠ 这种情形**不叫**「早停无效」，而是「**内部验证判定这个增量分支不该加入**」。
