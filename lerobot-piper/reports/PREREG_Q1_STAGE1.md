## 2 时间轴与计分（设计稿 §2.3）

- 主起点 = 每个 chunk 的开头 `t0`。实测可用到 `t0`；指令和理想陀螺可用到 `t1`，之后钳位到第 `t1` 帧。
- 计分范围 `ê_t, t ∈ [t0, min(t1, n−1)]`。逐 chunk 拼接成整集，再算 `P(·)`：去均值 → bandpass41（0.5–9 Hz）→ 丢首尾 20。
- 会话误差比 `ρ_s = Σ_e ‖P(gap−ê)‖² / Σ_e ‖P(gap)‖²`，`redu_s = 1 − ρ_s`。
- 辅助项（不进主分数、不挑模型）：
  - chunk 中段起点 `t0 + 50`，覆盖后半个 chunk；
  - 前瞻分层 3–6 / 7–12 / 13–27 / 28–52 / 53–96 / 97–102 帧（带通会混合相邻帧，只是近似）。97–102 恰为每个完整 chunk 的末 6 个计分帧，用来分解末端钳位的影响。

## 4 训练与停止规则（停止规则由用户 2026-10-02 定，见 §11-11…17；其余默认值见 §12）

- 每步均匀抽 1 个训练集，取其 6 个主窗口，拼接后算损失。Adam lr 1e-3，梯度裁剪 1.0。
- 损失：
  - 端到端 = ω 项 + 关节项。ω 项为 `‖P(gap−ê)‖²/(3T_e)`，除以训练折零预测误差的均值；关节项为 0.5·宽带 MSE/尺度 + 0.5·3–9 Hz 带内 MSE/尺度。
  - 分层模型的关节层只用关节项；传感器层闭式拟合。
- **停止规则（嵌套验证：内层选步、外层最后评价）**：
  - 训练上限 10000 步；检查点 0 / 250 / 500 / 1000 / 1500 / 2000 / 3000 / 4000 / 6000 / 8000 / 10000。
  - 每个「模型 × 外层折 × 种子」独立选 step*：外层的 4 个训练会话轮流当内层验证会话（内层留一会话，不按集随机切），用其余 3 个会话训到上限，在每个检查点给验证会话的主窗口算 ρ（与外层同口径）。
  - `V(step)` = 4 个验证会话 ρ 的等权平均；step* = `V` 最小的检查点，完整精度平局（rtol 1e-12、atol 1e-15）取最早。
  - 最终权重 = 在外层 4 个训练会话上同种子训到 step* 的权重；同种子下它与长跑第 step* 步的快照逐位相同（已测）。
  - 外层留出会话**不参与选步**，只在最后评分一次。
  - step* 落在上限（10000）时**不追加步数**，报告注明「最佳点落在搜索边界，尚不能确认训练充分」。
  - 第 0 步的含义不统一：端到端 = 零预测（误差输出为零）；分层 = 伺服先验 + 已拟合的传感器层（关节层未训练）。不套用 F_inc「step* = 0」的解释。
  - 设计稿 §5 #3「1a/1b 训练预算一致」在此口径下 = 同一上限、同一检查点、同一选步规则；各自选出的 step* 可以不同。
- 训练种子 0 / 1 / 2，全部报告。判据用各种子 `ρ_s` 的平均（平均误差，不平均预测）。
- CPU 单线程 + 确定性算法：同种子逐位复现（已测）；运行脚本固定 BLAS 线程数为 1。
