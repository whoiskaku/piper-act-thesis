## 1. 结构

```
ACT 连续指令
  → 不启用点到点限幅器，也不启用 G-v3
  → MuJoCo：kp1 = 5000，j2–j6 保持 XML 值
  → 刚体 IMU / 传感器模型
```

| 项 | 值 |
|---|---|
| 规划器 | **无**（限幅器与 G-v3 均不启用） |
| `kp1` | **5000** —— 称「**有效跟踪增益**」，**不解释为真实机械刚度** |
| `kp` j2–j6 | XML 原值 200/200/100/50/50 |
| `damping` / `armature` | XML 原值 / 全 0 |
| 传感器 | 刚体 IMU 模型（`ee_accel` / `ee_gyro`） |
| 模型文件 | `sim/piper_model.xml`，sha256[:16] = `7f15d5a97d629896` |

## 2. 依据：公平矩阵（规划器 3 档 × `kp1` 2 档，其余逐字相同）

### pp2 开发基准集（17 集）

| 规划器 | `kp1` | 关节 RMS° | 接缝后 10 帧 | 难处前 10% | vs 无限幅（同 kp） |
|---|---|---:|---:|---:|---|
| 无限幅 | 500 | 2.600 | −17.8% | 11.1% | — |
| 点到点限幅 | 500 | 2.708 | −22.8% | 5.0% | 6/17，中位 **−13.6 pp** |
| 流式同步 | 500 | 2.587 | −20.1% | 4.6% | 7/17，中位 **−12.7 pp** |
| **无限幅** | **5000** | **0.924** | −19.1% | 15.5% | — |
| 点到点限幅 | 5000 | 1.083 | −26.1% | 7.3% | 6/17，中位 **−13.8 pp** |
| 流式同步 | 5000 | 0.916 | −21.4% | 7.5% | 6/17，中位 **−13.5 pp** |

（四区域两列为**逐集中位**，不加权，避免被单集主导。）

### 激励套件（20 条）

| 规划器 | `kp1` | 关节 RMS° | IMU 残差/实测 |
|---|---|---:|---:|
| 无限幅 | 500 | 1.924 | 2.7388 |
| 点到点限幅 | 500 | 1.727 | **0.5551** |
| 流式同步 | 500 | 1.862 | 0.7729 |
| 无限幅 | 5000 | 1.844 | 2.7706 |
| 点到点限幅 | 5000 | **1.604** | **0.4758** |
| 流式同步 | 5000 | 1.752 | 0.7216 |

### 由此得出的两条

1. **两个数据集的关节角误差都偏好 `kp1 = 5000`，三种规划器一致。**
   ⇒ 物理跟踪层采用高有效跟踪增益。
2. **两个限幅器在 pp2 上都不通过**「多数集改善 + 正中位」
   （6–7/17，中位 −12.7 ~ −13.8 pp）⇒ π 的连续 ACT 模式**两个都不启用**。

## 3. 措辞约束

- `kp1 = 5000` 只称 **「有效跟踪增益」**。它是当初为凑 2 帧滞后手调的值；
  本次是按**公平矩阵的关节角证据**重新采纳，与原先的手调理由无关。
  **不得表述为已测定的机械刚度。**
- **点到点限幅器不是被否定的**：它在激励套件上有效
  （IMU 残差 2.7388 → 0.5551 @ `kp1=500`；2.7706 → 0.4758 @ `kp1=5000`），
  **保留为探针 / 长保持模式**。
- **G-v3 已判否、非默认**，代码与产物保留供审计（`sim/step2_g/g_v3.py` 顶部有横幅）。

## 4. 仍未解决

- **IMU 侧的剩余误差不是 `kp` 能解决的**：pp2 主指标在全部 6 格里都是
  **−17.8% ~ −26.1%**（逐集中位），无一为正。
- pp2 日志**无逐帧时间戳**，全程假设固定 20 Hz。
- ~3 Hz 腕部余振不建模，成因未定（IMU 支架模态 / 整臂弯曲模 / 重力补偿均未排除）。
- 天花板 96.9%（真机自身可重复性，难处口径）。

## 5. 下一步：命令→关节轨迹层的神经残差

```
q̂ = q_cmd + NN(近期指令, 状态历史)
q̂ → MuJoCo / 刚体传感器模型 → IMU
```

**理由**：A 段是主要缺口；**B 段喂入真实关节角后能稳定解释约 68% 的陀螺能量**
（残差/实测 0.3245，17/17 一致）⇒ **暂不需要端到端直接预测 IMU。**

**数据纪律**：现有 17 集继续作为**开发集**，按**整集**划分训练/验证；
**神经残差结构冻结之后，再采真正的最终 holdout。**
