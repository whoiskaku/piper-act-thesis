# ③a δa 复放探针 —— 结果归档（2026-07-27 真机执行）

**一句话**：真机第一次直接验证了 Ĝ 的增量通道——**方向对、增益 1.40×**，命门通过，③b 解锁。

---

## 1. 这是什么实验

测「真机对一个已知小修正 δa 的实际反应 = 不 = Ĝ 模型预测的反应」。
**开环复放**（跑录好的指令 + 固定探针，不跑 ACT / 不跑 π），故安全、可控、可重复。

每集三条对照复放：
| 臂 | 指令 | 得到 |
|---|---|---|
| A1 | 原始（裸）| 基线 |
| B | 原始 + 已知 δa 探针 | 加修正后 |
| A2 | 原始（再裸）| 复放噪声底 |

- 真实增量 = **B − (A1+A2)/2**
- 噪声底 = **A2 − A1**
- 对账对象 = **Ĝ_δ[δa 探针]** 的预测

## 2. 为什么是命门

方法（π 在 Ĝ 里练）成立的前提 = Ĝ 对 δa 预测靠谱。但**所有训练日志 δa≡0**，
增量通道从训到现在只靠线性外推，从未被真实数据检验。③a 是**唯一**能直接堵这个洞的实验。

## 3. 经过（两轮）

| 轮 | 探针 | 问题 / 结果 |
|---|---|---|
| v1 | 单帧 5mrad 脉冲（insert→pp2）| 信噪 1.8 未过：复放噪声底实测 44 mrad/s，白噪声模型低估 3× |
| **v2** | **8帧 5Hz 方波小波 ×6mrad × j2/j3 × 三集 pp2** | 打共振带，预测响应峰 ↑3-5×，**判据全过** |

**换 pp2 的原因**：insert 旧策略成功率低，复放失败轨迹不安全且污染数据（pp2 能顺利完成）。

## 4. v2 终判（14 发，剔接触后）

| 判据 | 阈值 | 结果 | |
|---|---|---|---|
| ① 信噪 | >3 | 4.4（j2 2.2 / j3 6.6） | ✓ |
| ② 方向 cos | >0.6 | **0.681** | ✓ |
| ③ 增益 g | 报告 | **1.396 ± 0.222** | → 留 β=300 |
| ④ 线性度 | 噪声内 | ✓ | ✓ |

**预注册判据全部通过。**

## 5. 三个结论

1. **两独立测量收敛**：离线代理 1.3-1.5× vs 真机直测 **1.40×** 完全一致
   → **「Ĝ 增量通道从未直接验证」caveat 正式退役**。
2. **β=300 由测量确认**：g=1.40 落在鲁棒曲线中央（破坏阈值 1.86-2.17，余量 33%）。
3. **Ĝ 弱点定位在 j3**：
   - j2: g=1.11, cos=0.79 —— 脉冲响应近乎完美同频同相；
   - j3: g=2.27, cos=0.57, 真实峰 530 vs 模型 105 —— **柔性幅度低估 ~2.3×**。
   - 旁证：编码器空间 j3 几乎无响应（伺服 g=0.24）→ 肘部脉冲被减速器背隙吃掉、
     关节角不动，**但扭矩冲击仍强烈敲响结构**（IMU 530）。推测辨识数据 j3 少 5Hz
     激励 → W[:,j3] 欠拟合。
   - **这三集探针 = 首份 δa≠0 数据**，可重拟合 Ĝ 的 j3 增量通道（v1.1 候选）。

## 6. 副产品：复放方法论成立

A1↔A2 互相关：滞后 0 帧、相关 **0.985-0.989**（三集一致）→ 执行可重复性远好于
「56% 每次不同」的印象；44 mrad/s 噪声底只是陀螺 RMS(~300) 的 15% 残差。
