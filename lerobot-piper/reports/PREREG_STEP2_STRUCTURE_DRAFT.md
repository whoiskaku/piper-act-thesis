## §1 候选 F：传动 / 连杆柔性自由度

在关节 `j` 处把执行器留在**电机侧**，连杆侧加一个被动铰：

```
link(j-1) → [link{j}_rotor: joint{j} 电机侧, 带 G-q-v1 的 Ia_j]
             → [link{j}: joint{j}_flex 被动(stiffness K, damping C)] → 下游
编码器读电机侧 joint{j}；IMU 看连杆侧下游 —— 与真机测点位置一致
```

| | |
|---|---|
| 离散因子 | `j ∈ {j2, j3, j5}`（j2 = 臂下垂模载体；j5 = 腕部载体；j3 = 肘） |
| 连续参数 | `ω_f`（Hz）、`ζ_f` |
| 换算 | `K = M_eff·(2πω_f)²`，`C = 2ζ_f(2πω_f)M_eff`；`M_eff` 取模型在 HOME 的质量矩阵对角元 |

**与旧 G-flex 的两处关键不同**：

1. 旧版把电机侧带宽**硬钉在 40 Hz**（`armature = kp/(2π·40)²`）作为数值稳定的
   建模选择。**本版不需要** —— `Ia_j` 已由 G-q-v1 辨识（`Ia2 = 0.4163` kg·m²，
   ωn = √(kp2/Ia2) ≈ 9.5 Hz，`dt = 2 ms` 下稳定）。
2. 旧版基线是 **XML 默认 kp×1**，且**只试了 j2**。本版底座是 G-q-v1，
   并把 `j` 作为离散因子。

> 旧 G-flex 判否（12/24 分组，物理频率处 0/24）是在**关节误差约 1°** 的底座上做的，
> 现在是 **0.3–0.4°** ⇒ **不能直接外推**，这是一个不同的实验。

## §2 候选 B：IMU 支架的二阶旋转模态

现状：`ee_imu_site` 是**直接挂在 `link6` 上的无质量 site**
（`pos="0 0 0.13"`，有径向伸出）—— **支架完全没有建模**：无 body、无质量、无自由度。

```
link6 → [imu_bracket: 继承 site 的 pos/quat, 被动铰(K, C)]
          → ee_imu_site @ (0,0,0)  ← 陀螺/加速度计挂在这里
```

| | |
|---|---|
| 离散因子 | 铰轴 `∈ {bracket x, y, z}` |
| 连续参数 | `ω_b`（Hz）、`ζ_b` |
| 支架质量惯量 | **声明的建模选择**，非辨识量。TSND151 ≈ 22 g，含支架取 `m = 0.05 kg` |

**因为支架很轻，它几乎不反作用于臂** ⇒ 实际上是个**传感器侧的二阶滤波器**，
可辨识量只有 `(ω_b, ζ_b)`；质量只影响它对臂的负载（可忽略）。
**⇒ 必须做质量 ×0.5 / ×2 的灵敏度检查**：若结论随之翻转，该候选不可用。
