## 1. Step 1 的定义（已定）

> 一组随机、受控的真机干预实验，用来证明补正方向确实存在，
> 并采集 Step 2 构建 G 所需的数据。

**不是**完整的真机 PPO，**不是**训练最终的 π。

**范围（写死）**：ACT 冻结；单一任务 = **pp2**；20 Hz；六关节位置补正；
研究范围限于当前任务分布，**不追求**「任意机器人动作」的通用 G。

### 三个交付物

| | 内容 | 出处 |
|---|---|---|
| ① | 一套干净的裸 ACT 真机基线 | 会话 1 的 P0 |
| ② | `D_real` = {状态, 动作, 补正, 真实后续响应} | 会话 1 的 P1–P3 |
| ③a | 离线解出的**候选补正** | 由 ② 离线解出 |
| ③b | 该候选在**新真机数据**上确实降低 gap | 会话 2–3 的 10 个 matched triplet |

**三项全部完成才进入 Step 2。** ③a 与 ③b 必须分开：
`sim/step1_gate.py:101` 的 `optimal_da` docstring 自承「**非因果**（用到全序列）」——
它对每条 episode 事后解出不同的 δa，只能给上界，**不是**可在未知 episode 上执行的策略。

## 2. 架构决定：(d) IMU 条件化的自适应前馈

```
δa_t = F_cmd( a⁰_{t:t+K}, ideal_{t:t+K}, z_t )  +  R_imu( e_≤t )
                                    ▲
       z_t = E_imu( ω_≤t, q_≤t, a_≤t )   ← 慢变执行状态(延迟/增益/共振强度)
```

- 已知未来指令承担**主**补偿；
- IMU **不**负责预测尚未发生的全部瞬时误差；
- IMU 估计**慢变**执行状态，据此调整前馈；另保留一个很小的实时残差项。

与 `RESEARCH_PLAN_v5.md` 的原始混合结构一致（「每 chunk（5s 指令已知）提前算
sim_ideal，喂补正当参照」+「用外置 IMU 观测真机实际运动」）。

### 为什么不是纯 IMU 反馈

`CAUSAL_CEILING.md` 实测（同网络同划分，只换输入）：

| 输入 | 留出 R² ⇒ 降幅上限 |
|---|---|
| ⑥ 仅测量侧（IMU 误差历史 + 编码器） | **3.7%** |
| ⑤ 仅指令侧（已知未来指令） | 26.1% |
| ⑦ 全部 51 维 | 29.6% |

**术语精度**：3.7% **不是**严格证明的信息论硬上限，而是「当前特征集、TCN、
数据与划分下的经验可预测率」（`CAUSAL_CEILING.md` §6.1 自己就这么写）。
结构性的部分（要修的是自己**还没造成**的误差）是信息论的；**3.7% 这个数字是经验的**。
数学上不能断言任何反馈网络都超不过它。

但项目决策上结论不变：141 ms 因果延迟 + 测量侧经验 R² 仅 3.7% +
两次实时反馈真机均恶化（+31.7%、+73.1%）⇒ **不赌**一个新网络把纯 IMU 反馈
从 ~4% 抬到 15%。

### 一条支持慢适应通道的证据

`causal_ceiling.py` 里 TCN 的感受野 = `1 + 2×(1+2+4)` = **15 帧 = 0.75 s**。
那个 3.5 pp 的边际贡献是**在 0.75 秒窗口内**测的 —— 结构上无法表示跨集/跨会话的
慢适应。所以它**不构成**对 `z_t` 通道的上界。

而慢漂移确实存在且量级可观：`AD_pi_only_RESULT.md` 记录「臂内前后半差
A +16.3% / D −19.3%」——同一条臂同一会话内前后半 gap 能量差 16–19%，
与目标效应同量级。

> 这**不**证明 `z_t` 有效（漂移存在 ≠ 能从 IMU 估出），只说明它瞄准的东西真实存在。

## 3. 两个 claim 必须拆开

| | 对比 | 回答 | 门槛 |
|---|---|---|---|
| **H1** | **C − A**（`r_CA`） | 混合补正总体是否有效 | 见 §4，**15%**（confirmatory） |
| **H2** | **C − B**（`r_CB`） | 运行时 IMU 是否有增量 | **不适用 15%** —— 本批**探索性**，见 §5 |

三臂：`A` 裸 ACT ／ `B` 仅指令侧补正（`F_cmd`）／ `C` 指令侧 + 实时 IMU。
**B 与 C 的 `F_cmd` 必须完全相同**，否则 `C−B` 测的不是 IMU 的边际贡献。

**必须诚实声明**：
- `C−A ≥ 15%` 只证明**混合方法**有效；
- 只有 `C−B` 才证明**运行时 IMU** 有用；
- 若 `C−B ≈ 0`，本方法实质退化为「指令侧前馈」，IMU 仅用于学习与评价。

**15% 从此只称为「混合系统的总效果门槛」，不再称为「IMU 反馈效果门槛」。**

## 4. H1 的判据（冻结）

### 指标

```
r_i = 1 − L_C,i / L_A,i
```

`L` = pp2 **全程** gap 能量 = `bandpass(real − ideal)` 陀螺三轴，0.5–9 Hz，
41 抽头 FIR，ideal 由 `chunks[].raw` 逐 chunk 渲染 —— 与 `analyze_ab` 同口径。

- **主指标保留接触帧**（候选在接触窗输出为零，但主指标不删这些帧
  —— 避免靠删难点换漂亮数字）。
- 预先排除的非接触运动段仅作**机制指标**，不作判据。

### 通过条件（全部满足）

1. `median(r_CA) ≥ 15%`
2. **对 `r_i` 做单样本 t 检验**（H0: `r = 0`），`p < 0.05` 双侧，且均值方向为改善
   —— **不是**对原始 `L` 做配对 t 检验，两者不可混用
3. `≥ 8/10` 个 block 为正向改善
4. **每个会话各自的中位数 > 0**（2 会话 × 5 block）
5. 任务成功率与安全性不下降（sat_pct、stale、nan 不劣于 A）

15% 有项目内先例：`PREREG_FF_insert.md:59`「降幅 < 15% 或 p > 0.05 ⇒ 判否」。

**主检验固定为条件 2 的单样本 t 检验**；Wilcoxon 符号秩仅作稳健性附报，不得替换主判据。

### 旧 A/D 数据能提供什么、不能提供什么

`outputs/ab2/AD_result.json`（2026-07-29，A/D 各 10 集，**块跑**）：

| 量 | 值 | 能否传递到本设计 |
|---|---|---|
| A 臂 CV | **11.59%** | ✅ **可传递** —— 同任务同裸 ACT 基线，新实验的 A 臂还是它 |
| D 臂 CV | 37.39%（含离群）／5.52%（剔除） | ❌ D 是失败的 π，与新候选结构无关 |
| A↔D 指标配对相关 ρ | +0.056 | ❌ **不可传递，也不是下界** —— 块跑下按 index 配对的 episode 在时间上相隔很远，测的根本不是交替设计下的 ρ，是另一个量 |
| A 臂 lag-1 自相关 | +0.683，95%CI **[0.04, 0.93]** | ⚠ 仅用于说明「episode 尺度漂移**存在**」，CI 太宽不能用于定 n |

离群判定用**预先规定**的规则（中位数 3×MAD）：A 臂 0 个，D 臂 1 个（ep1）。
两套（保留／剔除）在 `sim/step1_design_analysis.py` 输出中**都列出，不默认删除**。

### 样本量：n = 10 个 matched triplet（事前固定）

**`n = 10` 事前固定，不依赖旧 A/D 的 ρ 点估计**（该点估计不可传递，见上表）。
同时预注册它在若干 ρ／SD(r) 情景下的工作特性：

Monte Carlo **联合模拟五项合取判据**（`sim/step1_design_analysis.py`，nsim=40000，
假设 CV_A = CV_C = 11.59%）：

| 真实效应 | ρ=0.00 (SD=16.4%) | ρ=0.35 (SD=13.2%) | ρ=0.68 (SD=9.2%) |
|---|---|---|---|
| 0% | 0.3% | 0.1% | 0.0% |
| 10% | 15.0% | 13.1% | 7.2% |
| **15%** | **42.8%** | **47.3%** | **49.7%** |
| **20%** | **74.6%** | **83.5%** | **92.7%** |
| 26% | 95.0% | 98.5% | 99.9% |
| 33% | 99.7% | 100.0% | 100.0% |

> ⚠ **不得称本设计「对 ρ 稳健」。** 真实效应 20% 时功效在 **75%（ρ=0）～93%（ρ=0.68）**
> 之间；真实效应恰为 15% 时仅 **43%～50%**。准确说法是：
> **n 事前固定、不依赖不可靠的 ρ 点估计**，其功效随 ρ 变化已如上表预注册。

条件⑤（成功率/安全性）无法模拟 ⇒ 上表为**上界**，真实功效 ≤ 此值。

**各条件单独通过率**（真实 20%，ρ=0.35）：① 84.5%／② 98.9%／③ 97.6%／④ 99.5%
⇒ **合取 83.4%**。各项取 min = 84.5% ≠ 联合 83.4%（条件不独立，min 只是上界）
—— 故必须联合模拟，不能用各项功效取 min 冒充。**最卡的是条件①**。

### 为什么是 8/10 而不是 9/10

在 SD(r)=15.9%、真实效应恰为 15pp 时，`≥9/10` 的功效仅 **46.4%**，
`≥8/10` 为 75.8%。`9/10` 在效应达标时仍有过半概率判否。

且**加大 n 救不了固定比例的符号判据**（比例判据随 n 增大反而更难满足）：
n=10 需 9 个 → 46.4%；n=14 需 13 个 → 27.6%；n=16 需 15 个 → 20.9%。

（`9/10` 的 H0 下 α=0.0107、`8/10` 为 0.0547；本设计中符号计数是**辅助**条件，
统计显著性由条件② 承担，故 α 略高可接受。）

### 关于「门槛=期望效应 ⇒ 功效只有 50%」

上表中真实效应恰为 15% 时功效 43–50%，这是**门槛设在期望效应上的必然结果**。
本设计接受这一点，含义是：

> 15% 是**实用显著性下限**（低于此不值得继续），**不是**期望效应。
> 本设计在**真实效应 ≥20%** 时功效 75–93%；若真实效应恰在 15% 附近，
> 判否是**预期内**的结果，应解读为「效应不足以支撑继续」，而非「方法无效」。

参照：指令侧天花板 26.1%，需 57% 提取率才到 15%。

### 交替是硬性要求

`AD_pi_only_RESULT.md` 那次是**块跑**，漂移直接进入误差。A 臂 lag-1 自相关
+0.683 说明 episode 尺度的漂移确实存在，matched triplet 让同一 block 内的
A/B/C 在时间上相邻，从而共享这部分漂移。

**⇒ 必须用 §8 的 matched triplet（冻结的平衡顺序），不得块跑。**
但**不得**据此宣称能达到 ρ=0.68 —— 该点估计的 CI 是 [0.04, 0.93]，
真实 ρ 由本批数据**实测**（见 §5 交付物）。

## 5. H2 的处理：本批探索性 + 后续独立 confirmatory

`C − B` 的预期效应仅约 3.5 pp ⇒ **本批 10 个 block 必然只是探索性的。**

### 本批（10 个 matched triplet）

H2 **仅为探索性**，只交付、不判定：

| 交付物 | 标注 |
|---|---|
| `SD(r_CB)`、`SD(r_CA)` | **可行性/方差估计** |
| `ρ_AC`、`ρ_BC` 及其 CI | **可行性/方差估计**（n=10 时 CI 很宽） |
| `C−B` 效应量与配对 CI、方向、跨会话一致性 | 探索性 |

**这些一律不作通过门槛。** 之所以要它们，是因为它们是排后续 H2 会话的唯一依据
—— 旧 A/D 数据测不出交替设计下的配对结构（§4）。

### 后续独立 H2 confirmatory 的样本量（公式此刻冻结）

```
n = ceil( (z_{1−α/2} + z_{1−β})² · SD(r_CB)² / δ_min² )
```

| 参数 | 冻结值 |
|---|---|
| α | 0.05（双侧） |
| power | 0.80 |
| 系数 `(z+z)²` | 7.849 |
| `δ_min`（最小有意义效应） | **3.5 pp** |
| 取整 | **向上取整** |
| `Nmax` | **60 对** |

**若公式给出的 n > Nmax=60 ⇒ 判定「本平台参数下 H2 不可行」并如实报告**，
不降门槛硬做。代入示例：

| SD(r_CB) | 公式 n | 判定 |
|---|---|---|
| 6.0% | 24 | 采用 |
| 9.2% | 55 | 采用 |
| 11.7% | 88 | **> Nmax ⇒ 判不可行** |
| 16.4% | 173 | **> Nmax ⇒ 判不可行** |

**后续 H2 confirmatory 必须用独立数据**，n 由上式代入本批实测 `SD(r_CB)` 计算。

### 若要把本批并入未来 H2 检验

必须走**一次性 blinded sample-size re-estimation**，否则属 optional stopping：

- **检查时点**：本批 10 个 block 全部完成后，**仅此一次**
- **只读取 `SD(r_CB)`**；**不读**均值、方向、p 值
- 公式／α／power／`δ_min`／`Nmax`／取整规则 = 上述，**不得改动**

未按此执行 ⇒ 本批数据**不得**并入 H2 检验。

## 8. 采集设计

### 会话 1 — 开环辨识（约 23 集）

`BCORR_MODE=probe`：注入由种子完全决定的带限白噪声 δa（0.5–9 Hz，六关节独立），
**不读 IMU、不经 π**。

| 档 | mode | seed | mrad | 集数 | 作用 |
|---|---|---|---|---|---|
| P0 | off | — | — | 5 | 裸 ACT 基线（交付物 ①） |
| P1 | probe | **1000–1007，每集一个** | 1.5 | 8 | 主辨识集 |
| P2 | probe | **2000, 2001, 2002 各 2 集** | 1.5 | 6 | **跨 seed 前向预测验证** |
| P3 | probe | **复用 1000–1003** | **3.0** | 4 | 幅值线性检验 |

**P3 必须复用 P1 的 seed** —— 线性检验要的是「同一段激励波形、幅值 ×2 ⇒ 响应是否 ×2」；
换 seed 会把幅值变化与激励变化混在一起。

**现有实现问题（须先修）**：`b_correction_deploy.py:54` 的 probe 表在 `__init__`
一次性生成，而 `reset()` 会把 `stats["frames"]` 归零 ⇒ **每集都从噪声序列第 0 帧重放**，
「seed=1 × 8 集」实际只有 **1 个**噪声实现、重复 8 次，不是 8 个独立实现。
须改为按集号重新生成，并把当集实际 seed 写入日志。

### H 的跨 seed 验证（独立性第一关）

- 训练 seed 与测试 seed **在采集前写死**（已在上表）；
- 测试 seed **不参与** lag、ridge、λ、H 结构或候选选择；
- ≥3 个完全未见的测试 seed（2000/2001/2002）；
- 每个测试 seed 重复 2 集；
- 统计时**先在 seed 内聚合**，以 **seed 为独立单位**。

### 会话 2–3 — confirmatory：10 个 matched triplet（30 集）

候选**冻结后**执行，**不做在线搜索，不更新候选**。

**三臂定义**：

| 臂 | 内容 |
|---|---|
| `A` | 裸 ACT |
| `B` | 仅指令侧补正 = `F_cmd` |
| `C` | 指令侧 + 实时 IMU = `F_cmd` + `R_imu`／`z_t` |

**`B` 与 `C` 必须使用完全相同的 `F_cmd`**，`C` 只多出 IMU 通道
—— 否则 `C−B` 测的就不是「实时 IMU 的边际贡献」。

**Matched triplet 规则**：

- 每个 block 含 `A`、`B`、`C` 各一集，共 **10 block = 30 集**
- 顺序用**预先生成并冻结**的平衡序列，尽量覆盖 `ABC/BCA/CAB/ACB/CBA/BAC`
  六种排列（附录 A）
- 每个 block 使用**相同的标准化 reset／初始条件**
- **独立单位 = 10 个 block，不是 30 个 episode**（统计时以 block 为单位）
- 分别计算 `r_CA = 1 − L_C/L_A` 与 `r_CB = 1 − L_C/L_B`

**⇒ 必须 matched triplet，不得块跑，也不是简单固定的 ABCABC 循环。**

独立性来自：新 episode、新 reset、未参与候选选择的任务实现、跨会话。

分 2 会话各 5 block：
- 只做一个会话 ⇒ 只能声称「**同会话条件下**可补正」；
- 完成两个会话 ⇒ 方可声称「跨会话稳定」。

### 为什么三臂一起跑，而不是先 A/C 再补 B

1. 三臂 matched triplet **本身就是产生真正配对数据的实验** —— `ρ_AC`／`ρ_BC`／
   `SD(r_CA)`／`SD(r_CB)` 从此是**实测**，不再靠旧数据外推（§4 已说明旧数据测不出这些）；
2. **H1 判否时 B 臂最有价值** —— `B−A` 指出失败在前馈部分还是 IMU 部分。
   只跑 A/C 的话，判否后只知道「C 不行」，不知道往哪修。

### 是否需要跨 FF 开关

取决于 claim：
- 只声称「裸 ACT、pp2 分布内有效」⇒ **不强制**；
- 声称「G 适用于裸 ACT 与 FF 两种控制条件」⇒ **必须**跨 FF 验证。

本预注册取前者。

## 10. 诚实边界

1. **15% 是实用显著性下限，不是期望效应。** 真实效应恰在 15% 时通过概率仅
   43–50%，这是**门槛=效应**的必然结果，设计已知且接受。
2. **本设计不是「对 ρ 稳健」。** 真实效应 20% 时功效在 75%（ρ=0）～93%（ρ=0.68）
   之间。准确说法是 n 事前固定、不依赖不可靠的 ρ 点估计，其情景表已预注册（§4）。
3. **旧 A/D 的 ρ=+0.056 不可传递，也不是下界** —— 块跑下按 index 配对测的是另一个量。
   真实的 ρ_AC／ρ_BC 由本批 matched triplet **实测**，n=10 时其 CI 仍会很宽，
   故只标注为「可行性/方差估计」，不作门槛。
4. **H2 在本批预算下不可能有结论**，只作探索性报告；后续 confirmatory 需独立数据。
5. **3.7% 是经验值不是硬上限**（§2）。若将来有更强信息源（视觉、更长历史、
   原始 IMU），该数字可能被抬高。
6. 功效计算中**唯一**用到的旧数据是 **A 臂 CV = 11.59%**，并假设 `CV_C ≈ CV_A`
   —— C 臂的 CV 未知，这是本预注册对已有数据依赖最重的一处假设。
   旧 D 臂 CV（37.4% 含离群／5.5% 剔除后）**未**用于任何 n 的计算。
7. 全部功效计算假设 `r_i` 近似正态、各 block 独立；条件⑤（成功率/安全性）
   无法模拟，故 §4 的功效表是**上界**。跨会话的批次效应未建模。

## 附录 A — 冻结的 block 顺序

10 个 matched triplet 的臂顺序，采集前生成并冻结（六种排列尽量均匀覆盖）：

| block | 顺序 | | block | 顺序 |
|---|---|---|---|---|
| 1 | A B C | | 6 | B A C |
| 2 | B C A | | 7 | A B C |
| 3 | C A B | | 8 | A C B |
| 4 | A C B | | 9 | B A C |
| 5 | C B A | | 10 | C B A |

会话划分：block 1–5 → 会话 2；block 6–10 → 会话 3。

构造法：六种排列各一次（此时每臂在每位置各 2 次），再补 4 个
（`ABC`/`ACB`/`BAC`/`CBA`）使每臂恰在**一个**位置多 1 次。位置计数：

| 位置 | A | B | C |
|---|---|---|---|
| 首 | **4** | 3 | 3 |
| 中 | 3 | **4** | 3 |
| 末 | 3 | 3 | **4** |

⇒ 每臂各在一个位置上多一次，三臂对称，**无系统性位置偏倚**。
（10 不是 6 的倍数，无法完全平衡；这是最接近的配置。）
