## 1. Step 1 的定义（已定）

> 一组随机、受控的真机干预实验，用来证明补正方向确实存在，
> 并采集 Step 2 构建 G 所需的数据。

**不是**完整的真机 PPO，**不是**训练最终的 π。

**范围（写死）**：ACT 冻结；单一任务 = **pp2**；20 Hz；六关节位置补正；
研究范围限于当前任务分布，**不追求**「任意机器人动作」的通用 G。

### 三个交付物

| | 内容 | 出处 |
|---|---|---|
| ① | 一套干净的裸 ACT 真机基线 | 会话 1 的 P0 |
| ② | `D_real` = {状态, 动作, 补正, 真实后续响应} | 会话 1 的 P1–P3 |
| ③a | 离线解出的**候选补正** | 由 ② 离线解出 |
| ③b | 该候选在**新真机数据**上确实降低 gap | 会话 2–3 的 10 个 matched triplet |

**三项全部完成才进入 Step 2。** ③a 与 ③b 必须分开：
`sim/step1_gate.py:101` 的 `optimal_da` docstring 自承「**非因果**（用到全序列）」——
它对每条 episode 事后解出不同的 δa，只能给上界，**不是**可在未知 episode 上执行的策略。

## 2. 架构决定：(d) IMU 条件化的自适应前馈

```
δa_t = F_cmd( a⁰_{t:t+K}, ideal_{t:t+K}, z_t )  +  R_imu( e_≤t )
                                    ▲
       z_t = E_imu( ω_≤t, q_≤t, a_≤t )   ← 慢变执行状态(延迟/增益/共振强度)
```

- 已知未来指令承担**主**补偿；
- IMU **不**负责预测尚未发生的全部瞬时误差；
- IMU 估计**慢变**执行状态，据此调整前馈；另保留一个很小的实时残差项。

与 `RESEARCH_PLAN_v5.md` 的原始混合结构一致（「每 chunk（5s 指令已知）提前算
sim_ideal，喂补正当参照」+「用外置 IMU 观测真机实际运动」）。

### 为什么不是纯 IMU 反馈

`CAUSAL_CEILING.md` 实测（同网络同划分，只换输入）：

| 输入 | 留出 R² ⇒ 降幅上限 |
|---|---|
| ⑥ 仅测量侧（IMU 误差历史 + 编码器） | **3.7%** |
| ⑤ 仅指令侧（已知未来指令） | 26.1% |
| ⑦ 全部 51 维 | 29.6% |

**术语精度**：3.7% **不是**严格证明的信息论硬上限，而是「当前特征集、TCN、
数据与划分下的经验可预测率」（`CAUSAL_CEILING.md` §6.1 自己就这么写）。
结构性的部分（要修的是自己**还没造成**的误差）是信息论的；**3.7% 这个数字是经验的**。
数学上不能断言任何反馈网络都超不过它。

但项目决策上结论不变：141 ms 因果延迟 + 测量侧经验 R² 仅 3.7% +
两次实时反馈真机均恶化（+31.7%、+73.1%）⇒ **不赌**一个新网络把纯 IMU 反馈
从 ~4% 抬到 15%。

### 一条支持慢适应通道的证据

`causal_ceiling.py` 里 TCN 的感受野 = `1 + 2×(1+2+4)` = **15 帧 = 0.75 s**。
那个 3.5 pp 的边际贡献是**在 0.75 秒窗口内**测的 —— 结构上无法表示跨集/跨会话的
慢适应。所以它**不构成**对 `z_t` 通道的上界。

而慢漂移确实存在且量级可观：`AD_pi_only_RESULT.md` 记录「臂内前后半差
A +16.3% / D −19.3%」——同一条臂同一会话内前后半 gap 能量差 16–19%，
与目标效应同量级。

> 这**不**证明 `z_t` 有效（漂移存在 ≠ 能从 IMU 估出），只说明它瞄准的东西真实存在。

## 3. 两个 claim 必须拆开

| | 对比 | 回答 | 门槛 |
|---|---|---|---|
| **H1** | **C − A**（`r_CA`） | 混合补正总体是否有效 | 见 §4，**15%**（confirmatory） |
| **H2** | **C − B**（`r_CB`） | 运行时 IMU 是否有增量 | **不适用 15%** —— 本批**探索性**，见 §5 |

三臂：`A` 裸 ACT ／ `B` 仅指令侧补正（`F_cmd`）／ `C` 指令侧 + 实时 IMU。
**B 与 C 的 `F_cmd` 必须完全相同**，否则 `C−B` 测的不是 IMU 的边际贡献。

**必须诚实声明**：
- `C−A ≥ 15%` 只证明**混合方法**有效；
- 只有 `C−B` 才证明**运行时 IMU** 有用；
- 若 `C−B ≈ 0`，本方法实质退化为「指令侧前馈」，IMU 仅用于学习与评价。

**15% 从此只称为「混合系统的总效果门槛」，不再称为「IMU 反馈效果门槛」。**

## 4. H1 的判据（冻结）

### 指标

```
r_i = 1 − L_C,i / L_A,i
```

`L` = pp2 **全程** gap 能量 = `bandpass(real − ideal)` 陀螺三轴，0.5–9 Hz，
41 抽头 FIR，ideal 由 `chunks[].raw` 逐 chunk 渲染 —— 与 `analyze_ab` 同口径。

- **主指标保留接触帧**（候选在接触窗输出为零，但主指标不删这些帧
  —— 避免靠删难点换漂亮数字）。
- 预先排除的非接触运动段仅作**机制指标**，不作判据。

### 通过条件（全部满足）

1. `median(r_CA) ≥ 15%`
2. **对 `r_i` 做单样本 t 检验**（H0: `r = 0`），`p < 0.05` 双侧，且均值方向为改善
   —— **不是**对原始 `L` 做配对 t 检验，两者不可混用
3. `≥ 8/10` 个 block 为正向改善
4. **每个会话各自的中位数 > 0**（2 会话 × 5 block）
5. **安全与有效性门禁** —— A 类技术故障 / B 类候选失败，见 §4.1

15% 有项目内先例：`PREREG_FF_insert.md:59`「降幅 < 15% 或 p > 0.05 ⇒ 判否」。

**主检验固定为条件 2 的单样本 t 检验**；Wilcoxon 符号秩仅作稳健性附报，不得替换主判据。

### 4.1 条件⑤：安全与有效性门禁（冻结于 2026-08-19）

原写法「sat_pct、stale、nan 不劣于 A」**不可执行** —— `A` 是裸 ACT，不输出补正，
`sat_pct` 天然恒为 0。改为**绝对阈值**，并**严格区分两类异常**：

#### 操作定义

| 量 | 定义 |
|---|---|
| `sat_pct` | **裁剪前**的值超出对应硬界（B: ±2 mrad，C: ±3 mrad）的**帧比例** |
| 接触窗 | 夹爪**指令**跳变（`\|Δgrip\| > 0.02 × GRIP_FULL`）**前后各 10 帧**，`GRIP_FULL = 0.035` |
| 接触窗内 δa | **B、C 都强制输出 0** |

> 接触窗用夹爪**指令**判定，而 chunk 的未来指令在生成时已知 ⇒ 「前后各 10 帧」
> 中的「后 10 帧」也是决策时可得的，不违反因果性（与 §6.2 同一论据）。
> 主指标**仍保留**这些帧（§4）——不修接触窗，但也不删它的帧。

#### A 类：纯技术故障 ⇒ 整个 triplet 作废并重跑

限于**与候选无关**的故障：通信中断、记录/落盘失败、`stale` ≠ 0（IMU 链路）、
某臂帧数 < 550。

**重跑整个 triplet，不重跑单臂**（重跑单臂会破坏 matched 结构）。记录发生次数。

#### B 类：候选失败 ⇒ triplet **保留**，H1 **判否**

- `sat_pct` > **1.0%**（任一臂任一集）
- 模型输出 `nan` ≠ 0
- 急停
- 异常碰撞

**这一类绝不允许"删掉重跑"** —— 否则等于把安全失败从样本里筛掉，
剩下的全是侥幸成功的集，判据就失去意义。发生即记录并计入判否。

#### 其他

- **任务失败的集保留进主分析**，不剔除。

### 样本量：n = 10 个 matched triplet（事前固定）

**`n = 10` 事前固定，不依赖旧 A/D 的 ρ 点估计**（该点估计不可传递，见上表）。
同时预注册它在若干 ρ／SD(r) 情景下的工作特性：

Monte Carlo **联合模拟四项统计条件**（`sim/step1_design_analysis.py`，nsim=40000，
假设 CV_A = CV_C = 11.59%）—— 即完整五项门禁的**功效上界**：

| 真实效应 | ρ=0.00 (SD=16.4%) | ρ=0.35 (SD=13.2%) | ρ=0.68 (SD=9.2%) |
|---|---|---|---|
| 0% | 0.3% | 0.1% | 0.0% |
| 10% | 15.0% | 13.1% | 7.2% |
| **15%** | **42.8%** | **47.3%** | **49.7%** |
| **20%** | **74.6%** | **83.5%** | **92.7%** |
| 26% | 95.0% | 98.5% | 99.9% |
| 33% | 99.7% | 100.0% | 100.0% |

> ⚠ **不得称本设计「对 ρ 稳健」。** 真实效应 20% 时功效在 **75%（ρ=0）～93%（ρ=0.68）**
> 之间；真实效应恰为 15% 时仅 **43%～50%**。准确说法是：
> **n 事前固定、不依赖不可靠的 ρ 点估计**，其功效随 ρ 变化已如上表预注册。

上表是**四项统计条件**（①②③④）的联合模拟；条件⑤无法模拟
⇒ 上表为**完整五项门禁的功效上界**，真实功效 ≤ 此值。

情景模型为**保守恒定 SD**：`r_i ~ N(真实效应, SD)`，SD 与效应无关。
（精确 delta 法含均值比因子 `(L_C/L_A)² < 1`，会使 SD 略小 ⇒ 本模型偏保守，方向安全。）

**各条件单独通过率**（真实 20%，ρ=0.35）：① 84.5%／② 98.9%／③ 97.6%／④ 99.5%
⇒ **四项联合 83.4%**。各项取 min = 84.5% ≠ 联合 83.4%（条件不独立，min 只是上界）
—— 故必须联合模拟，不能用各项功效取 min 冒充。**最卡的是条件①**。

### 为什么是 8/10 而不是 9/10

在 SD(r)=15.9%、真实效应恰为 15pp 时，`≥9/10` 的功效仅 **46.4%**，
`≥8/10` 为 75.8%。`9/10` 在效应达标时仍有过半概率判否。

且**加大 n 救不了固定比例的符号判据**（比例判据随 n 增大反而更难满足）：
n=10 需 9 个 → 46.4%；n=14 需 13 个 → 27.6%；n=16 需 15 个 → 20.9%。

（`9/10` 的 H0 下 α=0.0107、`8/10` 为 0.0547；本设计中符号计数是**辅助**条件，
统计显著性由条件② 承担，故 α 略高可接受。）

### 关于「门槛=期望效应 ⇒ 功效只有 50%」

上表中真实效应恰为 15% 时功效 43–50%，这是**门槛设在期望效应上的必然结果**。
本设计接受这一点，含义是：

> 15% 是**实用显著性下限**（低于此不值得继续），**不是**期望效应。
> 本设计在**真实效应 ≥20%** 时功效 75–93%；若真实效应恰在 15% 附近，
> 判否是**预期内**的结果，应解读为「效应不足以支撑继续」，而非「方法无效」。

参照：指令侧天花板 26.1%，需 57% 提取率才到 15%。

### 交替是硬性要求

`AD_pi_only_RESULT.md` 那次是**块跑**，漂移直接进入误差。A 臂 lag-1 自相关
+0.683 说明 episode 尺度的漂移确实存在，matched triplet 让同一 block 内的
A/B/C 在时间上相邻，从而共享这部分漂移。

**⇒ 必须用 §8 的 matched triplet（冻结的平衡顺序），不得块跑。**
但**不得**据此宣称能达到 ρ=0.68 —— 该点估计的 CI 是 [0.04, 0.93]，
真实 ρ 由本批数据**实测**（见 §5 交付物）。

## 5. H2 的处理：本批探索性 + 后续独立 confirmatory

`C − B` 的预期效应仅约 3.5 pp ⇒ **本批 10 个 block 必然只是探索性的。**

### 本批（10 个 matched triplet）

H2 **仅为探索性**，只交付、不判定：

| 交付物 | 标注 |
|---|---|
| `SD(r_CB)`、`SD(r_CA)` | **可行性/方差估计** |
| `ρ_AC`、`ρ_BC` 及其 CI | **可行性/方差估计**（n=10 时 CI 很宽） |
| `C−B` 效应量与配对 CI、方向、跨会话一致性 | 探索性 |

**这些一律不作通过门槛。** 之所以要它们，是因为它们是排后续 H2 会话的唯一依据
—— 旧 A/D 数据测不出交替设计下的配对结构（§4）。

### 后续独立 H2 confirmatory 的样本量（公式此刻冻结）

求使**单样本双侧 t 检验**达到目标功效的最小 `n`，用**非中心 t 迭代**求解：

```
最小 n 使得   1 − F_nct(t_{1−α/2, n−1} ; df=n−1, ncp=δ_min/SD·√n)
              + F_nct(−t_{1−α/2, n−1} ; ·)   ≥  power
```

| 参数 | 冻结值 |
|---|---|
| α | 0.05（双侧） |
| power | 0.80 |
| `δ_min`（最小有意义效应） | **3.5 pp** |
| 求解法 | **非中心 t 迭代**（z 近似会低估 n，仅作对照） |
| `Nmax` | **60 对** |

代入示例（`sim/step1_design_analysis.py` 输出）：

| SD(r_CB) | z 近似 | **非中心 t** | 判定 |
|---|---|---|---|
| 6.0% | 24 | **26** | 采用 |
| 8.0% | 42 | **43** | 采用 |
| 9.2% | 55 | **57** | 采用 |
| 11.7% | 88 | **90** | > Nmax ⇒ 不可行 |
| 16.4% | 173 | **175** | > Nmax ⇒ 不可行 |

### 「不可行」的准确表述

若 n > `Nmax` = 60，**必须**表述为：

> 在当前 `δ_min` = 3.5 pp、目标功效 80% 与 `Nmax` = 60 的**机时预算**下，
> H2 的 confirmatory 不可行。

**不得**简写成「本平台 H2 不可行」，更**不等于**证明运行时 IMU 没有效果 ——
这是预算约束下的可检验性判定，不是效应存在性的结论。

### 本批与后续的关系：完全独立

- **本批 10 个 block**：完整报告探索性 H2（效应量、配对 CI、方向、跨会话一致性）；
- **后续 H2 confirmatory**：**只使用全新的独立数据**，`n` 由上式代入本批实测
  `SD(r_CB)` 计算；
- **本批数据不并入后续 H2 检验。不设 blinded-SSR 并入分支。**

> 理由：「本批既完整报告 H2、又允许日后并入检验」自相矛盾 ——
> 报告即已解盲，之后再并入就不再是 blinded SSR。故取**完全独立验证**这一条。

## 6. 候选结构（冻结于 2026-08-19）

**第一版不使用神经网络。** 全部为线性/标量运算，逐帧可在线计算。

### 6.1 总体

```
δa_B(t) = clip( Θ · x̃_t ,  ±2 mrad )          ← 指令侧前馈，固定线性滤波器
δa_C(t) = clip( z_t · δa_B(t) ,  ±3 mrad )     ← 实时 IMU 慢增益，z_t ∈ [0, 1.5]
```

两臂共用**同一个** `Θ`（预注册 §3 要求：C 只多出 IMU 通道）。
不使用绝对时间、episode ID，或任何按 pp2 轨迹位置查表的固定补正表。

**限幅（每关节，冻结）**：

| 量 | 上限 | 理由 |
|---|---|---|
| `δa_B` | **±2 mrad** | 与 `step1_gate` 解出的最优 δa（0.86–2.08 mrad RMS）同量级 |
| `δa_C` | **±3 mrad** | `z ≤ 1.5` 时 `1.5 × 2 = 3`；且 **P3 只验证到 3.0 mrad**，不外推 |

两者都远在部署代码原有的 `ε = 10 mrad` 硬界之内；候选**自己**施加这两个更紧的界，
`ε` 仅作最外层兜底。

### 6.2 `x̃_t`：指令侧特征窗（决策时已知）

「因果」= 决策时可得。**chunk 的未来指令在生成时即已知**（5 s 提前量），
所以前瞻不违反因果性 —— 这正是指令侧天花板 26.1% 远高于测量侧 3.7% 的原因。

`x̃_t` = 把下式在 `k = 0…M`（`M = 15`）上堆叠：

```
x_{t+k} = [ ideal(t+k), ideal(t+k+4), ideal(t+k+8),
            a(t+k),     a(t+k+4),     a(t+k+8)  ]        ∈ R³⁶
```

- `ideal` = 逐 chunk 运动学渲染的理想 IMU（与 `build_dagger_labels` 同口径）
- `a` = ACT 原始指令（未加 δa、未加任何修正）
- **索引越过本 chunk 末尾时，钳位到 chunk 最后一帧**
- ⚠ **拟合与部署必须使用逐字节相同的特征构造（含钳位）** ——
  此前 ideal 整集样条 vs 逐 chunk 渲染的口径失配就是这类错误

`M = 15` 由 H 的支撑决定：`δa(t)` 影响 `gap(t … t+15)`，要最优地选它就必须看这一段。

### 6.3 `Θ` 的解法（两级线性，合成后是**一个**固定 FIR）

**第一级 —— baseline predictor**（在没有任何补正时 gap 会是多少）：

```
ê(t) = W · x_t ,     W = argmin Σ_t ‖ e_base(t) − W x_t ‖² + λ_W ‖W‖²
```

`e_base` = 带通(0.5–9 Hz)陀螺 gap。取自 §6.6 的拟合集；其中 P1 部分先减去探针的
已知贡献 `H ⊛ δa_probe`。

**第二级 —— 用实测 H 求逆**（滚动时域最小二乘）：

```
δa_B(t) = argmin  Σ_{k=0}^{M} ‖ ê(t+k) + (H ⊛ δa)(t+k) ‖²  +  λ_K ‖δa‖²
          取解的第一元素
```

两级都是线性 ⇒ 合成为**单个矩阵** `Θ`，部署时只是一次矩阵乘。
`Θ` 在冻结时算出并存盘，运行时不再做任何求解。

**滚动逆的简化（明确写出，不做 MPC）**：解 `δa_B(t)` 时，
**把已提交的 `δa_B(t−1 … t−15)` 对 `gap(t … t+15)` 的残余响应置零**，
即「历史响应置零的局部近似」。这样每帧只是一次固定矩阵乘，不需要在线状态。
该近似的代价**不假设、而是测量**：§6.7 的离线闸门用**完整因果卷积**
（含全部历史 δa）评估最终效果。

**`λ_W`、`λ_K`、H 的 ridge —— 选取规则（冻结）**：
按 **episode 分组的 5 折交叉验证**（不是按帧分，避免同集帧泄漏），
网格 `{1e-3, 1e-2, 1e-1, 1, 10} × trace(XᵀX)/dim`，取使留出折残差能量最小者。

⚠ **每一折都必须在该折的训练 episode 内重新走完整条 `H → W → Θ` 流程**，
**不得**先用全部 P1 拟合一个 H、再拿它去评价各留出折 —— 那样 H 会跨折泄漏，
CV 选出的 λ 会偏乐观。折的划分覆盖全部 11 个拟合 episode（P0 ep0–2 + P1 ep0–7），
每折的 H 只用该折训练集里的 P1 集拟合。CV 只在拟合集内部进行（§6.6）。

### 6.4 H：小补正范围内的局部线性响应

```
gap(t) = Σ_{τ=0}^{15} H(τ) · δa(t−τ) + baseline(t) + 噪声        H ∈ R^{16×3×6}
```

由 P1 的**实际发送 δa + 实际 IMU 变化**岭回归拟合，滞后 0–15 帧。

**为什么 baseline 不建模也不影响 H 的无偏性**：probe 是**外生**的（由 seed 完全决定，
不读状态），故 `δa ⊥ baseline`。即使 baseline 远大于 `H⊛δa`，H 的估计仍无偏。
这是开环 probe 存在的**全部理由**。

H 是**小补正范围内的真机线性回归**，不是 Step 2 的通用仿真 G。

### 6.5 `z_t`：实时 IMU 慢增益（归一化 LMS）

运行时**观测不到**「不补正时的 gap」（`baseline` 不可观测），所以
「预测降幅 vs 实测降幅之比」一类定义在真机上算不出来。可观测的正确形式是
对 `z` 做梯度下降：

```
e(i) = baseline(i) + z · p(i) ,   p = H ⊛ δa_B
∂/∂z ‖e‖² = 2⟨e, p⟩              ← 两项都可观测
```

### ⚠ 在线用的 `e` 不能是 41-tap 带通

正式指标的 0.5–9 Hz 带通是 **41 抽头、居中**的 FIR，需要 **20 帧未来样本（1 s）**，
实时拿不到。故：

| 用途 | 用什么 |
|---|---|
| **H 的拟合**、**在线 LMS** | **未带通的、已对齐的 raw 陀螺 gap**（见下方去直流） |
| 离线闸门（§6.7）、**最终 H1 指标**（§4） | 41-tap 带通，**仅离线** |

带通是线性算子、与卷积可交换，所以同一个 `H`（在 raw 空间拟合）在离线需要带限量时
直接对其输出滤波即可，无须另拟合一个。

**去直流（必需，且完全因果）**：raw 陀螺 gap 含陀螺零偏等直流成分，
而 `p` 也可能有非零均值 ⇒ `⟨e,p⟩` 会混入与目标无关的 DC×DC 项，使 `z` 偏。
对 `e` 与 `p` 施加**同一个**一阶因果高通（截止 0.5 Hz，与频带下沿一致）：

```
m_e(i) = (1−α)·m_e(i−1) + α·e_raw(i)      α = 1 − exp(−2π·0.5/20) ≈ 0.1453
ẽ(i)   = e_raw(i) − m_e(i)                 （p 同法得 p̃，用同一个 α）
```

必须对两者用**同一个**算子，否则内积的梯度含义被破坏。下式中的 `e`、`p` 均指 `ẽ`、`p̃`。

**更新式（每帧，全部为标量运算）**：

```
i = t − L                                    L = 3，即墙钟 t 时刻可得的最新 gap
p(i) = Σ_{τ=0}^{15} H(τ) · δa_B(i−τ)         ⚠ 用**未乘 z 的** δa_B 历史
若 update_mask(i):
    g   = ⟨e(i), p(i)⟩ / ( ‖p(i)‖² + ε )
    z  ← clip( z − μ · g ,  0 ,  1.5 )
δa_C(t+1) = z · δa_B(t+1)                    ← 更新后的 z 用于**下一帧**
```

⚠ **`p` 必须由 `δa_B`（未乘 `z`）算，不能用实际发出的 `δa_C`。**
因为 `e = baseline + z·p`，对 `z` 求导得 `2⟨e, p⟩`，这里的 `p` 按定义就是
「`z=1` 时的响应」。若误用 `δa_C = z·δa_B`，等于把 `z` 计入两次，梯度尺度错误。
（`z` 慢变是这一步的前提 —— `μ=0.005` 即为此。）

| 参数 | 冻结值 |
|---|---|
| `μ` | **0.005** |
| `z` 范围 | **[0, 1.5]** |
| `z₀`（每集重置） | **1.0** |
| `L` | 3 |
| `ε` | 拟合集上 `‖p‖²` 中位数的 **1%**，冻结为一个具体数值并记录 |
| `e` | 因果带通陀螺 gap（0.5–9 Hz），三轴 |

**`z_min = 0` 是刻意的**：只有下界取 0，方向判断错误时补正才能被**拉回到零**。
若取 [0.5, 1.5]，最多只能声称「减弱错误补正」，不能声称「退回零」。

**这条规则能做什么、不能做什么（不得夸大）**：

`z` 是**标量**，只能沿 `δa_B` 已有的方向缩放，**不能旋转它**。而 `p = H⊛δa_B`
的方向来自 `H` ⇒ **LMS 并非「完全不依赖模型」**。准确表述是：

> **在 P2 已验证 `H` 方向正确的前提下，LMS 用实测 IMU 调整补正的幅值。**

它仍有一条实打实的保护性质：若 `H`（因而 `p`）方向错了，`⟨e,p⟩` 的符号会把 `z`
拉向 **0**（§6.5 收敛表：方向完全错时 ≈7 s 退到 0），即**关掉**错误的补正，
而不是放大它。但它**修不了**方向 —— 修方向是 `H` 与 P2 的职责，不是 `z` 的。
v1/v2 两次失败正是方向错；本设计靠 **P2 的数值门槛**（§8）拦截，`z` 只是第二道兜底。

**收敛速度（μ=0.005 实测，`sim/step1_design_analysis.py` 无关，见下方复现片段）**：

| 情形 | 解析最优 `z*` | 收敛到 | 用时 |
|---|---|---|---|
| 方向正确、幅值刚好 | +1.00 | 1.000 | 0 s（本就在最优点） |
| 方向正确、补正偏弱 | +2.00 → 夹持 1.50 | 1.500 | ≈6 s |
| **方向完全错** | −1.00 → 夹持 **0** | **0.000** | **≈7 s** |
| 方向正确、补正过强 2× | +0.50 | 0.501 | ≈38 s |
| 正交（无贡献） | 0 | 0.003 | ≈60 s |

**要点**：`z` 的**保护性**作用（方向错 ⇒ 退回 0）在 **≈7 s** 内生效，一集 30 s 内充分。
但**精调**增益（如"过强 2×"需 38 s、"正交"需 60 s）**慢于一集的长度**，
加上每集重置 `z₀=1`，⇒ **`z` 在单集内只能部分适应**。

这限制了 `C−B` 的期望效应 —— H2 的真实边际很可能**小于** 3.5 pp 的估计。
本设计接受这一点：`z` 的首要职责是**结构性防止方向错误**，其次才是精调。

**`update_mask(i)`（完全因果，部署可算）**：

```
gate(i) ≥ 0.08                                   有效运动（现有因果 gate，rad/s）
且  近 10 帧内无夹爪跃变: max|Δgrip| < 0.02 × GRIP_FULL      非接触
```

`GRIP_FULL` 为**固定常数**（不用逐集 min/max —— 那是非因果的）。
离线闸门仿真必须用**同一个** mask。

### 6.6 数据划分（无重复使用）

| 数据 | 用途 | 是否参与拟合 |
|---|---|---|
| P0 ep **0–2**（3 集） | 拟合 `W`（与 P1 合并） | ✅ 拟合 |
| P1 ep 0–7（8 集） | 拟合 `H`；减去 `H⊛δa_probe` 后并入 `W` 的拟合 | ✅ 拟合 |
| P2（6 集，3 个未见 seed × 2） | **仅**验证 H 跨 seed | ❌ |
| P3（4 集，复用 P1 seed @3.0 mrad） | **仅**验证幅值线性 | ❌ |
| P0 ep **3–4**（2 集） | **仅**做端到端离线闸门（§6.7） | ❌ **永不并回拟合** |

`Θ`、`λ_W`、`λ_K`、H 的 ridge、`ε` 全部只由「✅ 拟合」那两行决定。

### 6.7 离线可行性闸门（在花 30 集之前）

用 P2 验证过的 H，在 **P0 ep3–4** 上离线计算「若施加 `δa_B`，gap 会降多少」：

```
r̂_i = 1 − ‖ e_base,i + H ⊛ δa_B,i ‖²  /  ‖ e_base,i ‖²          i ∈ {ep3, ep4}
```

- **`median(r̂) < 8%` ⇒ 停止，不跑正式三臂**，如实报告负结果
- 通过后，这两集**不重新并入拟合**

这是**模型内**预测（用了 H），不是独立证据；作用只是在明显够不着时省下 30 集。
阈值 8% 此刻冻结。n=2 时中位数等于均值，估计很粗 —— 它只是止损线，不是统计检验。

## 8. 采集设计

### 会话 1 — 开环辨识（约 23 集）

`BCORR_MODE=probe`：注入由种子完全决定的带限白噪声 δa（0.5–9 Hz，六关节独立），
**不读 IMU、不经 π**。

| 档 | mode | seed | mrad | 集数 | 作用 |
|---|---|---|---|---|---|
| P0 | off | — | — | 5 | 裸 ACT 基线（交付物 ①） |
| P1 | probe | **1000–1007，每集一个** | 1.5 | 8 | 主辨识集 |
| P2 | probe | **2000, 2001, 2002 各 2 集** | 1.5 | 6 | **跨 seed 前向预测验证** |
| P3 | probe | **复用 1000–1003** | **3.0** | 4 | 幅值线性检验 |

**P3 必须复用 P1 的 seed** —— 线性检验要的是「同一段激励波形、幅值 ×2 ⇒ 响应是否 ×2」；
换 seed 会把幅值变化与激励变化混在一起。

**现有实现问题（须先修）**：`b_correction_deploy.py:54` 的 probe 表在 `__init__`
一次性生成，而 `reset()` 会把 `stats["frames"]` 归零 ⇒ **每集都从噪声序列第 0 帧重放**，
「seed=1 × 8 集」实际只有 **1 个**噪声实现、重复 8 次，不是 8 个独立实现。
须改为按集号重新生成，并把当集实际 seed 写入日志。

### P2 / P3 的数值通过标准（冻结）

「不过就停止」必须可执行，故定义统一的统计量 **β**：

```
β = argmin_b  ‖ bandpass(gap) − b · bandpass(H_P1 ⊛ δa_applied) ‖²        （过原点的标量 OLS）
```

`H_P1` = 只用 P1 拟合的 H；`δa_applied` = 该集实际注入的 probe。
**β 是"实测响应相对 H 预测的比例"**：H 完全正确 ⇒ β ≈ 1；H 不可迁移 ⇒ β ≈ 0 或为负。
（离线计算，故可用 41-tap 带通。）

| 检验 | 计算 | **通过标准** |
|---|---|---|
| **P2 跨 seed** | 每个未见 seed 内先合并其 2 集算 `β_seed`，得 3 个值 | **median(β_seed) ≥ 0.5** 且 **3 个 seed 的 β 全部 > 0** |
| **P3 幅值线性** | 4 集合并算 `β_P3`（δa 为 3.0 mrad，波形同 P1） | **β_P3 / median(β_seed) ∈ [0.7, 1.3]** |

- **P2 不过 ⇒ H 不可迁移，整条路径作废**，不做 P3、不跑三臂。
- **P3 不过 ⇒ 该幅值范围内非线性显著**，`Θ` 的线性求逆前提不成立，同样停止。

β ≥ 0.5 的含义：即使实测响应只有 H 预测的一半，方向仍正确、求逆仍有意义；
低于 0.5 则模型偏差已大到不宜据以求逆。

### H 的跨 seed 验证（独立性第一关）

- 训练 seed 与测试 seed **在采集前写死**（已在上表）；
- 测试 seed **不参与** lag、ridge、λ、H 结构或候选选择；
- ≥3 个完全未见的测试 seed（2000/2001/2002）；
- 每个测试 seed 重复 2 集；
- 统计时**先在 seed 内聚合**，以 **seed 为独立单位**。

### 会话 2–3 — confirmatory：10 个 matched triplet（30 集）

候选**冻结后**执行，**不做在线搜索，不更新候选**。

**三臂定义**：

| 臂 | 内容 |
|---|---|
| `A` | 裸 ACT |
| `B` | 仅指令侧补正 = `F_cmd` |
| `C` | 指令侧 + 实时 IMU = `F_cmd` + `R_imu`／`z_t` |

**`B` 与 `C` 必须使用完全相同的 `F_cmd`**，`C` 只多出 IMU 通道
—— 否则 `C−B` 测的就不是「实时 IMU 的边际贡献」。

**Matched triplet 规则**：

- 每个 block 含 `A`、`B`、`C` 各一集，共 **10 block = 30 集**
- 顺序用**预先生成并冻结**的平衡序列，尽量覆盖 `ABC/BCA/CAB/ACB/CBA/BAC`
  六种排列（附录 A）
- 每个 block 使用**相同的标准化 reset／初始条件**
- **独立单位 = 10 个 block，不是 30 个 episode**（统计时以 block 为单位）
- 分别计算 `r_CA = 1 − L_C/L_A` 与 `r_CB = 1 − L_C/L_B`

**⇒ 必须 matched triplet，不得块跑，也不是简单固定的 ABCABC 循环。**

独立性来自：新 episode、新 reset、未参与候选选择的任务实现、跨会话。

分 2 会话各 5 block：
- 只做一个会话 ⇒ 只能声称「**同会话条件下**可补正」；
- 完成两个会话 ⇒ 方可声称「跨会话稳定」。

### 为什么三臂一起跑，而不是先 A/C 再补 B

1. 三臂 matched triplet **本身就是产生真正配对数据的实验** —— `ρ_AC`／`ρ_BC`／
   `SD(r_CA)`／`SD(r_CB)` 从此是**实测**，不再靠旧数据外推（§4 已说明旧数据测不出这些）；
2. **H1 判否时 B 臂最有价值** —— `B−A` 指出失败在前馈部分还是 IMU 部分。
   只跑 A/C 的话，判否后只知道「C 不行」，不知道往哪修。

### 是否需要跨 FF 开关

取决于 claim：
- 只声称「裸 ACT、pp2 分布内有效」⇒ **不强制**；
- 声称「G 适用于裸 ACT 与 FF 两种控制条件」⇒ **必须**跨 FF 验证。

本预注册取前者。

## 10. 诚实边界

1. **15% 是实用显著性下限，不是期望效应。** 真实效应恰在 15% 时通过概率仅
   43–50%，这是**门槛=效应**的必然结果，设计已知且接受。
2. **本设计不是「对 ρ 稳健」。** 真实效应 20% 时功效在 75%（ρ=0）～93%（ρ=0.68）
   之间。准确说法是 n 事前固定、不依赖不可靠的 ρ 点估计，其情景表已预注册（§4）。
3. **旧 A/D 的 ρ=+0.056 不可传递，也不是下界** —— 块跑下按 index 配对测的是另一个量。
   真实的 ρ_AC／ρ_BC 由本批 matched triplet **实测**，n=10 时其 CI 仍会很宽，
   故只标注为「可行性/方差估计」，不作门槛。
4. **H2 在本批预算下不可能有结论**，只作探索性报告；后续 confirmatory 需独立数据。
5. **3.7% 是经验值不是硬上限**（§2）。若将来有更强信息源（视觉、更长历史、
   原始 IMU），该数字可能被抬高。
6. 功效计算中**唯一**用到的旧数据是 **A 臂 CV = 11.59%**（仅作历史规划锚点），
   并假设 `CV_C ≈ CV_A` —— C 臂的 CV 未知，这是本预注册对已有数据依赖最重的一处假设。
   旧 D 臂 CV（37.4% 含离群／5.5% 剔除后）**未**用于任何 n 的计算。
7. 全部功效计算假设 `r_i` 近似正态、各 block 独立；条件⑤（成功率/安全性）
   无法模拟，故 §4 的功效表是**上界**。跨会话的批次效应未建模。
8. **`z_t` 在单集内只能部分适应**（§6.5）：方向纠错 ≈7 s 内生效，但精调增益需
   38–60 s，长于一集 30 s，且每集重置 `z₀=1`。⇒ H2 的真实边际很可能**小于**
   3.5 pp 的估计，本批的探索性 `C−B` 应据此保守解读。
9. `Θ` 用两级（先 `ê` 再求逆）而非一次性直接最小化残差，属
   certainty-equivalence 近似，忽略了 `ê` 的估计误差。单级解在统计上更优，
   但两级更可审计；差异为二阶量。

## 附录 A — 冻结的 block 顺序

10 个 matched triplet 的臂顺序，采集前生成并冻结（六种排列尽量均匀覆盖）：

| block | 顺序 | 会话 | | block | 顺序 | 会话 |
|---|---|---|---|---|---|---|
| 1 | A B C | 2 | | 6 | C A B | 3 |
| 2 | B C A | 2 | | 7 | A B C | 3 |
| 3 | A C B | 2 | | 8 | A C B | 3 |
| 4 | C B A | 2 | | 9 | B A C | 3 |
| 5 | B A C | 2 | | 10 | C B A | 3 |

构造法：六种排列各一次（此时每臂在每位置各 2 次），再补 4 个
（`ABC`/`ACB`/`BAC`/`CBA`）使每臂恰在**一个**位置多 1 次。

**总体**位置计数：

| 位置 | A | B | C |
|---|---|---|---|
| 首 | **4** | 3 | 3 |
| 中 | 3 | **4** | 3 |
| 末 | 3 | 3 | **4** |

**会话内**位置计数（每臂在每位置 1–2 次，无会话内偏倚）：

| | 会话 2 首/中/末 | 会话 3 首/中/末 |
|---|---|---|
| A | 2 / 1 / 2 | 2 / 2 / 1 |
| B | 2 / 2 / 1 | 1 / 2 / 2 |
| C | 1 / 2 / 2 | 2 / 1 / 2 |

> 早先的排布使 `C` 在会话 3 中 3/5 次落在末位，会与会话内漂移混淆；
> 现按上表重新分配，**排列多重集不变**，总体平衡不变，且会话内也平衡。

## 附录 B — `matched` 的定义

一个 block 内的三集必须满足：

| 项 | 要求 |
|---|---|
| `block_id` | 三集写入**同一** `block_id`，作为统计的独立单位 |
| 初始物体位姿 | **相同**（同一摆放，或由同一 seed 决定的摆放） |
| reset target | **相同**的复位目标位姿 |
| 初始机器人状态 | **三臂各关节初始编码器差异 ≤ 0.5°**；超出则该 triplet 按 A 类技术故障重跑 |
| `z_t` 初始化 | **三臂各自重新初始化**，**不得跨 episode 继承** |

`z_t` 不得继承这一条尤其重要：若 `C` 臂的慢变状态估计跨集延续，
block 之间就不再独立，`r_CB` 会被上一集的状态污染。
