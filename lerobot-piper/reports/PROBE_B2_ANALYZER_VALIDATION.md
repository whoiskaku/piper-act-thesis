## 1. 阻断项 ①：100 Hz 路径未进入估计器 —— 已关闭

此前 `load()` 只把 `imu100` 交给 `check_recording()` 做记录质量检查，真正进分析的仍是 20 Hz 的
`d["imu"]`，100 Hz 带来的相位分辨率并未进入估计器。现改为：

- `load()` 返回**原始记录 dict**，并强制要求 `t_send` 存在（缺失即报错要求重采）
- `arm_windows(rec, seq, sign)`：按**该臂自身**的 `t_send[w]` 定窗起点，`t_imu` 定采样时刻，
  `zoh_map()` 把实际发送的 20 Hz δa 按 ZOH 映射到 IMU 时间戳；窗长 = 激励 2.0 s + 完整拖尾 1.5 s
- 丢包过半的窗直接弃用；四臂取共同可用窗

### 关键设计：奇偶分解必须在频域做

B+/B− 是**独立复放**，IMU 时间戳互不对齐。时域相减需要插值，而 7 Hz 分量对插值极敏感。
故各臂按自身时间戳独立锁相，再在频域组合：

```
U(f)       = (U_{B+} − U_{B−}) / 2
Y_odd(f)   = (Y_{B+} − Y_{B−}) / 2                        ← 线性增量，噪声 0.5σ²
Y_even(f)  = (Y_{B+} + Y_{B−}) / 2 − (Y_{A1} + Y_{A2}) / 2 ← 非线性/漂移，应 ≈ 0
Y_noise(f) = (Y_{A2} − Y_{A1}) / 2                        ← 噪声底，与 Y_odd 同方差
```

精确、零插值。Ĝ 预测是模型信号，在均匀 100 Hz 相对网格上带限求值，与实际采样网格无关。

### 非均匀采样的锁相

`lockin_at` 改为 Δt 加权：`X(f) = (2/T) Σ x_k e^{−j2πf t_k} Δt_k`。
实测抖动贡献可忽略（见 §4 分解表）。

## 2. 阻断项 ②：CI —— 已关闭（bootstrap 保留，未降级为合成 1σ）

主方法为**真实噪声频域 bootstrap**。三次迭代才做对，过程记录如下（都是实测覆盖率抓出来的）：

| 版本 | 噪声池/重采方式 | 增益 CI 覆盖率 | 症结 |
|---|---|---|---|
| v1 | 拟合残差 ∪ 实测噪声窗，整窗时域重采 | 99%（过宽） | 池只有 6 个整窗，方差估计过糙 |
| v2 | 仅实测噪声窗，**相位随机化**替身 | 60%（过窄） | 冻结了单次实现的周期图，χ²₂ bin 级涨落被抹掉 |
| v3 | 实测噪声窗 → 池化平滑 3×3 **互谱矩阵** → 复高斯替身；**频域**重采 | **92–94%** ✓ | — |

v2→v3 的决定性一步不是替身分布，而是**重采层级**。v1/v2 先用 `reconstruct()` 把确定性部分
重建成整窗连续正弦再加噪声，但真实响应是 2 s 猝发 + 衰减 —— 重建与估计器不自洽，
bootstrap 分布整体偏离点估计（7.0 Hz 偏 0.29，该频点覆盖率 **12%**）。
v3 直接给**观测的锁相值** `Y_r(f)` 加噪声替身的锁相值，确定性部分就是观测本身，无需重建。

替身生成保留有色谱与三轴互相关（对互谱矩阵做 Cholesky），同时恢复正确的谱涨落。

### 覆盖率验收（120 次实现 × 400 bootstrap，名义 95%）

| 情形 | 四频点增益 CI | 四频点相位 CI | 附加时延 CI | τ 1σ | @7 Hz |
|---|---|---|---|---|---|
| 白噪声 | 92% | 94% | 92% | 6.9 ms | 17° |
| 有色噪声 AR(0.6)+三轴相关 | 94% | 92% | 97% | 10.3 ms | 26° |
| 时钟抖动 3 ms + 随机丢样 2% | 94% | 94% | 95% | 7.6 ms | 19° |

解析式 `sqrt((1−γ²)/(2 n_d γ²))` 保留为量级对照：γ²=0.71 ⇒ σ ≈ 15°，与 bootstrap 同量级。

覆盖率目标取**零噪声估计量**（该配置下估计器无噪声时收敛到的值），而非机械真值 ——
覆盖率衡量抽样变异，系统偏差单独报告（见 §3）。

## 3. 零噪声精度与两项已定位的系统偏差

| 量 | 结果 |
|---|---|
| \|z\| | 1.75914 vs 真 1.76067，误差 **0.085%** |
| 残差比 | 0.2059 vs sin(12°)=0.2079 |
| τ | 72.51 ms vs 真 75，偏 **−2.5 ms**（7 Hz 下 6.3°） |

τ 的 −2.5 ms 已完全定位，**不是 bug**，分两部分：

**(a) 有限窗内四音调互泄漏，−1.1 ms。** 激励 2.0 s 内四频点各为整周期（12/13/14/15 周），
但分析窗是 3.5 s，非 2.0 s 的整数倍 ⇒ 音调间不再正交。已排除：不是响应截断
（窗末残余仅峰值的 0.05%），不是离散化（100/200/500/1000 Hz 结果一致到 0.01 ms）。
窗长无法延到 4.0 s —— 注入窗间距只有 3.5 s，再长就吃进隔壁窗的激励。

**(b) 方向失配会伪装成时延，约 −0.12 ms/度。** Ĝ 输出的三轴方向随频率变化，
旋转投影因子 `(H_Ĝ^H R H_Ĝ)/|H_Ĝ|²` 自带频率相关相位：

| 旋转角 | 0° | 5° | 12° | 20° | 30° |
|---|---|---|---|---|---|
| 残差比 | 0.001 | 0.086 | 0.206 | 0.339 | 0.496 |
| 视在时延偏差 | −1.1 ms | −1.7 ms | −2.5 ms | −3.5 ms | −4.9 ms |

**解读真机 τ 时必须并读残差比**，否则会把方向失配误记成时延。已写进分析器输出。

## 4. 端到端验收（`--e2e`）

自检只验估计器内核。另造四条**独立时钟**的合成记录（各自开机时刻、发送抖动 2 ms、
IMU 抖动 2 ms），走完整真机路径 `arm_windows → 频域奇偶分解 → bootstrap`：

```
增益 1.77（真 1.76）✓ | τ +68 ms（真 75）✓ | 偶/奇 0.16 ✓线性
```

τ 偏差分解（8 mrad，j3）：

| 情形 | 增益 | τ 偏差 |
|---|---|---|
| 零噪声·零抖动 | 1.758 | −2.9 ms |
| 零噪声·IMU 抖 2 ms | 1.761 | −3.1 ms |
| 零噪声·+发送抖 2 ms | 1.760 | −2.6 ms |
| 噪声 50 mrad/s·全抖动 | 1.766 | −5.4 ms |

**抖动贡献 ≈ 0**（Δt 加权锁相有效）。偏差几乎全部是 §3 已定位的旋转伪时延。

顺带修掉一个真机会踩的健壮性 bug：`_noise_model` 的特征分解兜底路径批量维度写错，
且正则化项是纯相对的 —— 任一噪声窗退化（全零）时会直接崩。已改为带绝对地板 + 批量特征分解。
