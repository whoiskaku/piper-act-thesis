# RESEARCH_PLAN_v5 — 面向理想动作的侧信道实时补正

- 日期: 2026-07-08（讨论 converge 后开工版；细节在执行中出现时再讨论定）
- 取代: RESEARCH_PLAN_v4（已归档于 git 历史）
- 依据: 指導教員面談 2026-06-17 / 06-24 / 07-06

## 0. 一句话

在不改动、不竞争底层策略（ACT/BiD/StageACT/VLA/…）的前提下，做一个**可后挂（plus-on）的侧信道补正模块**：以**仿真渲染的理想动作**（理想＝ACT 指令）为参照，用外置 IMU 观测真机实际运动，把真机执行拉向理想——填掉「理想 → 现实」之间的墙。**不是**把 IMU/jerk 数值弄平滑。

## 1. 核心设定（已定）

- **理想 = ACT 生成的指令**（非人类 demo、非 jerk 绝对值）；度量 = `real − sim_ideal`（重点在 IMU 空间）。
- **理想的算法（倾向）**: 运动学渲染——指令平滑插值 → FK → 虚拟 IMU 加速度/角速度+重力投影；不往理想里塞动力学（6 关节耦合含在运动学 J̇q̇ 项中；动力学只进「怎么纠」）。sim 测试时最终确认。
- **部署架构 T2**: sim 离紧实时控制路径；每 chunk（5s 指令已知）提前算 sim_ideal，喂补正当参照 + **实时数字孪生可视化**；否掉每步在线 MPC。
- **训练**: **DAgger/监督主干**（真机实测误差、ILC 式迭代；保底交付）**+ 条件触发的有界 RL 微调**（reward=−‖real−ideal‖，专修非线性口袋；残差形状证明需要才加）。不做 full/在线 RL。
- **⚠ 墙的内容不预设**: 旧 setup 的发现（滞后/边界跳变/振动超出/corr=1.000）一律**待重测**，不当既定事实。强候选假设：6 关节惯性/耦合力矩致跟踪偏离（可重复→可纠）。

## 3. 验收与诚实边界

- 验收: `real−sim_ideal` 显著下降（IMU 空间）；成功率不降；模块可挂 ≥2 种底层策略。
- 边界: sim_ideal 目标准度是共享依赖；不可重复随机部分是天花板；反馈带宽受 20Hz/Nyquist 限；IMU 只测安装处；「补偏离→提成功率」须实测证明（老师「是不是本来就没问题」之问）。
