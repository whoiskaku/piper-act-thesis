# 本轮工作总结（2026-09-01 ~ 09-02）—— 汇报用

一句话：**查出并修正了一个贯穿全部历史数字的采样口径缺陷；据此排除了参数层；
按预定规则停止了旧的 G→π 路线；然后用「物理底座 + 双层残差」拿到第一次实质性进展
——3–9 Hz 的波形保真度 ρ² 从 0.193 提到 0.520，7 条预注册判据过 6 条。**

---

## 1. 起点：老师关心的"形状"问题

上一轮的疑问是「G 的 IMU 输出形状到底像不像真机」。我们把口径拆开测：

    残差/实测 = 形状误差 (1−ρ²) + 幅度误差（最优增益 α≠1 的部分）

G-q-v1 的最优增益是 **1.06**，残差 0.564 ≈ 1−ρ² 0.563 ⇒ **幅度基本对，差的全是形状**。
分频看是割裂的：**0.5–3 Hz ρ=0.84（形状对），3–9 Hz ρ=0.33（形状不对）**。
图 `fig6_pp2_shape_bands.png`。

## 2. 最重要的单项发现：采样口径缺陷

被动监听 CAN 总线实测：

| 信号 | 总线上的真实速率 | 我们的落盘 |
|---|---|---|
| 六关节高速反馈 0x251–0x256 | **200 Hz**，零缺样 | 未落盘 |
| **关节角 0x2A5–0x2A7** | **200 Hz** | `GetArmJointMsgs()` 20 Hz **无抗混叠** |
| 腕部 IMU (TSND151) | 100 Hz | `get_latest()` 20 Hz **无抗混叠** |
| 仿真侧陀螺 | 1 kHz | **9 Hz 抗混叠**后降到 20 Hz |

⇒ **一直在拿抗混叠过的预测，去对混叠过的目标打分。**

把两侧都改成同型抗混叠后（pp2 诊断集 4 条 / 2 会话）：

| 3–9 Hz ρ² | 旧口径 | 新口径 |
|---|---|---|
| 天花板（真关节 + 刚体渲染） | 0.391 | **0.692** |
| G-q-v1 | 0.201 | 0.235 |

**这推翻了之前"损失主要在关节→IMU 传感器层"的归因**——那个结论建立在被混叠污染的
天花板（0.487）上。真天花板 0.692，缺口主要在关节轨迹预测。
图 `fig7_recaliber_pp2.png`。

> 顺带确认：**电机电流这一路判否**。它在 speed 之上只增加 +0.07 的相干，
> 且跨会话的 γ²(f) 形状相关只有 +0.220（门槛 0.5）。原计划的 N4SID 前提未获支持。

## 3. 参数层判否（决定性的否定）

此前六轮改动（接触补丁 / 限幅器 / ΔH·u_hf / 学习式残差 / 速度目标 / planner）全部失败，
一直留着「也许只是目标函数从没要求过 3–9 Hz」这个可能性 —— 因为原辨识损失是
**宽带位置 RMS，没有任何带通**，而 3–9 Hz 只占关节位置能量的 **0.003%–0.12%**。

把带内项同权写进目标后重跑（3 seed × 1008 trial，预算固定）：

- 训练 `L_39` 只从 0.5416 → 0.5090（**−6%**），代价是宽带从 0.0307 → 0.0451（**+47%**）
- 留出 A 上的带内项**反而变差**（0.5271 → 0.5620）⇒ 那 6% 没泛化
- 诊断集 3–9 Hz ρ² **0.204 → 0.202**

**⇒ 23 个伺服参数在 3–9 Hz 上确实到顶，这次是在"目标真的要求了它"的前提下测的。**
图 `fig8_band_negative.png`。

（附带定位：j5 占 3–9 Hz 绝对速度误差的 **39.6%**，其误差几乎等于信号本身，
且不是时序问题。留档未追。）

## 4. 旧 G→π 路线按预定规则停止

把 π 的增量通道门禁重跑在 **0.5–3 Hz**（固定 G-q-v1、复用现有 ab4 数据与分析器、
只改评价频带）：

| 判据 | 门槛 | 0.5–9 Hz | **0.5–3 Hz** |
|---|---|---|---|
| P2 beta 中位 | ≥0.5 | 0.9546 ✓ | **0.2809 ✗** |
| P3/P2 幅值线性 | 0.7–1.3 | 1.0134 ✓ | **1.6377 ✗** |
| P0 削减中位 | ≥8% | 2.65% ✗ | **0.86% ✗** |

机理不是"激励不够"（探针能量占比相当），是**相干性塌了**：
ρ(实测 gap, 预测探针响应) 从 0.267 掉到 **0.054**。

**为什么这对 G 也成立**：`H` 是**直接看着真机的增量响应**拟合的、不经任何仿真器，
所以它是这批数据上**任何**增量模型的上界。H 达不到 ⇒ G 更达不到。

> 口径限制（必须并读）：本门禁**不能区分**「真机低频增量响应本身弱」与
> 「这批数据在低频测不动它」。两种读法对眼下的决定一致，但对能否翻案含义不同。

## 5. G-vNext：第一次实质性进展

模型（两层都是**因果 FIR**，不是神经网络）：

    q̂ = G-q-v1(u) + r_q(u, q̂_base, history)        目标 = q200_real − q_Gq
    ω̂ = kin(q̂)   + r_s(u, q̂, q̂̇, history)          目标 = IMU100_real − kin(q200_real)

新采 32 条：会话1 训练族 18（pp2 + pp2a），会话2 留出族 8（pp2f + pp2f60）+ 重复 6。
**留出族只在会话2 采** ⇒「轨迹未参与训练」与「会话未参与训练」同时成立。

### 留出结果（未见轨迹 + 跨会话，8 条）

| | 0.5–3 Hz ρ² | 3–9 Hz ρ² | 最难 20% 窗改善 |
|---|---|---|---|
| G-q-v1 | 0.817 | 0.193 | 0/8 |
| **相位模板** | 0.827 | **0.137** | 0/8 |
| 零输入对照 | 0.817 | 0.193 | 0/8 |
| **G-vNext** | **0.836** | **0.520** | **8/8** |
| 刚体天井（真关节 + 刚体渲染） | 0.939 | **0.649** | — |
| 可重复性上界（真机自身） | 0.983 | 0.840 | — |
| 冻结门槛（预注册） | 0.789 | 0.707 | — |

**7 条判据过 6 条**，唯一未过是判据 2（3–9 Hz 0.520 < 0.707）。
图 `fig9_gvnext_holdout.png`（波形，中位集 + 最难集）、`fig10_gvnext_scorecard.png`（记分）。

### 两点值得对老师强调

1. **没有输给相位模板。** 旧的 `hf_learned_residual` 实验致命的一条正是
   「输给按帧序平均的模板」（−0.253），当时的结论是「缺的是可观测输入或传感器信息，
   不是模型容量」。这次相位模板是 **0.137**，比 G-q-v1 的 0.193 还差
   ⇒ **不是在记忆任务的时间模板**，学到的是真东西。
2. **最难 20% 的波形窗口 8/8 全部改善**（按实测带内能量取最难，防止被少数高能量集拉动）。

### 判据 2 是结构性的，不是调参问题

    0.193 ──r_q──▶ 0.410 ──r_s──▶ 0.520 │ 刚体天井 0.649 │ 可重复性 0.840
                                                 门槛 0.707

**门槛 0.707 高于刚体渲染的天井 0.649** ⇒ 只要传感器侧还是「刚体渲染 + 加性残差」
这个结构，关节层做到多好都过不了。剩下的差距落在 0.649 → 0.840 那一段，
即**刚体假设本身**（支架模态 / IMU 内部滤波 / 外参 / 连杆柔性）。

## 6. 过程中修正的三处错误（说明数字为什么可信）

1. **形状 vs 能量口径**：先前只报 `残差/实测`（能量口径）。分离后确认 G-q-v1 的
   幅度基本对（增益 1.06），差的是形状 —— 老师关心的正是这一点。
2. **带内项权重形同虚设**：`0.5·MSE + 0.5·MSE(带通)` 里带通目标方差小三个数量级，
   带内项几乎不起作用。改成各自按自身尺度归一后，折外 −3.4% → +3.6%。
3. **一条执行异常的集污染训练**：`pp2_ep001` 带 `return_blocked=True`（集内 j2 指令
   −1.44° 而实测 97.49°），关节残差 RMS 620 mrad vs 正常 3–7 mrad，
   **一条占训练集 99.9% 的残差能量**。剔除后折外 +3.6% → **+45.9%**。
   根因：采集编排器按帧数判「录满了」，不管「执行对没对」。已加有效性过滤。

## 7. 现在的位置

- **G-q-v1** 仍冻结，作为**绝对通道**的有效仿真模型
  （命令 → 编码器关节轨迹的有效预测模型；**不得**称为「24 个真实物理参数已辨识的 G」）。
- **G-vNext** 按预注册**不冻结**（判据 2 未过），但 0.5–3 Hz 已达 0.836（门槛 0.789），
  3–9 Hz 从 0.193 提到 0.520。
- **参数层**在 3–9 Hz 上已判否；**旧 G→π 路线**已按预定规则停止；
  **电机电流通道**判否。

## 8. 下一步的三个选项（已讨论，第三项暂停）

- **(a)** 认下 3–9 Hz 的 0.520，用现有保真度重新讨论 π 的用法；
- **(b)** 把 `r_s` 从加性改成**位形相关的乘性 / 二阶结构**（支架模态）——
  这正是 `structure_compare.py` 比过、但当时在混叠口径下做的那条线，**零机时**；
- **(c)** 加装第二个 IMU 分离「传动柔性 vs 支架模态」——
  **用户 2026-09-02 决定暂停，不加第二台 TSND**。

## 9. 引用本文数字时必须带的口径

- 留出 = 会话2 的 pp2f(5) + pp2f60(3)；两层的 nlag/λ 由**训练族折外**选定。
- 真机侧 100 Hz → 9 Hz 低通 → 20 Hz；时基 = TSND 设备 ms + CAN 内核时刻；
  **不用落盘的 20 Hz 字段**。
- 真机逐集正交 Procrustes 旋入机体系（绑带逐会话重装、无标定）；**逐系列最优位移**
  （20 Hz 下 1 样本 = 50 ms，在 3–9 Hz 是 54°–162° 相移，用共同位移会把天井压到近零）。
- 可重复性上界 0.983 / 0.840 是 pp2 **跨会话**实测（比同会话保守）。
  预注册的 0.986 / 0.884 是 `1−‖A−B‖²/‖B‖²` 口径被当 ρ² 用（混了指标），
  所幸偏严；**门槛按预注册保持冻结**。
- 本轮数字**不可与** 17 集 pp2 开发基准集或历史旧口径数字并列。
- 30 条候选中 4 条因越 MuJoCo 模型限位（j2，0.07–0.40°）在采集前剔除，**未放宽限位**。
