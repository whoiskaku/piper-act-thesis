# 预注册：带权目标重辨识（G-q-v2）

**日期** 2026-09-01　**分支** develop　**机时** 0（全部用现有数据）

---

## 0. 为什么

`RESULT_CAN_OBSERVABILITY.md` 之后追加的四项零机时诊断，把 3–9 Hz 的病因定死了：

1. **渲染路径固定住之后，关节就是主因。** 同一条 `kin20`：
   G 的关节 → ρ²=**0.204**，真关节 → ρ²=**0.648**（20 Hz 微分本身只损失 0.692→0.648）。
2. **但 G 的关节位置误差其实很小**：3–9 Hz 逐关节 ρ² = 0.93/0.93/0.73/0.88/0.86
   （j1/j2/j3/j5/j6），残差 0.07–0.15（j3 是 0.40）。
   陀螺放大了它 —— 腕部陀螺是六路贡献的**和**，各路部分抵消而误差不抵消。
3. **灵敏度是强超线性的**（合成 `q = q_true + α·(q_hat − q_true)`）：

   | 关节误差保留 | 0% | 25% | 50% | 75% | 100%(当前) |
   |---|---|---|---|---|---|
   | 陀螺 3–9 Hz ρ² | 0.648 | 0.615 | **0.531** | 0.351 | 0.204 |

   ⇒ **关节误差减半就拿回可得增益的 73%。**
4. **而当初的目标函数从来没要求过 3–9 Hz。** `optuna_ident_enc.evaluate`：

   ```python
   err = q - it["enc"]                      # 全带位置误差, 无带通
   ej  = RMS(err[:,j]) / travel[j]
   loss = mean(ej)
   ```

   而 3–9 Hz 只占关节位置能量的 **0.003%–0.12%**(pp2) / 中位 **0.66%**(套件)。
   ⇒ 权重是万分之一到千分之几量级，**参数从没被要求拟合这个带**。
   0.5–3 Hz 位置 ρ²=0.999–1.000 正是目标优化出来的；3–9 Hz 的 0.73–0.93 是顺带掉出来的。

**六轮结构性改动（接触/限幅器/ΔH·u_hf/学习式残差/速度目标/planner）都绕开了最简单的一件事：
让目标函数去拟合那个带。**

## 1. 不需要重采（原计划的第 2 条撤销）

原以为要重采 90 条标定套件，因为它是 20 Hz 落盘的。实测**编码器侧的混叠可以忽略**：

| | 3–9 Hz ρ²(抗混叠 vs 朴素抽取) | 能量比 | >10 Hz 占比 |
|---|---|---|---|
| j1 | 0.960 | 1.07 | 0.0035% |
| j2 | 0.968 | 1.04 | 0.0001% |
| j3 | 0.953 | 1.08 | 0.0001% |
| j5 | 0.987 | 1.02 | 0.1265% |
| j6 | 0.960 | 1.10 | 0.0293% |

机理：**编码器测的是伺服跟踪的关节，带宽本来就受限；IMU 测的是结构振动，不受限。**
所以 IMU 混叠严重（>10 Hz 占陀螺能量 5.48%，3–9 Hz 真机再现性 88.4%→68.5%），
编码器几乎不混叠。⇒ **现有 90 条数据在 3–9 Hz 是可用的。**

套件的 3–9 Hz 含量（编码器能量占比中位）：
chirp **4.08%** · multisine **8.17%** · step 0.41% · sweep 0.18% ⇒ 有东西可拟合。

## 2. 改什么（唯一的改动）

`optuna_ident_enc.evaluate` 的损失加一个同权的带内项：

```
L = 0.5 · L_broad + 0.5 · L_39

L_broad = mean_j [ RMS(err_j) / travel_j ]                    # 与冻结版逐字相同
L_39    = mean_j [ RMS(bp(err_j, 3–9)) / RMS(bp(enc_j, 3–9)) ] # 带内 残差/实测
```

- `L_39` 按**带内实测 RMS** 归一（不是 travel），所以 **1.0 = 带内预测全零**，
  与全项目通用的 `残差/实测` 口径一致。
- **权重 0.5 事前定死，不调。** 两项各自已无量纲化，等权是唯一无需调参的选择。
  用留出集挑 w 就是在留出集上调参。
- 其余**一个字节不改**：同一切分、同一事件网格、同一读数惯例、
  实际 `t_send`/`t`（不假定严格 20 Hz）、每条等权、只评价被激励关节、不逐集搜滞后、
  `kp6` 仍是 gauge（自由参数 23）。

| 集 | 角色 |

| 90 条激励套件 | 训练 + 原有留出 A/B（与冻结版同切分） |

| | 0.5–3 Hz | 3–9 Hz |
|---|---|---|

## 5. 门禁（**全部**满足才取代 G-q-v1）

**主判据**
1. 诊断集腕部陀螺 **3–9 Hz ρ² ≥ 0.35**（kin20 渲染口径，当前 0.204）。
   依据：灵敏度表上 0.351 对应"关节误差减少 25%"，是有意义的最低门槛。
2. **4 条集里至少 3 条**各自改善，且逐集中位为正。

**防退化判据**（任一不过即判否）

3. 诊断集腕部陀螺 **0.5–3 Hz ρ² ≥ 0.70**（当前 0.735）。
4. 逐关节 **0.5–3 Hz 位置 ρ² ≥ 0.99**（当前 0.993–1.000）。
5. 原有留出 A/B 上的**宽带**位置损失 `L_broad` **≤ 1.05 ×** 冻结 θ* 的同集数值。

**说明**：第 5 条允许 5% 的宽带退化，因为等权目标必然要在两项间取舍；
但 3、4 条保证低频的**波形**不塌。
