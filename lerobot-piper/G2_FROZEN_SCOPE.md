## 1. 模型

```
q̂ = G-q-v1(u) + r_q(·)          两层都是**因果 FIR**
ω̂ = kin(q̂)   + r_s(·)
```

- **G-q-v1** = 「命令 → 编码器关节轨迹的有效预测模型」。
  **不得**称为「24 个真实物理参数已辨识的 G」。
  `kp` = 「有效跟踪增益」，非真实机械刚度；`Ia` 个体值不可解释
  （只有 `(M_link+Ia)/kp` 有意义）；`fc` 无意义。
  `kp6 = 50` 是**事前声明的标尺** ⇒ 自由参数 **23**，不是 24。
- `r_q`：FIR nlag=4, λ=1e-4。`r_s`：FIR nlag=16, λ=1e-4。
  两层的 nlag/λ **均由训练族折外选定**。
- 权重 `outputs/step4_gvnext/{rq/rq_fir.npz, rs/rs_fir.npz}`，**本次收口后不再改动**。

## 2. 冻结数值（开发验证集 8 条：会话2 pp2f + pp2f60）

| | 0.5–3 Hz ρ² | 3–9 Hz ρ² |
|---|---|---|
| G-q-v1（无残差层） | 0.817 | 0.193 |
| **G-2** | **0.836** | **0.520** |
| 相位模板对照 | 0.827 | 0.137 |
| 零输入对照 | 0.817 | 0.193 |
| G-2 结构真天花板（全关节 oracle + `r_s`） | 0.937 | 0.756 |
| 可重复性上界（模型可达，pp2 跨会话实测） | 0.983 | 0.840 |
| 原预注册冻结门槛 | 0.789 ✓ | 0.707 ✗ |

**相对位置**：0.5–3 Hz 达可重复性上界的 **85.0%**（0.836/0.983），**过门槛**；
3–9 Hz 只到 **61.9%**（0.520/0.840）、达结构天花板的 **68.8%**（0.520/0.756），**未过门槛**。

## 3. 适用范围（引用时必须一并声明）

**可用**
- **0.5–3 Hz 的绝对通道**：ρ²=0.836，过门槛，且优于三个对照。
- 关节层：`r_q` 使 3–9 Hz 关节误差降 **38.5%**，5/5 关节改善，宽带关节 RMS **−19.7%**。
- 最难 20% 窗口 **8/8** 改善（相对 G-q-v1）。

**不可用 / 需另附说明**
- **3–9 Hz 的逐时刻波形保真**：ρ²=0.520，**已知限制**，见 §4。
- **未被授权用于训练 π**：G→π 增量通道门禁已判否
  （`plan_g_to_pi_route_stopped`，H 作为上界失败 ⇒ 任何 G 更不行）。
  该判否带一条**未解除的口径限制**：ab4 **无 ±δa 配对**，
  低频失败机理是任务基线淹了探针（ρ=0.054），
  **不能区分**「真机低频增量响应弱」与「这批数据测不动它」。
- 现役 π 由 `sim/train_pi_direct.py` 对**解析雅可比**标签训练，**完全不用 G**
  （pp2 13.9±2.2% / ins 41.1±1.6%）⇒ 本收口**不影响**现有交付。

## 4. 已知限制：3–9 Hz 波形保真不足

### 4.1 缺口的定位（oracle 替换实测，开发验证集中位）

| | 3–9 Hz ρ² |
|---|---|
| G-2 现状 | 0.520 |
| **+ oracle j5** | **0.730** |
| + oracle j2 | 0.556 |
| + oracle j2/j3 | 0.608 |
| 全关节 oracle + `r_s` | 0.756 |

⇒ 缺口在**关节层**，且 **j5 单独占关节层可得空间的 89%**（+0.210 / +0.236）。
j2 只有 +0.036，**尽管**它占 3–9 Hz 关节**位置**残差能量的 74.5%
—— **位置残差能量不能用来判断对腕部 IMU 的影响**（腕部关节几何权重压倒性）。

### 4.2 为什么 j5 修不动（全部已实测，零机时）

| 项 | 数值 |
|---|---|
| j5 带内运动由命令解释的比例 | **幅值 94.1% / 能量 88.6%** ⇒ **不是**「非指令运动」 |
| pp2 跨关节带内输入 \|相关\| | 中位 **0.12**、最大 0.32 ⇒ 单关节隔离买不到可辨识性 |
| j5 残差 vs 其他关节**真实运动**的偏差修正多重相干 | **0.118**(训练) / **0.186**(开发) |
| j5 专用滤波器（带内损失、nlag≤64、λ 全扫） | 开发集 38.8% → **40.1%**（仅 +1.3pp） |
| **+ 位形调度** `s(q)·X` | 折外 47.7% 但开发集 **34.3%（−4.5pp）**，跨会话不泛化 |
| pp2 的位形范围 | `q̂2+q̂3 ∈ [−2.6°, 61.8°]`、sd 20.9° ⇒ **不是**「范围太窄辨不出」 |
| j5 自身命令静止时的带内振动 | 占 j5 误差能量 **21%** |
| j5 自身可重复性上界 | 0.849 ⇒ 误差/信号下限 0.388（现状 0.749） |

**结论**：**现有命令 + G 的预测状态里没有足够信息**去预测 j5 的 3–9 Hz 关节轨迹。

### 4.3 已穷尽的路线（**都不要重跑**）

| 路线 | 判否依据 |
|---|---|
| 参数层（23 参数）再辨识 | 带权 Optuna 3 seed × 1008 trial：`L_39` 仅 −6% 而宽带 +47%；诊断 ρ² 0.204→0.202 |
| 高速 CAN 的 motor speed/current | current 比 speed 只多 +0.07；跨会话 γ²(f) 形状相关 0.220 < 0.5 |
| j5 下游柔性铰（35 格网格） | 底座层 +31.4% 但完整模型 0.520→**0.524**、逐集 3/8；根因 = Δ 有 **87.9%** 落在 `r_s` 特征张成内 |
| 传感器层任何 **LTI** 追加结构 | `kin(q̂)` 本就是 `r_s` 的特征 ⇒ `ω̂=(I+A(z))·kin+…` **已是一般 MIMO 因果线性传递率**；二阶 `H(s)` 只是其特例。实测 `kin` 通道占 3–9 Hz 输出能量 41.6% |
| 神经网络残差层 | 样本内 +64.9% / 折外 **−56.6%** = 纯记忆（17 集） |
| j5 专用 / 位形调度 | §4.2 |
| 跨关节 → j5 定向探针 | **用户 2026-09-02 撤回**。工况只覆盖 j5 误差能量 21%，完美成功估算也只到 ρ²≈0.564（需 0.707） |

### 4.4 本阶段明确不做

- **第二个 IMU：本阶段放弃**（用户 2026-09-02 确认，**非**决策反转，记录不改）。
  它在技术上是分离「支架柔顺 vs 上游结构」的正确仪器
  （同一 link6 上两个陀螺的刚体部分精确抵消），但不在本阶段范围内。
- **条件随机残差（只追频谱/统计保真）：不启动** —— 用户判定它
  **改变了「逐时刻波形保真」这个研究目标**。
  （补充事实：可重复性上界 0.840 意味着剩下的 0.320 仍是**确定性**内容，
  不是随机地板；所以这条路的诚实表述是「放弃波形」而非「剩下是噪声」。）
- **支架模态 / 传感器侧乘性二阶**：已放弃（见 §4.3 的 LTI 张成论证）。
- **不再反向修改 G。**

## 5. 口径（每处引用必须带）

- 真机 100 Hz → 9 Hz 低通 → 20 Hz；关节 200 Hz；
  时基 = TSND 设备 ms + CAN 内核时刻；**不用落盘的 20 Hz 字段**。
- 真机逐集**正交 Procrustes** 旋入机体系（绑带逐会话重装、无标定）。
- 3–9 Hz 的数字必须带**逐系列最优位移**（1 sample = 50 ms = 该带 54°–162° 相位）。
- 多重相干须**偏差修正**（null = q/n），且 **q ≥ n 时退化**（曾据此撤回一个 0.472）。
- **ρ² 不可线性相加。**
- 8 条是**开发验证集**，**不是**密封 holdout（柔性铰探针已看过）。
  真正的密封验证需另采未见轨迹，本阶段不做。
- 可重复性上界用 pp2 **跨会话**实测 0.983 / 0.840；预注册的 0.986 / 0.884 是
  `1−‖A−B‖²/‖B‖²` 口径被当 ρ² 用（混了指标，所幸偏严）。
- 本文数字**不可与** 17 集 pp2 开发基准集或 `structure_compare` 旧口径并列。
