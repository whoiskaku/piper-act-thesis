## 0. 命名约束（**先写死**）

本模型一律称 **「j5 下游有效柔性模态」**。

**不得**称为「已辨识出的 j5 真实传动柔性」。
理由：柔性铰只是在**编码器下游**插了一个二阶自由度，它同样可以吸收
支架柔顺、连杆挠曲、传感器映射误差等。**要验证其物理归属需要第二个 IMU**
（已放弃，见 `plan_g_vnext_result`），因此归属**未定**。

沿用既有口径约束：`kp` 称有效跟踪增益；`Ia` 个体值不解释；
G-q-v1 = 「命令 → 编码器关节轨迹的有效预测模型」。

## 1. 依据（已完成的单点探针）

固定点 ω=8.485 Hz、ζ=0.4（取自旧网格 j5 的 IMU 最优），**底座对底座**、不含残差层：

| 判据 | 训练族 17 条 | 留出 8 条 |
|---|---|---|
| ① j5 编码器 3–9 Hz 误差/信号 | 0.970 → 0.968（−0.1%） | 0.961 → 0.960（−0.1%） |
| ② 柔性铰相对运动（占 j5 带内） | 0.0713°（26.3%） | 0.0813°（29.9%） |
| ③ 腕部 IMU 3–9 Hz ρ² | 0.237 → 0.249（+5.2%） | 0.187 → **0.212（+13.7%）** |
| ④ 腕部 IMU 0.5–3 Hz ρ² | 0.811 → 0.813（+0.3%） | 0.812 → 0.813（+0.2%） |

**与 `r_s` 的重叠**：Δ =（柔性陀螺 − 底座陀螺）的 RMS 是 `r_s` 输出的 53%，
但 ρ(Δ, r_s) = +0.202 ⇒ **`r_s` 只解释了柔性铰贡献的 4.1%，几乎正交**。

落在预先定死的第二条判读（编码器不变、IMU 明显改善、低频不退化）⇒ 放行网格。

> ⚠ **`ρ²` 不可线性相加。** 底座层面的 0.187 → 0.212 **不得**外推为
> 「G-2 的 0.520 → 0.545」。完整模型必须直接评价（阶段 2）。

## 3. 阶段 1：j5 单铰网格（**只搜 j5**）

- 底座 **G-q-v1 的 θ\* 逐字固定**；`r_q`、`r_s` 也**保持不变**。
- **只增加一个自由度**：j5 电机侧/连杆侧之间的被动铰，参数只有 `(ω, ζ)`。
- 结构与实现**复用** `sim/step2_g/structure_compare.py` 的 `build_flex` / `flex_xml`
  （电机侧保留 `joint5`，编码器读电机侧；连杆侧加被动铰）。

**网格（事前定死，固定预算，结束后不追加、不外延）**

| | 值 | 格数 |
|---|---|---|
| ω | 7 个 log 等距 ∈ [3, 16] Hz 🔧 | 7 |
| ζ | {0.1, 0.2, 0.4, 0.7, 1.2} 🔧 | 5 |
| **合计** | | **35** |

上界 16 Hz 由可解析性定：`mj_dt = 0.002 s`，`dt·ωn = 0.2 ≤ 0.25`。
旧网格的 ζ 上界是 0.4 且最优正落在边界上 —— 本次已放宽到 1.2。

> **若选中格落在网格边界**：如实报告为局限，**不外延、不加格**。

**选格（只用训练族）**

- 目标 = **训练族的腕部 IMU 3–9 Hz ρ²**（最大化）。
  旧实验按**编码器**训练损失选格，与机制错配（铰作用在编码器下游）——本次订正。
- **约束**：编码器宽带损失 `L_broad ≤ 1.05 × 底座` 🔧。
  防止「靠拖垮关节层来改善 IMU」。
- 开发验证集**不参与选格**。

## 4. 阶段 2：重新折外拟合 `r_s`

柔性铰改变的正是**编码器下游**的残差，故选定结构后必须重拟 `r_s`。

- **`r_q` 保持不变**（它拟合的是编码器侧，铰不改变其目标）。
- `r_s` 按原规矩重拟：训练族内 **K=6 折外**、按集划分、
  损失 `(1−w)·MSE/var + w·MSE(bp)/var(bp)`（**每项按自身尺度归一**）、`w=0.5`、
  `nlag`/`λ` 由**折外**选、开发验证集不参与。
- `r_s` 的目标仍是 `IMU100_real − kin_flex(q200_real)`；
  输入里的 `q̂` 仍**只用 `r_q` 的折外预测**（防泄漏）。
- **完整模型 = 柔性底座 + `r_q` + 重拟的 `r_s`，直接评价。**

## 5. 阶段 2 的门禁（在**开发验证集** 8 条上）

| # | 判据 | 门槛 |
|---|---|---|
| 1 | 腕部 IMU **3–9 Hz** ρ² 中位 | ≥ **0.560** 🔧（G-2 现为 0.520） |
| 2 | 逐集改善 | ≥ **6/8** 集 |
| 3 | 腕部 IMU **0.5–3 Hz** ρ² 中位 | ≥ **0.826** 🔧（G-2 现为 0.836，容 0.010 退化） |
| 4 | 关节层宽带 RMS | 不恶化 > **5%** |
| 5 | 两个频段仍优于 **相位模板** 与 **零输入对照** | 全部严格优 |
| 6 | 最难 20% 窗口改善占比 | > 50% |

**全部满足**才认定 j5 柔性模态有效；否则本条线终止。

> 门槛 0.560 的依据：探针在底座层给出 +0.025，重拟 `r_s` 后应不低于此；
> 取 +0.040 是为了把「真实增益」与「8 条集的抽样波动」分开。
> **这不是原预注册的判据 2（0.707）** —— 那是最终目标，本阶段不以它为门槛。

## 6. 阶段 3：**本预注册不授权**

只有在**同时**满足下列条件时，才可对**另一个单独关节**做单点探针：

1. 阶段 2 全部通过；
2. 剩余残差**明确指向**某一个具体关节（须有 oracle 替换实测支持，
   如 `+oracle jX` 的 Δρ² 排序）。

**不得**依据旧的 `structure_compare` 结果直接开放 j2 或六关节网格。
届时另行预注册。

## 8. 报告口径（每处引用必须带）

- 称 **「j5 下游有效柔性模态」**；物理归属**未定**。
- 8 条为**开发验证集**，**不是**密封 holdout。
