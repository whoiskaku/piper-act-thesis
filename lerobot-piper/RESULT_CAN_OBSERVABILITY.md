# 高速 CAN 可观测性试验 —— 结果

预注册见 `PREREG_CAN_OBSERVABILITY.md`。采集 2026-09-01。

## 0. 一句话

高速反馈是 **200 Hz**（远超预期），停止门**大幅通过**；但真正的收获不是"多一路电机通道"，
而是查明**关节角在总线上也是 200 Hz**、而我们一直用 20 Hz 无抗混叠抽取——
**把口径修正后，3–9 Hz 的天花板从 ρ²≈0.37 升到 ≈0.67，而 G-q-v1 只有 0.23。**
⇒ 3–9 Hz 的缺口主要在 **G 的关节轨迹预测**，不在传感器层。这**推翻了 §28 的归因**。

## 1. 第 1 步：静止探针（通过）

`sim/step3_canobs/probe_highspd_rate.py`，被动只读、未使能。

| 项 | 实测 | 门槛 |
|---|---|---|
| 逐关节速率 | **200.0 Hz** | ≥ 20 Hz |
| 疑似缺样 | 0 | — |
| 帧间隔 | 中位 5.00 ms，p99 5.09–5.19，最大 5.28 | — |
| Nyquist | **100 Hz** | ≥ 10 Hz |
| 六路帧错位 | 相对 j1 = 0.13/0.27/0.46/0.59/0.73 ms（周期内顺序发送） | — |
| 时钟漂移 | 10 s 内 0 µs | — |

与计划假设不符的三处：`pos` 在 0x251–6 上**不存在**（byte4–7 恒零）；
`effort` = `current` × 固定系数、不含新信息；
**关节角 0x2A5–0x2A7 也是 200 Hz**。

## 2. 两个开放问题的判定（运动集）

**A. `current` 在运动中是活的。** 相邻变化率 ~70%，唯一值最多 1201，量程 0–2527 mA。
静止时的恒定（j1..j6 = 49/659/96/36/123/59 mA）是真恒定，不是字段更新慢。

**B. `motor_speed` 与 `d(q200)/dt` 同源，没有独立输出侧编码器的证据。**
按 |ρ| 选滞后后滞后 ≈ 0（0–5 ms），增益 |0.58|–|0.87|（系统性 < 1 ⇒ 固件给的是平滑估计），
符号逐关节翻转（电机安装方向）。

| 关节 | 行程 | 0.5–3 Hz ρ² | 3–9 Hz ρ² |
|---|---|---|---|
| j1 | 51–59° | 0.996–0.998 | 0.82–0.87 |
| j2 | 101–105° | 0.998–0.999 | 0.94–0.95 |
| j3 | 45–50° | 0.997 | 0.886–0.894 |
| j5 | 20–22° | 0.967–0.973 | 0.878–0.920 |
| j6 | 15–17° | 0.933–0.973 | 0.46–0.54 |
| j4 | **1.7–1.9°** | — | — （激励不足，不判） |

⇒ 200 Hz 关节角消掉的是**帧间混叠**，**不是**「编码器≠连杆角」。
⇒ 既然 speed ≈ dq/dt，**唯一真正新增的通道是 `current`**。

## 3. ⚠ 自造的问题：记录器拖慢了控制环

| 记录 | CAN录 | 帧间隔 中位/p99/最大 | 实际 Hz |
|---|---|---|---|
| 07-27/28 共 7 条 | 否 | 50.15–50.18 / 52.4–55.0 / 54–59 ms | **19.91–19.92** |
| 09-01 ep0/ep1 | **是** | 51.21–51.32 / **84.5–86.4** / **101–103** ms | 19.26–19.32 |

同期 TSND 主机到达 p99 也从 12.95 ms 恶化到 39.75 ms。

**原因**：初版在后台线程里调 SDK 的 `PiperMessage()` + `DecodeMessage()`，
**26.4 µs/帧 × 1800 帧/s**。已改为线程只存原始字节（**0.21 µs/帧，快 125 倍**），
解码推迟到停机后。字节布局已与 SDK 逐位核对（`>hH` / `>ii`）。

**诚实说明**：合成回路复现只看到很小的效应（p99 50.35→50.83 ms），
差别可能在于合成测试里没有 TSND 第三线程一起抢 GIL。
**相关性明确（唯一变更 + 两条流一起退化），机制未完全证实 —— 下个会话必须复核环路时序。**

**数据仍然可用**：TSND 设备端 ms 步长恒为 10、**零丢样**（退化的只是主机到达时刻）；
CAN 是内核时间戳。故本文所有分析**只用设备/内核时间戳，不用落盘的 20 Hz 字段**。

## 4. 抗混叠口径修正 —— 主结果

同一份干净流，只改抽取方式（20 Hz 输出口径不变），逐系列各自的最优位移：

| 口径 | 0.5–3 Hz ρ² | **3–9 Hz ρ²** | 0.5–9 Hz ρ² |
|---|---|---|---|
| 天花板 20 Hz 旧：两侧朴素抽取 | 0.848 | **0.374** | 0.597 |
| 天花板 20 Hz 新：两侧抗混叠 | 0.951 | **0.673** | 0.818 |
| 天花板 100 Hz 原生 | 0.957 | 0.652 | 0.804 |

⇒ **抗混叠单独带来 3–9 Hz 的 ρ² +0.299**；100 Hz 与抗混叠 20 Hz 几乎相同
⇒ 抽到 20 Hz 本身不是瓶颈，**混叠才是**。

G-q-v1（模型未动一个字节，只改真机侧抽取）：

| | 0.5–3 Hz | **3–9 Hz** | 0.5–9 Hz |
|---|---|---|---|
| G-q-v1 旧口径 | 0.716 | **0.185** | 0.431 |
| G-q-v1 新口径 | 0.747 | **0.230** | 0.503 |
| 天花板 新口径 | 0.951 | **0.673** | 0.818 |

口径修正给 G +0.045、给天花板 +0.120，但**倍率几乎相同**（1.243 vs 1.217）——
正是"目标里混入独立噪声、ρ² 被乘上 |A|²/(|A|²+|n|²)"的理论预期，是自洽性检验。

### 归因反转

3–9 Hz 的缺口分解（新口径）：
- **G 的关节轨迹预测：0.673 − 0.230 = 0.443**
- 传感器/可观测层：1 − 0.673 = 0.327

**§28 说"损失主要在关节→IMU 层、23 参数/planner/接触都够不着"，那是建立在被混叠
污染的天花板（0.487）上的。真天花板是 0.673，主因是关节轨迹预测。**

图 `outputs/step3_canobs/fig7_recaliber_pp2.png`：下段 3–9 Hz 最强 4 秒，
橙（真关节 200 Hz）ρ = +0.91/+0.92，紫（G-q-v1）+0.50/+0.53。

### ⚠ 位移敏感性（引用时必须带）

20 Hz 输出下 1 样本 = 50 ms，在 3–9 Hz（周期 111–333 ms）是 54°–162° 的相移：

| 系列 | L=0 | L=1 | L=2 | L=3 |
|---|---|---|---|---|
| 天花板 | **0.664 / 0.681** | 0.008 / 0.030 | 0.366 / 0.403 | 0.000 / 0.022 |
| G-q-v1 | 0.007 / 0.014 | **0.222 / 0.237** | 0.034 / 0.010 | 0.206 / 0.217 |

**必须逐系列用自己的最优位移**；用共同 L 会把天花板压到 0.008。
（作图时我一度重犯了这个错误。）
天花板 L=0 而 G-q-v1 L=1 ⇒ **G 比真关节晚约 50 ms**，与既有滞后所见一致。

## 5. 事前停止门

残差 = 真机 IMU(抗混叠) − G-q-v1，带通 3–9 Hz，100 Hz 时基。
多元相干**必须扣偏置**：q 路输入、n 段平均时零假设水平就是 q/n。

| 集 | 输入 | 原始 γ² | 零假设 q/n | **扣偏置后** |
|---|---|---|---|---|
| ep0 | speed | 0.846 | 0.273 | **0.788** |
| ep0 | current | 0.765 | 0.273 | **0.677** |
| ep0 | speed+cur | 0.934 | 0.545 | **0.855** |
| ep1 | speed | 0.858 | 0.261 | **0.808** |
| ep1 | current | 0.761 | 0.261 | **0.677** |
| ep1 | speed+cur | 0.946 | 0.522 | **0.886** |

阈值 0.35 ⇒ **通过**，两集高度一致。

**但判读必须小心**：残差 ≈（真关节运动 − G 预测的关节运动）经传感器映射，
而 speed ≈ 真关节速度。所以「speed 与残差高度相干」等价于「G 的关节预测不准」——
**它本身不提供改进 G 的手段**（推理时没有真机反馈，见并入条件第 5 条）。
`current` 在 speed 之上只增加 **+0.07**（0.788 → 0.855）。

**未能判定的两条**（预注册要求跨会话）：
- 「两个会话各自独立 ≥ 0.35」：**只采了 1 个会话**（2 条集相隔 2 分钟）。
- 「两会话 γ²(f) 曲线相关 ≥ 0.5」：同会话内两条不同动作之间是 +0.26/+0.15/+0.57，
  这不是跨会话测试，不能顶替。

## 6. 结论与下一步

1. 停止门按字面**通过**，但它指向的方向不是"给 G 加电机电流通道"。
2. 真正的发现：**G-q-v1 的 23 个参数当初是对着 20 Hz 混叠编码器辨识的** ——
   有缺陷的不只是评价口径，**训练目标本身**也有缺陷。
   现在可以拿 200 Hz 抗混叠的真关节轨迹当目标重辨识。
3. 障碍：90 条激励标定套件全部是 20 Hz 落盘的，要利用这一点得**重采标定套件**
   （机械式复放，但要实机时间）。
4. 记录器已修（快 125 倍），**下个会话必须复核环路时序**（应回到 p99 ≤ 55 ms）。

## 7. 口径（引用本文数字时必须带）

- pp2 **诊断集 2 条**，同属 2026-09-01 一个会话，是 **replay 复放**集，
  **不是** 17 集 pp2 开发基准集的裸 ACT 集。**两组数字不可并列。**
- 新会话没有配套 IMU 朝向标定 ⇒ 装着旋转**逐集用正交 Procrustes 拟合**，
  与 §28 用 `load_calib(CALIB)` 的做法不同。
- 时基用 TSND 设备 ms 与 CAN 内核时刻；**落盘的 20 Hz 字段未使用**（环路已劣化）。
- 逐系列各自最优位移；3–9 Hz 的数字对位移极其敏感（见 §4）。
- 固件 **S-V1.5-8**、SDK 0.6.1 ⇒ 属"旧固件 J1–J3 另有倍率"范围，
  `effort` **只作激励代理，不称真实关节力矩**；落盘保留原始 `current`。
