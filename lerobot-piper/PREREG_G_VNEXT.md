它自己写死的停止规则是：「若仍输给相位模板 ⇒ 立即停止；那说明缺的是
**可观测输入或传感器信息，不是模型容量**。」**该规则本轮原样继承**（见 §6 判据 3）。

本轮**只有下列四点**不同，其余一律照旧：

1. **真值改为抗混叠的 IMU100 与 CAN q200**（旧实验的目标是 20 Hz 无抗混叠抽取，

2. **先学习关节层残差，不再固定错误的 `q̂`**（旧实验固定 `q̂ = G-q-v1(u)`，
   只学 IMU 残差；而 3–9 Hz 缺口里 **0.457 在关节层**、0.308 在传感器层）。
3. **重新采集多样化、跨会话 pp2**，而非重复任务模板。
4. **关节残差与传感器残差分开训练和审计。**

## 2. 模型

$$\hat q = G_{q\text{-}v1}(u) + r_q(u,\ \hat q_{\rm base},\ history)$$
$$\hat\omega = kin(\hat q) + r_s(u,\ \hat q,\ \dot{\hat q},\ history)$$

| | 目标 |
|---|---|
| `r_q` | `q200_real − q_Gq` |
| `r_s` | `IMU100_real − kin(q200_real)` |

- **训练 `r_s` 时只能使用 `r_q` 的折外（out-of-fold）预测**，避免训练泄漏。
- 两层**都先用因果 FIR**。**FIR 明显不足时只试一个固定规模的小网络，不做架构搜索。**
- `G_{q-v1}` 冻结不动（θ\* sha16 `ad590ed4ba0b5d33`）。`kin` = 现有刚体传感器渲染。

## 5. 冻结门槛

锚在**真机自身可重复性上界**（任何确定性模型的物理上界）：

| 带 | 可重复性上界 | **门槛 = 80%** |
|---|---|---|
| 0.5–3 Hz | 0.986 | **ρ² ≥ 0.789** |
| 3–9 Hz | 0.884 | **ρ² ≥ 0.707** |

> ⚠ **口径**：0.986 / 0.884 是在 `probe_b2` 的 6 次裸复放上测的
> （`sim/step2_ceiling.py` + 抗混叠对照），**不是在 pp2 上**。
> 会话 2 的 6 条重复将**在 pp2 上实测**同一量。
> **数值门槛 0.789 / 0.707 事前冻结，不随实测值浮动**（否则是移动球门）。
> 若 pp2 实测上界**低于**门槛，则目标本身不可达 —— 那本身就是本轮的结论。

## 6. 判据（**全部**满足才冻结 G-vNext）

在**未见轨迹 + 跨会话留出**（pp2f + pp2f60，会话 2）上评价：

| # | 判据 | 门槛 |
|---|---|---|
| 1 | 腕部 IMU **0.5–3 Hz** ρ² | ≥ **0.789** |
| 2 | 腕部 IMU **3–9 Hz** ρ² | ≥ **0.707** |
| 3 | 两个频段均优于 **G-q-v1**、**相位模板**、**零输入对照** | 全部严格优 |
| 4 | `r_q` 留出 **3–9 Hz 关节误差下降** | ≥ **20%** |
| 5 | `r_q` 逐关节改善 | ≥ **4 / 5 个可动关节**（见下） |
| 6 | 宽带关节 RMS 不恶化 | ≤ **+5%** |
| 7 | **最难 20% 波形窗口**多数改善 | > 50% 的窗口改善 |

**判据 5 的订正**：用户原文写「4/6 关节」，但 **j4 在四个族里全程恒为 0**
（实测 `a_arm[:,3]` 恒为 0.0）⇒ 可动关节只有 **5** 个（j1,j2,j3,j5,j6），
故写作 **≥ 4/5**。

**判据 7 的定义**（防止被少数高能量集拉动）：把留出集切成 4 s 窗口，
按**实测带内能量**取最难的 20%，逐窗比较 G-vNext 与 G-q-v1 的带内残差，
统计改善窗口占比。**汇总指标与逐窗指标必须同时报告。**

**三个对照的定义**：
- **G-q-v1** = `r ≡ 0`；
- **相位模板** = 训练族上按帧序（时间模板）平均的残差 —— 记忆基线；
- **零输入对照** = 同一 FIR 结构但输入置零 ⇒ 只能输出常数 —— 隔离"输入是否携带信息"。

## 7. 报告口径（**每一处引用都必须带**）

- 分别报告 **0.5–3 Hz / 3–9 Hz / 全频段 / 最难波形**，不得只报汇总。
- 逐系列各自最优位移（3–9 Hz 对位移极敏感：1 样本 = 50 ms = 54°–162° 相移）。
- 真机侧 100 Hz → 9 Hz 低通 → 20 Hz；仿真侧同型（`g_q_v1.py:231` 已是）。
- 时基用 TSND 设备 ms 与 CAN 内核时刻；**不用落盘的 20 Hz 字段**。
- 装着旋转逐集正交 Procrustes（跨会话绑带重装 ⇒ 每会话朝向不同）。
- 本轮数字**不可与** 17 集 pp2 开发基准集、也不可与 §28 的旧口径数字并列。
