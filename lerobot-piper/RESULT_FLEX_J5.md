# 结果：j5 下游有效柔性模态 —— **判否**

预注册 `PREREG_FLEX_J5.md`。执行 2026-09-02，机时 0。

## 0. 一句话

阶段 1 的网格在**底座层**确实找到明显更好的点（IMU 3–9 Hz ρ² 0.2365 → **0.3107**，+31.4%），
但阶段 2 把它装进完整模型后，开发验证集上 3–9 Hz 只从 **0.520 → 0.524**，
逐集仅 **3/8** 改善 ⇒ **门禁未过，本条线终止**。

根因已定位并实测确认：**柔性铰的贡献 Δ 有 87.9% 落在 `r_s` 已有特征的张成里**
（训练族折外）。它不是新信息，是 `r_s` 本来就能自己造出来的东西。

### 1.2 局限（按预注册如实报告，**未外延**）

选中格 (3.965, 0.7) **不在**网格边界，但角点 **(3.0, 1.2) = 0.3086 几乎打平**，
而它同时压在 **ω 下界**和 **ζ 上界**上。响应面提示存在一条向「更低 ω / 更高 ζ」

这条脊的方向本身就是线索：ω→低、ζ→高 = 铰**越来越不像共振、越来越像一阶滞后**，
即越来越是一个 **LTI 元件**。这与 §3 的根因一致。

## 2. 阶段 2：重拟 `r_s`（构造的落实）

预注册 §4 写「目标仍是 `IMU100_real − kin_flex(q200_real)`」，
但柔性铰是**仿真自由度**，真机编码器给不出铰角，`kin_flex(q200_real)` 无定义。
落实为（`sim/step4_gvnext/stage2_flex.py` 文档字符串同此）：

```
Δ(u)   = gyro_flex(u) − gyro_base(u)        两次 MuJoCo 前向，同 θ*、同命令
ω̂      = kin(q̂) + Δ + r_s′                 q̂ = G-q-v1(u) + r_q   ← r_q 冻结
目标 Y′ = A_body − kin(q_true) − Δ
```

- Δ ≡ 0 时**逐比特退回 G-2** ⇒ 可直接比较。
- 关节层与 G-2 **完全相同**，柔性铰的全部作用只走 Δ ⇒ 不重复计入。
- Δ 以**单位增益**进入，不作 `r_s′` 的特征、不拟合缩放 ⇒ 不新增自由度。
- 口径：Δ 两端都是 MuJoCo 陀螺经 9 Hz 低通后取 20 Hz，与 `kin_gyro_fs` 同约定。

**重拟结果**：`r_s′` = FIR nlag=16, λ=1e-4，折外 3–9 Hz 削减 **39.0%**
——**低于** G-2 的 `r_s`（42.3%）。

## 4. 根因：Δ 落在 `r_s` 的张成里（实测 87.9%）

`sim/step4_gvnext/diag_flex_span.py` —— 用**同一组 `r_s` 特征、同一阶数**，
在训练族上**折外**回归 Δ：

| λ | 折外可解释的 Δ（3–9 Hz） | （0.5–3 Hz） |
|---|---|---|
| 1e-4 | **87.9%** | 90.0% |
| 1e-3 | 86.9% | 89.9% |
| 1e-2 | 84.9% | 90.2% |

Δ 的带内 RMS = `r_s` 目标带内 RMS 的 56% —— **量不小，但不是新信息**。

这与项目里已有的结论完全一致：**因果 FIR 张成 LTI 传递率**，
而 `kin(q̂)` 本身就是 `r_s` 的特征之一，所以 `ω̂ = (I + A(z))·kin + …`
已经是一个一般的 MIMO 线性传递率。选中点 (ω=3.965, ζ=0.7) 是**重阻尼低频**、
铰运动仅 0.146°，工作在近乎线性的区间 ⇒ 几乎没有落在 FIR 张成之外的成分。

## 5. ⚠ 我在探针里用错了正交性判据（必须记下）

探针报告过：「Δ 与 `r_s` 输出的 ρ = 0.202 ⇒ **ρ² = 0.041，几乎正交** ⇒ 应当叠加而非被吸收」。

**这是错的测法。** 与**已拟合输出**低相关，**不等于**落在**特征张成之外**。
`r_s` 之所以没输出 Δ 那个形状，是因为它在拟合另一个目标，不是因为它做不到。
正确的判据是本文件 §4 那个：**同一特征集能否折外重现 Δ**。答案是 87.9%。

**教训（可推广）**：给一个已有可学习残差层的模型加新结构项时，
「新项 vs 现有输出的相关」是无效判据；必须测「新项是否在现有特征的张成之内」。
这个检查零成本，应当在开网格**之前**做。

## 6. 顺带确认的两件事

- **阶段 1 的选格判据也有问题**（但不是失败主因）：它按**底座层** IMU ρ² 选，
  而底座层没有 `r_s`，所以它奖励的恰恰是「一个好的 LTI 滞后修正」——
  正是 `r_s` 已经能提供的东西。响应面向低 ω / 高 ζ 的脊（§1.2）就是这个奖励的痕迹。
- **不是「柔性铰没动」**：铰在带内相对运动 0.146°（探针点为 0.0713–0.0813°），
  机制确实活跃；它只是**没带来新信息**。

## 8. 口径（每处引用必须带）

- 称 **「j5 下游有效柔性模态」**；物理归属**未定**（需第二个 IMU，已放弃）。
  **不得**称「已辨识出的 j5 真实传动柔性」。
- 8 条是**开发验证集**，**不是**密封 holdout（探针已看过）。
- 本文所有完整模型数字均来自**完整模型直接评价**；**`ρ²` 不可线性相加**，
  底座层的 0.187→0.212 从未被外推。
- 结构由**训练族**选定，开发验证集未参与选格与拟合；`r_q` 全程冻结。
- 真机 100 Hz → 9 Hz 低通 → 20 Hz；时基 = TSND 设备 ms + CAN 内核时刻；
  逐集正交 Procrustes 旋入机体系；逐系列最优位移。
- 与 17 集 pp2 开发基准集、`structure_compare` 的旧口径数字**均不可并列**。
